# @mantine/lightbox

[![npm](https://img.shields.io/npm/dm/@mantine/lightbox)](https://www.npmjs.com/package/@mantine/lightbox)

Full-screen media lightbox with carousel navigation

[View documentation](https://mantine.dev/)

## Installation

```bash
# With yarn
yarn add @mantine/lightbox @mantine/core @mantine/hooks embla-carousel embla-carousel-react

# With npm
npm install @mantine/lightbox @mantine/core @mantine/hooks embla-carousel embla-carousel-react
```
