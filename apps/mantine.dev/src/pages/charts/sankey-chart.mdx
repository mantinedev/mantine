## Usage

`SankeyChart` is based on the [Sankey recharts component](https://recharts.org/en-US/api/Sankey).
It visualizes flow between nodes where the width of each link is proportional to the flow value:

<Demo data={SankeyChartDemos.usage} />

## Node color

Set `color` on a node in the data to change its color. Theme colors and any valid CSS color are accepted:

<Demo data={SankeyChartDemos.color} />

## Custom colors

Use `colors` prop to set colors for nodes that do not have `color`. Colors repeat when there are more nodes than colors:

<Demo data={SankeyChartDemos.colors} />

## Node width and padding

Use `nodeWidth` to control the width of each node and `nodePadding` to control
the spacing between nodes:

<Demo data={SankeyChartDemos.nodeWidth} />

## Link opacity

Use `linkOpacity` prop to control the opacity of links between nodes:

<Demo data={SankeyChartDemos.linkOpacity} />

## Disable tooltip

To disable the tooltip, set `withTooltip={false}`:

<Demo data={SankeyChartDemos.noTooltip} />
