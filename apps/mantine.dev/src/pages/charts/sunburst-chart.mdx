## Usage

`SunburstChart` is based on the [SunburstChart recharts component](https://recharts.org/en-US/api/SunburstChart).
It displays hierarchical data as concentric rings, similar to a treemap plotted in polar coordinates:

<Demo data={SunburstChartDemos.usage} />

## Data format

Each node has a `name`. Leaf nodes have a `value`. Nodes with `children` show the sum of their children, or their own `value` if it is larger. Nodes can be nested to any depth, and top-level nodes can be leaves:

```tsx
export const data = [
  {
    name: 'Frontend',
    color: 'blue.6',
    children: [
      { name: 'React', value: 400 },
      { name: 'Vue', value: 200 },
      { name: 'Angular', value: 150 },
    ],
  },
  {
    name: 'Backend',
    color: 'teal.6',
    children: [
      { name: 'Node', value: 300 },
      { name: 'Python', value: 250 },
    ],
  },
];
```

## Node color

`color` accepts theme colors and any valid CSS color. Children inherit the color of their parent node unless they set their own. Top-level nodes without `color` get colors from a default palette:

<Demo data={SunburstChartDemos.color} />

Use `innerRadius` prop to control the size of the empty circle in the center of the chart:

<Demo data={SunburstChartDemos.innerRadius} />

## Start and end angle

Use `startAngle` and `endAngle` props to draw a part of the ring. Angles are in degrees, `0` points to the right and angles grow counterclockwise. Without `endAngle`, the chart draws a full circle from `startAngle`:

<Demo data={SunburstChartDemos.angles} />

## Labels

Set `withLabels` to display value labels inside sectors. Labels that do not fit their sector are hidden. Increase `size` to give labels enough space:

<Demo data={SunburstChartDemos.withLabels} />
