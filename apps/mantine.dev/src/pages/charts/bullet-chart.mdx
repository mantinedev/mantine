## Usage

`BulletChart` displays a value against a target on top of range bands:

<Demo data={BulletChartDemos.usage} />

## Data format

Each item in `ranges` sets the upper bound of a band with `value` and its `color`.
The optional `label` names the band. It is read by screen readers and shown in the default tooltip.
Visible labels always show the formatted range value.

```tsx
const ranges = [
  { value: 100000, color: 'red.8', label: 'Poor' },
  { value: 200000, color: 'yellow.8', label: 'Average' },
  { value: 300000, color: 'teal.8', label: 'Good' },
];
```

The scale ends at the largest of the ranges, `value` and `target`.
A value beyond all ranges extends the scale, and `NaN` or `Infinity` values are not displayed.

## Accessibility

`BulletChart` is announced as an image. Its accessible name is built from `label`, the formatted value, the range label and the target, for example "Revenue value $230k, in Good range, target $150k".
Set `aria-label` to replace the generated name, for example to translate it:

```tsx
<BulletChart aria-label="Ingresos: 230k, objetivo 150k" value={230000} target={150000} ranges={ranges} />
```
