## Usage

`BulletChart` displays a value against a target on top of range bands:

<Demo data={BulletChartDemos.usage} />

## Data format

`BulletChart` expects `ranges` as an array of objects with `value` and `color` properties:

```tsx
const ranges = [
  { value: 150000, color: 'red.8', label: 'Poor' },
  { value: 225000, color: 'yellow.7', label: 'Average' },
  { value: 300000, color: 'teal.8', label: 'Good' },
];
```

## Label

Use `label` prop to display a label next to the chart:

<Demo data={BulletChartDemos.label} />

## Vertical orientation

Set `orientation="vertical"` to render the chart vertically. Vertical chart requires a fixed height:

<Demo data={BulletChartDemos.vertical} />

## Bar color

Use `barColor` prop to change the value bar color and `targetColor` to change the target marker color:

<Demo data={BulletChartDemos.barColor} />

## Chart size

Use `size` prop to change the height of the track and `barSize` to change the height of the value bar:

<Demo data={BulletChartDemos.barSize} />

## Value formatter

Use `valueFormatter` prop to format values in labels and tooltip. Set `withTooltip` to display the tooltip on hover:

<Demo data={BulletChartDemos.valueFormatter} />
