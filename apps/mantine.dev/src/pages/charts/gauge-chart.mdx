## Usage

`GaugeChart` displays a single value on a radial arc:

<Demo data={GaugeChartDemos.usage} />

## Sections

Use `sections` to split the arc into threshold bands. Each section ends at its `value`, the last section should end at `max`.
With `sections`, the whole arc is colored, use the [target marker](#target-marker) to show where the value falls:

<Demo data={GaugeChartDemos.sectionsProp} />

## Target marker

Set `target` to draw a line marker across the arc at the given value.
Use `targetColor` and `targetSize` to change its color and thickness:

<Demo data={GaugeChartDemos.target} />

## Start and end angle

`startAngle` and `endAngle` set the span of the arc in degrees. `0` is the top of the chart, positive values go clockwise:

<Demo data={GaugeChartDemos.angles} />

A span of 360 degrees renders a full circle. Set `endAngle` lower than `startAngle`
to draw the arc counter-clockwise:

```tsx
import { GaugeChart } from '@mantine/charts';

function Demo() {
  return (
    <>
      {/* Full circle */}
      <GaugeChart value={72} startAngle={0} endAngle={360} />

      {/* Counter-clockwise */}
      <GaugeChart value={72} startAngle={120} endAngle={-120} />
    </>
  );
}
```

## Accessibility

The chart has `role="meter"` and announces the formatted value.
The `label` is not used as the accessible name, set `aria-label` to name the metric:

```tsx
import { GaugeChart } from '@mantine/charts';

function Demo() {
  return <GaugeChart value={72} aria-label="CPU utilization" />;
}
```
