## Usage

`MatrixChart` is a heatmap with categorical axes, each cell is colored based on its value:

<Demo data={MatrixChartDemos.usage} />

## Data format

Data is an array of `MatrixChartCell` objects:

```tsx
interface MatrixChartCell {
  x: string;
  y: string;
  value: number | null;
}
```

- `x` – column identifier
- `y` – row identifier
- `value` – numeric value for color interpolation, `null` for empty cells

## Labels

Set `withXLabels` and `withYLabels` to display axis labels. Use `xLabels` and `yLabels` props to override labels taken from the data,
and `xLabelsPosition="top"` to display x-axis labels above the chart:

<Demo data={MatrixChartDemos.labels} />

## X-axis labels rotation

Use `xLabelsRotation` prop to change the angle of x-axis labels, for example, `0` for horizontal labels:

<Demo data={MatrixChartDemos.xLabelsRotation} />

## Tooltip

Set `withTooltip` prop and provide `getTooltipLabel` function to display a tooltip on cell hover:

<Demo data={MatrixChartDemos.tooltip} />

## Colors

Use `colors` prop to change the palette. Cell colors are interpolated between the given colors:

<Demo data={MatrixChartDemos.colors} />

## Values domain

Use `domain` prop to set a custom `[min, max]` range for color interpolation:

<Demo data={MatrixChartDemos.domain} />

## Cell size and gap

Use `cellSize`, `gap` and `cellRadius` props to change cell size, spacing and border radius:

<Demo data={MatrixChartDemos.cellSize} />

Use `getCellProps` to add props to individual cells based on their data:

## Legend

Set `withLegend` prop to display a color legend below the chart. Use `legendLabels` prop to change its labels:

<Demo data={MatrixChartDemos.legend} />

## Accessibility

Cells are not announced by screen readers. Set `aria-label` or `aria-labelledby`
to describe what the chart shows:

```tsx
import { MatrixChart } from '@mantine/charts';

function Demo() {
  return <MatrixChart data={[]} aria-label="Deployments per service and weekday" />;
}
```
