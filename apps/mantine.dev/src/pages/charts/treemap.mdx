## Usage

`Treemap` is based on the [Treemap recharts component](https://recharts.org/en-US/api/Treemap).
It displays hierarchical data as a set of nested rectangles:

<Demo data={TreemapDemos.usage} />

## Nested data

Each data item can have a `children` array. Children inherit the `color` of their parent node:

<Demo data={TreemapDemos.nestedDataDemo} />

## Node color

`color` accepts theme colors and any valid CSS color:

<Demo data={TreemapDemos.color} />

## autoContrast

Label color is adjusted to the node background color when [theme.autoContrast](/theming/theme-object/#autocontrast) is enabled.
Set `autoContrast={false}` to disable it:

<Demo data={TreemapDemos.autoContrast} />

## Node stroke

Use `strokeWidth` and `strokeColor` props to change the stroke around nodes:

<Demo data={TreemapDemos.strokeColor} />

## Disable tooltip

To disable the tooltip, set `withTooltip={false}`:

<Demo data={TreemapDemos.noTooltip} />
