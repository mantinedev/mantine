## Usage

`BarsList` displays a list of horizontal bars with names and values:

<Demo data={BarsListDemos.usage} />

## Data format

`BarsList` expects data in the following format. Values must be non-negative. Negative and non-finite values are treated as 0:

```tsx
export const data = [
  { name: 'React', value: 950000 },
  { name: 'Vue', value: 320000 },
  { name: 'Angular', value: 580000 },
  { name: 'Svelte', value: 145000 },
];
```

## Auto contrast

Set `autoContrast` prop to adjust text color to the bar background color.
It applies to bars with solid background: `variant="filled"` or colors with a shade, for example `blue.9`.
It is enabled by default when [theme.autoContrast](/theming/theme-object/#autocontrast) is set:

<Demo data={BarsListDemos.autoContrast} />

## Custom colors

Each bar can have its own color by setting the `color` property in the data.
Set `variant="filled"` to display bars with solid background. Colors with a shade, for example `blue.6`, always have solid background:

<Demo data={BarsListDemos.customColors} />

Use `getBarProps` to pass props to each bar element, for example, to highlight some bars.
