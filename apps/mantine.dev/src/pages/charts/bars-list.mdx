## Usage

`BarsList` displays a list of horizontal bars with names and values:

<Demo data={BarsListDemos.usage} />

## Data format

`BarsList` expects data in the following format:

```tsx
export const data = [
  { name: 'React', value: 950000 },
  { name: 'Vue', value: 320000 },
  { name: 'Angular', value: 580000 },
  { name: 'Svelte', value: 145000 },
];
```

## Auto contrast

Text color is adjusted to the bar background color when [theme.autoContrast](/theming/theme-object/#autocontrast) is enabled.
Set `autoContrast={false}` to disable it:
