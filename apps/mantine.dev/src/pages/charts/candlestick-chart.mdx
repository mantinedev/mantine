## Usage

`CandlestickChart` displays open, high, low and close (OHLC) values as candles.
The candle body shows the open–close range, the thin line shows the high–low range:

<Demo data={CandlestickChartDemos.usage} />

## Data

Set `dataKey` to the property that is used for the x-axis. OHLC values are read from
the `open`, `high`, `low` and `close` properties of each data item:

```tsx
import { CandlestickChart } from '@mantine/charts';

const data = [
  { date: 'Mar 01', open: 136, high: 142, low: 133, close: 140 },
  { date: 'Mar 02', open: 140, high: 145, low: 138, close: 139 },
  { date: 'Mar 03', open: 139, high: 141, low: 129, close: 131 },
];

function Demo() {
  return <CandlestickChart h={300} data={data} dataKey="date" />;
}
```

The y-axis does not start at zero, its domain is calculated from the data.
To change it, pass `domain` through `yAxisProps`.

## Tooltip labels

Use `labels` prop to change the open, high, low and close labels in the tooltip:

```tsx
import { CandlestickChart } from '@mantine/charts';

function Demo() {
  return (
    <CandlestickChart
      data={data}
      dataKey="date"
      labels={{ open: 'Ouverture', high: 'Haut', low: 'Bas', close: 'Clôture' }}
    />
  );
}
```
