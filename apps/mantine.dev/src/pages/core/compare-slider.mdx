## Usage

`CompareSlider` displays two layers in the same box with a draggable divider between them,
for example to compare two versions of an image. The `before` layer is displayed on the left
of the divider, the `after` layer on the right:

<Demo data={CompareSliderDemos.usage} />

## Compare any content

`before` and `after` accept any React node. Both layers fill the container,
make sure they have the same dimensions:

<Demo data={CompareSliderDemos.content} />

Set `changePositionOnHover` to move the divider with the pointer instead of dragging:

<Demo data={CompareSliderDemos.hover} />

## Custom handle

Use the `handle` prop to replace the default divider handle with any React node:

<Demo data={CompareSliderDemos.customHandle} />

Set `withHandle={false}` to hide the handle, the divider line stays interactive:

```tsx
import { CompareSlider, Image } from '@mantine/core';

function Demo() {
  return (
    <CompareSlider
      withHandle={false}
      before={<Image src="/before.png" />}
      after={<Image src="/after.png" />}
    />
  );
}
```

## Container size

`CompareSlider` takes the full width of its parent and has no intrinsic height. Set the height
with `h` prop or an `aspect-ratio`. If the parent does not constrain the width, for example a flex
container, set `w` or `maw` as well. Make both layers fill the box:

```tsx
import { CompareSlider, Image } from '@mantine/core';

function Demo() {
  return (
    <CompareSlider
      w={{ base: 300, sm: 500 }}
      h={{ base: 192, sm: 320 }}
      before={<Image src="/before.png" h="100%" w="100%" fit="cover" />}
      after={<Image src="/after.png" h="100%" w="100%" fit="cover" />}
    />
  );
}
```

## Transition

Set `transition` prop to animate position changes made with the keyboard or with a controlled value.
Pass `true` for the default duration or a number of milliseconds. The transition is not applied
while the divider is dragged or when `changePositionOnHover` is set:

```tsx
import { CompareSlider } from '@mantine/core';

function Demo() {
  return <CompareSlider transition={200} before="Before" after="After" />;
}
```

## Accessibility

The handle is a slider element, set `aria-label` to describe it for screen readers:

```tsx
import { CompareSlider } from '@mantine/core';

function Demo() {
  return <CompareSlider aria-label="Compare before and after" before="Before" after="After" />;
}
```
