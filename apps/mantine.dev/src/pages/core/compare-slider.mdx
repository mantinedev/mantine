## Usage

`CompareSlider` displays two layers in the same box with a draggable divider between them.
It is commonly used to compare two versions of an image. The `before` layer is displayed
on the left/top side of the divider, the `after` layer – on the right/bottom side.

<Demo data={CompareSliderDemos.usage} />

## Compare any content

`before` and `after` accept any React node: videos, maps, charts, code blocks or plain markup.
Both layers fill the container, make sure they have the same dimensions:

## Custom handle

Use the `handle` prop to replace the default divider handle with any React node:

<Demo data={CompareSliderDemos.customHandle} />

Set `withHandle={false}` to hide the handle. The divider line stays visible and the component
remains interactive:

```tsx
import { CompareSlider, Image } from '@mantine/core';

function Demo() {
  return (
    <CompareSlider
      withHandle={false}
      before={<Image src="/before.png" />}
      after={<Image src="/after.png" />}
    />
  );
}
```

## Container size

`CompareSlider` does not have an intrinsic size. It takes the full width of its parent,
so in most layouts you only need to set a height with `h` prop or an `aspect-ratio`.
If the parent does not constrain the width (for example, a flex container), set `w` or `maw` prop.
Make both layers fill the box:

```tsx
import { CompareSlider, Image } from '@mantine/core';

function Demo() {
  return (
    <CompareSlider
      w={{ base: 300, sm: 500 }}
      h={{ base: 192, sm: 320 }}
      before={<Image src="/before.png" h="100%" w="100%" fit="cover" />}
      after={<Image src="/after.png" h="100%" w="100%" fit="cover" />}
    />
  );
}
```

## Transition

Set `transition` prop to animate position changes made with the keyboard or with a controlled
value. Pass `true` to use the default `150ms` duration or a number to set the duration in
milliseconds. The transition is not applied while the divider is dragged and when
`changePositionOnHover` is set:

```tsx
import { CompareSlider } from '@mantine/core';

function Demo() {
  return <CompareSlider transition={200} before="Before" after="After" />;
}
```

## Accessibility

The divider handle is a `role="slider"` element. To make the component accessible for screen
readers, set the `aria-label` prop:

```tsx
import { CompareSlider } from '@mantine/core';

function Demo() {
  return <CompareSlider aria-label="Compare before and after" before="Before" after="After" />;
}
```
