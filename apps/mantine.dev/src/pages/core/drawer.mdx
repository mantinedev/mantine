## Sizes

You can change the drawer width/height (depends on `position`) by setting the `size` prop to a predefined size or any valid width,
for example, `size="55%"` or `size={200}`:

```tsx
import { Drawer } from '@mantine/core';

function Demo() {
  return (
    <Drawer position="right" size="xl" opened onClose={() => {}}>
      {/* Drawer content */}
    </Drawer>
  );
}
```

## Full screen

Set the `fullScreen` prop to make the drawer take the entire viewport along its `position` axis,
or `fullScreenBelow` to do that only when the viewport is narrower than the given breakpoint:

<Demo data={DrawerDemos.fullScreenBelow} />

A full screen drawer takes full width for `left` and `right` positions and full height for `top` and
`bottom`. The `size`, `offset` and `radius` props are ignored while the drawer is full screen.

`fullScreenBelow` accepts a key of `theme.breakpoints` (`xs`, `sm`, `md`, `lg`, `xl`), any CSS length
(for example, `'50em'` or `'800px'`) or a number of pixels. The drawer reacts to viewport changes while
it is opened. `fullScreen` takes precedence over `fullScreenBelow` – it forces full screen at any
viewport width. When `snapPoints` are set, the drawer is sized by the snap points and neither
`fullScreen` nor `fullScreenBelow` has an effect.

## Swipe to dismiss

`Drawer` can be dismissed with a swipe gesture. Swipe to dismiss is enabled by default for all
four positions and is RTL-aware. Swipe the drawer towards its edge of the viewport to close it:

<Demo data={DrawerDemos.swipe} />

To disable swipe to dismiss, set `withSwipe={false}`:

```tsx
import { Drawer } from '@mantine/core';

function Demo() {
  return (
    <Drawer withSwipe={false} opened onClose={() => {}}>
      {/* Drawer content */}
    </Drawer>
  );
}
```

Use the `swipeThreshold` prop to control how far the drawer must be dragged before it is
dismissed. The value is a fraction of the drawer size along the drag axis (`0.25` by default,
meaning the drawer is dismissed once dragged past 25% of its size):

```tsx
import { Drawer } from '@mantine/core';

function Demo() {
  return (
    <Drawer swipeThreshold={0.5} opened onClose={() => {}}>
      {/* Drawer content */}
    </Drawer>
  );
}
```

## Disable swipe on specific elements

Set the `data-drawer-no-swipe` attribute on elements that must not start the swipe gesture,
for example, third-party drag and drop lists or other draggable widgets. The gesture is ignored
when it starts on the element or any of its descendants:

<Demo data={DrawerDemos.noSwipe} />

## Drag handle

Set the `withHandle` prop to display a grab-bar that hints the drawer can be dragged:

<Demo data={DrawerDemos.handle} />

The handle is rendered on the overlay at the drawer's leading edge (the edge that faces the viewport
interior) and stays attached to the panel while it slides and during swipe/snap drags.

## Snap points

Set the `snapPoints` prop to let the drawer rest at several sizes and be dragged between them:

<Demo data={DrawerDemos.snapPoints} />

Each snap point is a fraction of the viewport (for example, `0.4` for 40%), a number of pixels greater
than `1` (for example, `300`) or a string with a percentage or pixel value (for example, `'40%'` or
`'300px'`).

The active snap point can be controlled with `activeSnapPoint`/`onSnapPointChange` props
or used in uncontrolled mode with `defaultActiveSnapPoint` (the largest snap point by default).
In uncontrolled mode, the drawer returns to `defaultActiveSnapPoint` every time it opens:

```tsx
import { useState } from 'react';
import { Drawer } from '@mantine/core';

function Demo() {
  const [activeSnapPoint, setActiveSnapPoint] = useState<number | string>(0.4);

  return (
    <Drawer
      position="bottom"
      snapPoints={[0.4, 0.75, 1]}
      activeSnapPoint={activeSnapPoint}
      onSnapPointChange={setActiveSnapPoint}
      opened
      onClose={() => {}}
    >
      {/* Drawer content */}
    </Drawer>
  );
}
```

## Initial focus

`Drawer` uses [FocusTrap](/core/focus-trap/) to trap focus. Add the `data-autofocus`
attribute to the element that should receive initial focus.

<Demo data={DrawerDemos.initialFocus} />

If you do not want to focus any elements when the drawer is opened, use the `FocusTrap.InitialFocus`
component to create a visually hidden element that will receive initial focus:

<Demo data={DrawerDemos.initialFocusTrap} />

If you do not add the `data-autofocus` attribute and do not use `FocusTrap.InitialFocus`,
the drawer will focus the first focusable element inside it which is usually the close button.

## Control behavior

The following props can be used to control `Drawer` behavior.
In most cases it is not recommended to turn these features off –
it will make the component less accessible.

- `trapFocus` – determines whether focus should be trapped inside drawer
- `closeOnEscape` – determines whether the drawer should be closed when `Escape` key is pressed
- `closeOnClickOutside` – determines whether the drawer should be closed when user clicks on the overlay
- `returnFocus` – determines whether focus should be returned to the element that was focused before the drawer was opened

## react-remove-scroll settings

`Drawer` uses [react-remove-scroll](https://github.com/theKashey/react-remove-scroll)
package to lock scroll. You can pass props down to the `RemoveScroll` component
with `removeScrollProps`:

```tsx
import { Drawer } from '@mantine/core';

function Demo() {
  return (
    <Drawer
      removeScrollProps={{ allowPinchZoom: true }}
      opened
      onClose={() => {}}
    >
      {/* Drawer content */}
    </Drawer>
  );
}
```

## Compound components

You can use the following compound components to have full control over the `Drawer` rendering:

- `Drawer.Root` – context provider
- `Drawer.Overlay` – render [Overlay](/core/overlay/)
- `Drawer.Content` – main drawer element, should include all drawer content
- `Drawer.Header` – sticky header, usually contains `Drawer.Title` and `Drawer.CloseButton`
- `Drawer.Title` – `h2` element, `aria-labelledby` of `Drawer.Content` is pointing to this element, usually is rendered inside `Drawer.Header`
- `Drawer.CloseButton` – close button, usually rendered inside `Drawer.Header`
- `Drawer.Body` – a place for main content, `aria-describedby` of `Drawer.Content` is pointing to this element
- `Drawer.Footer` – footer element, usually contains action buttons, pinned to the bottom by default (controlled with `stickyFooter`)

## Drawer.Stack

Use `Drawer.Stack` component to render multiple drawers at the same time.
`Drawer.Stack` keeps track of opened drawers, manages z-index values, focus trapping
and `closeOnEscape` behavior. `Drawer.Stack` is designed to be used with `useDrawersStack` hook.

Differences from using multiple `Drawer` components:

- `Drawer.Stack` manages z-index values – drawers that are opened later will always have higher z-index value disregarding their order in the DOM
- `Drawer.Stack` disables focus trap and `Escape` key handling for all drawers except the one that is currently opened
- All opened drawers stay mounted and visible with a stacked depth effect – drawers below the top one are scaled down and offset to create a sense of depth
- Only one overlay is rendered at a time

<Demo data={DrawerDemos.stack} />

Drawers behind the top one are dimmed by the single overlay and cannot be interacted with –
only the top drawer receives pointer events, focus and `Escape` key presses. Set
`withStackTransform={false}` to disable the stacked depth effect – in this case only the top
drawer is visible, drawers behind it are hidden until the top one is closed.

Use the `maxDepth` prop (default `5`) to control how many stacked drawers are visible behind the
top one at the same time:

```tsx
import { Drawer, useDrawersStack } from '@mantine/core';

function Demo() {
  const stack = useDrawersStack(['first', 'second', 'third']);

  return (
    <Drawer.Stack maxDepth={3}>
      <Drawer {...stack.register('first')}>First</Drawer>
      <Drawer {...stack.register('second')}>Second</Drawer>
      <Drawer {...stack.register('third')}>Third</Drawer>
    </Drawer.Stack>
  );
}
```

Note that `Drawer.Stack` can only be used with `Drawer` component. Components built with `Drawer.Root`
and other compound components are not compatible with `Drawer.Stack`.

All drawers rendered inside `Drawer.Stack` are a part of the stack, `stackId` prop is required only to
connect drawer with the `useDrawersStack` hook. To enable stacking for all drawers in your application
without `Drawer.Stack`, see [shared stack](#shared-stack) section.

## useDrawersStack hook

`useDrawersStack` hook provides an easy way to control multiple drawers at the same time.
It accepts an array of unique drawers ids and returns an object with the following properties:

```tsx
interface UseDrawersStackReturnType<T extends string> {
  // Current opened state of each drawer
  state: Record<T, boolean>;

  // Opens drawer with the given id
  open: (id: T) => void;

  // Closes drawer with the given id
  close: (id: T) => void;

  // Toggles drawer with the given id
  toggle: (id: T) => void;

  // Closes all drawers within the stack
  closeAll: () => void;

  // Returns props for drawer with the given id
  register: (id: T) => {
    opened: boolean;
    onClose: () => void;
    stackId: T;
  };
}
```

Example of using `useDrawersStack` with `Drawer` component:

```tsx
import { Drawer, useDrawersStack } from '@mantine/core';

function Demo() {
  const stack = useDrawersStack(['first', 'second']);

  return (
    <>
      <Drawer {...stack.register('first')}>First</Drawer>
      <Drawer {...stack.register('second')}>Second</Drawer>
      <Button onClick={() => stack.open('first')}>Open first</Button>
    </>
  );
}
```

## Shared stack

Set `theme.overlayStack` to stack all `Drawer` components in your application automatically,
without `Drawer.Stack` wrapper and `stackId` prop:

```tsx
import { createTheme, MantineProvider } from '@mantine/core';

const theme = createTheme({
  overlayStack: true,
});

function App() {
  return <MantineProvider theme={theme}>{/* Your app here */}</MantineProvider>;
}
```

<Demo data={DrawerDemos.overlayStack} />

With `overlayStack` enabled, all drawers join one shared `Drawer.Stack`. Any drawer that is opened
while another drawer is opened is rendered on top of it: z-index, focus trap, `Escape` key handling
and the overlay are managed for the entire application. [Modal](/core/modal) components join their
own shared `Modal.Stack` – drawers and modals are never stacked visually together, but z-index,
focus trap and `Escape` key handling always follow the topmost opened drawer or modal.

`overlayStack` accepts an object to configure the shared stacks:

```tsx
import { createTheme } from '@mantine/core';

const theme = createTheme({
  overlayStack: {
    // Maximum number of stacked drawers that remain visible behind the top one, 5 by default
    maxDepth: 3,

    // true by default, false disables the depth effect and shows only the top drawer
    withStackTransform: false,
  },
});
```

When `theme.overlayStack` is set, `Drawer.Stack` does not create a separate stack – drawers
rendered inside it become a part of the shared stack, `maxDepth` and `withStackTransform`
props of `Drawer.Stack` are ignored. `useDrawersStack` hook can still be used to manage
opened state of several drawers.

`stackId` values inside the shared stack are scoped per `Drawer.Stack` instance – separate
`Drawer.Stack` components may reuse the same ids (for example, two components that both call
`useDrawersStack(['first', 'second'])`) without conflicts. `useDrawerStackContext` called inside such
`Drawer.Stack` returns only the drawers of that `Drawer.Stack`, and its `close` and `closeAll`
handlers do not affect drawers of other `Drawer.Stack` instances.

Use `useDrawerStackContext` hook to access the shared stack (or the closest `Drawer.Stack`)
from any component:

```tsx
import { Button, useDrawerStackContext } from '@mantine/core';

function CloseAllButton() {
  const stack = useDrawerStackContext();
  return <Button onClick={stack.closeAll}>Close all drawers ({stack.stack.length})</Button>;
}
```

`useDrawerStackContext` returns an object with the following properties:

```tsx
interface UseDrawerStackContextReturnType {
  // Ids of opened drawers, the last item is the top drawer
  stack: string[];

  // Id of the top drawer, undefined if no drawers are opened
  currentId: string | undefined;

  // Calls onClose of the drawer with the given id
  close: (id: string) => void;

  // Calls onClose of all opened drawers, starting from the top one
  closeAll: () => void;
}
```

## Fixed elements offset

`Drawer` component uses [react-remove-scroll](https://github.com/theKashey/react-remove-scroll)
package to lock scroll. To properly size these `elements` add a `className` to them ([documentation](https://github.com/theKashey/react-remove-scroll#positionfixed-elements)):

```tsx
import { RemoveScroll } from '@mantine/core';

function Demo() {
  return (
    <>
      <div className={RemoveScroll.classNames.fullWidth}>
        width: 100%
      </div>
      <div className={RemoveScroll.classNames.zeroRight}>
        right: 0
      </div>
    </>
  );
}
```

## Accessibility

`Drawer` component follows [WAI-ARIA recommendations](https://www.w3.org/WAI/ARIA/apg/patterns/dialog-modal/examples/dialog) on accessibility.

Set `title` props to make component accessible, will add `aria-labelledby` to the content element:

```tsx
import { Drawer } from '@mantine/core';

function Demo() {
  return <Drawer title="Drawer label" opened onClose={() => {}} />;
}
```

To set close button `aria-label` use `closeButtonProps`:

```tsx
import { Drawer } from '@mantine/core';

function Demo() {
  return (
    <Drawer
      closeButtonProps={{ 'aria-label': 'Close drawer' }}
      opened
      onClose={() => {}}
    />
  );
}
```
