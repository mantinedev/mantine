## Usage

`Marquee` scrolls its children continuously, for example a row of logos or testimonials:

<Demo data={MarqueeDemos.usage} />

## Pause on hover

Set `pauseOnHover` prop to pause the animation when the user hovers over the component
or moves focus inside it:

<Demo data={MarqueeDemos.pauseOnHover} />

## Pause control

Set `playing={false}` to pause the animation. Content that moves for more than five seconds
must have a control to pause it ([WCAG 2.2.2](https://www.w3.org/WAI/WCAG22/Understanding/pause-stop-hide.html)):

<Demo data={MarqueeDemos.playing} />

## Vertical orientation

Set `orientation="vertical"` to scroll content vertically. The container must have
a fixed height:

<Demo data={MarqueeDemos.vertical} />

## Multiple rows

Combine several `Marquee` components with different directions:

<Demo data={MarqueeDemos.multipleRows} />

## Fade edges

By default, the edges are faded with a gradient. Use `fadeEdges`, `fadeEdgeColor` and
`fadeEdgeSize` props to change or disable it. When `Marquee` is placed on a colored
surface, set `fadeEdgeColor` to the surface color:

<Demo data={MarqueeDemos.fadeEdges} />

## Customization

Use `reverse`, `duration` and `gap` props to change the direction, speed and spacing of the
animation. `repeat` sets the minimum number of copies, more are added to fill wide containers:

<Demo data={MarqueeDemos.configurator} />

## Accessibility

Only the first copy of children is exposed to assistive technologies. Repeated copies are
hidden and skipped by the Tab key, but stay clickable. The animation stops when the user
prefers reduced motion and `respectReducedMotion` is enabled on the [theme](/theming/theme-object/).
