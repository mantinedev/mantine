## Usage

`ActionBar` is a bottom bar with bulk actions that appears when items are selected.
Use `ActionBar.Divider` to separate groups of actions and `ActionBar.CloseButton`
to add a close button that calls `onClose`:

## Placement

By default, `ActionBar` is centered at the bottom of the screen. Change it with the `position` prop.
For non-centered positions, set `styles={{ root: { marginInline: 0 } }}` to remove the auto centering.
Use `affixProps` to pass props down to the underlying [Affix](/core/affix):

<Demo data={ActionBarDemos.placement} />

## Close on Escape

Set `closeOnEscape` to close the bar with the `Escape` key. `Escape` pressed inside
a modal or an opened dropdown does not close the bar:

## Transitions

Use `transitionProps` to change the [transition](/core/transition), its duration and timing function:

```tsx
import { ActionBar, Button } from '@mantine/core';

function Demo() {
  return (
    <ActionBar opened transitionProps={{ transition: 'slide-up', duration: 300 }}>
      <Button>Delete</Button>
    </ActionBar>
  );
}
```

## keepMounted

By default, the action bar is removed from the DOM when it is closed. Set `keepMounted`
to keep it mounted, for example to preserve form state inside the bar:

```tsx
import { ActionBar, Button } from '@mantine/core';

function Demo() {
  return (
    <ActionBar opened={false} keepMounted>
      <Button>Delete</Button>
    </ActionBar>
  );
}
```

## Rendering in a portal

`ActionBar` is rendered inside [Portal](/core/portal) by default. Set `withinPortal={false}`
to render it in place and `portalProps` to pass props down to the portal.

## Accessibility

`ActionBar` does not set any labels by default, set:

- `aria-label` on `ActionBar` to describe what the actions apply to
- `aria-label` on `ActionBar.CloseButton`, it renders only an icon

Screen readers are not notified when the bar appears. Set `announcement` to announce it
every time the bar opens or its content changes:

```tsx
import { ActionBar, Button } from '@mantine/core';

function Demo({ selection }: { selection: string[] }) {
  return (
    <ActionBar
      opened={selection.length > 0}
      aria-label="Selected rows actions"
      announcement={`${selection.length} rows selected, bulk actions available`}
    >
      <Button>Delete</Button>
      <ActionBar.CloseButton aria-label="Clear selection" />
    </ActionBar>
  );
}
```
