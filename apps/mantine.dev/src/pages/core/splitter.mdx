## CSS units

`defaultSize`, `min` and `max` props of `Splitter.Pane` accept numbers, percentages and CSS units:

- A number or a `%` string is a flexible size, the pane shares the leftover space with other flexible panes
- A `px` or `rem` string is a fixed size, the pane keeps it when the container is resized

`sizes` and `onSizeChange` use the unit the pane was declared with:

## Handle props

`getHandleProps` is called with the handle index and returns props for that handle.
Use it to set `aria-label` on each handle:

```tsx
import { Splitter } from '@mantine/core';

function Demo() {
  return (
    <Splitter getHandleProps={(index) => ({ 'aria-label': `Resize pane ${index + 1}` })}>
      <Splitter.Pane defaultSize={50}>First pane</Splitter.Pane>
      <Splitter.Pane defaultSize={50}>Second pane</Splitter.Pane>
    </Splitter>
  );
}
```

## Imperative API

Use `splitterRef` prop to collapse, expand and resize panes programmatically:

```tsx
import { useRef } from 'react';
import { Splitter } from '@mantine/core';
import { UseSplitterReturnValue } from '@mantine/hooks';

function Demo() {
  const splitterRef = useRef<UseSplitterReturnValue>(null);

  return (
    <>
      <button onClick={() => splitterRef.current?.collapse(0)}>
        Collapse first pane
      </button>
      <Splitter splitterRef={splitterRef}>
        <Splitter.Pane defaultSize={50} min={20} collapsible>
          First pane
        </Splitter.Pane>
        <Splitter.Pane defaultSize={50} min={20}>
          Second pane
        </Splitter.Pane>
      </Splitter>
    </>
  );
}
```

## Wrap Splitter.Pane

`Splitter.Pane` must be a direct child of `Splitter`, wrapping it in another component is not supported:

```tsx
import { Splitter } from '@mantine/core';

// This will not work – wrapped pane will not be recognized
function WillNotWork() {
  return (
    <Splitter.Pane defaultSize={50} min={20}>
      This part will not render correctly
    </Splitter.Pane>
  );
}

// Create a separate component for pane content instead
function PaneContent() {
  return <div>This will work as expected!</div>;
}

function Demo() {
  return (
    <Splitter h={200}>
      <Splitter.Pane defaultSize={50} min={20}>
        First pane
      </Splitter.Pane>
      {/* Do not wrap Splitter.Pane in another component */}
      {/* <WillNotWork /> */}
      <Splitter.Pane defaultSize={50} min={20}>
        <PaneContent />
      </Splitter.Pane>
    </Splitter>
  );
}
```

## use-splitter hook

`Splitter` is built on top of the [use-splitter](/hooks/use-splitter/) hook.
Use the hook directly when you need full control over the layout and styling.
