## Deprecation

`Paper` is deprecated in 10.0 and will be removed in 11.0. Use the [Surface](/core/surface)
component instead – it supports all `Paper` props and adds depth-aware background stepping
in dark color scheme. See the [Surface documentation](/core/surface) for migration details.
