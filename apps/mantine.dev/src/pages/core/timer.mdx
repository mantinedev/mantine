## Usage

`Timer` is a stopwatch and countdown that can be started, paused, resumed, reset and restarted.
It does not render playback buttons: add them with [Timer.Control](#custom-layout) or control
the timer with [useTimer](#controlling-the-timer). Set `autoStart` to start the timer on mount:

<Demo data={TimerDemos.usage} />

## Countdown and stopwatch

By default, `Timer` counts up from `startMs`. Set `countdown` prop to count down
from `startMs` to `targetMs` instead. In both modes the timer stops at `targetMs` and calls `onComplete`:

```tsx
import { Timer } from '@mantine/core';

function Demo() {
  return (
    <>
      {/* Stopwatch: counts up from 0 */}
      <Timer autoStart />

      {/* Countdown: counts down from 90 seconds to 0 */}
      <Timer countdown startMs={90 * 1000} autoStart />
    </>
  );
}
```

Changing `startMs` or `countdown` stops the timer and resets it to the new `startMs`.

## useTimer hook

`Timer` supports the [controller pattern](/guides/controllers) with the `useTimer` hook.
It accepts the same options as `Timer` props and returns the timer state and actions:

```tsx
import { useTimer } from '@mantine/core';

function Demo() {
  const controller = useTimer({ countdown: true, startMs: 60 * 1000 });

  controller.getValue(); // -> { totalMs, days, hours, minutes, seconds, milliseconds }
  controller.isRunning(); // -> boolean, true while the timer is counting
  controller.isPaused(); // -> boolean, true when the timer is started and then paused
  controller.getProgress(); // -> number from 0 to 1 when the boundary is set

  controller.start(); // starts from the current value, or from startMs after the timer has completed
  controller.pause();
  controller.resume();
  controller.reset(); // stops and resets the value to startMs
  controller.restart(); // resets and starts again

  return null;
}
```

## Timer.parse

`Timer.parse` (also available as `useTimer.parse`) converts a duration object, `Date` or ISO date
string to milliseconds:

```tsx
import { Timer } from '@mantine/core';

Timer.parse(90 * 1000); // -> 90000
Timer.parse({ minutes: 25 }); // -> 1500000
Timer.parse({ hours: 1, minutes: 30 }); // -> 5400000
Timer.parse('2030-01-01T00:00:00'); // -> milliseconds from now until the date
```

With a `Date` or a date string, the result depends on the current time. Calculate it once,
for example, in a `useState` initializer: a new `startMs` value on every render resets the timer:

<Demo data={TimerDemos.deadline} />

## Timer vs use-countdown

[use-countdown](/hooks/use-countdown) is a display-only countdown hook. Use `Timer` or `useTimer`
when the timer must count up or be paused, resumed and restarted.

## Accessibility

The root element has `role="timer"` and `aria-live="off"`, screen readers do not announce ticks.
Set `aria-live="polite"` to announce value changes, recommended only with `interval` of one second or more.

When `Timer.Control` renders only an icon, set an `aria-label`:

```tsx
import { Timer } from '@mantine/core';

function Demo() {
  return (
    <Timer countdown startMs={60 * 1000}>
      <Timer.Segment type="minutes" />
      <Timer.Separator />
      <Timer.Segment type="seconds" />
      <Timer.Control action="start" aria-label="Start timer">
        ▶
      </Timer.Control>
    </Timer>
  );
}
```
