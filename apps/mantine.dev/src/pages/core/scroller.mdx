## Usage

`Scroller` is a horizontal scroll container with navigation buttons displayed when the content overflows.
Native scrolling with trackpad, shift + mouse wheel and touch gestures keeps working:

<Demo data={ScrollerDemos.usage} />

## Disable drag scrolling

Content can be scrolled by clicking and dragging with the mouse. Dragging that starts on a link or an image moves that element instead. Set `draggable={false}` to disable drag scrolling and allow text selection:

<Demo data={ScrollerDemos.draggable} />

## Scroll amount

Set `scrollAmount` prop to change how many pixels the container scrolls when a navigation button is clicked:

<Demo data={ScrollerDemos.scrollAmount} />

## Control size

Set `controlSize` prop to change the width of the navigation buttons and their edge gradients:

<Demo data={ScrollerDemos.controlSize} />

## Custom icons

Set `startControlIcon` and `endControlIcon` props to replace the default chevron icons:

<Demo data={ScrollerDemos.customIcons} />

## Without controls

Set `withControls={false}` to remove the navigation buttons and the edge gradients, for example,
on touch devices. Native and mouse drag scrolling keep working:

<Demo data={ScrollerDemos.withoutControls} />

## Usage with Tabs

Wrap [Tabs.List](/core/tabs) with `Scroller` to make the tabs list scrollable when tabs do not fit.
Keep `Scroller` outside of `Tabs.List`, so the scroll buttons are not part of the tabs list:

<Demo data={TabsDemos.scroller} />
