## Usage

`Stat` displays a single metric: a label, a formatted value and an optional trend indicator:

<Demo data={StatDemos.usage} />

## Value formatting

Numeric values are formatted with [NumberFormatter](/core/number-formatter) and support the same formatting props.
Numeric strings are formatted the same way, other strings are rendered as is.
Use `prefix` and `suffix` to add units or currency:

<Demo data={StatDemos.formatting} />

To fully control value rendering, pass a `formatter` function.
Formatting props and `animate` are ignored when `formatter` is set:

```tsx
import { Stat } from '@mantine/core';

function Demo() {
  return (
    <Stat
      label="Temperature"
      value={21.5}
      formatter={(value) => `${value} °C`}
    />
  );
}
```

## Trend indicator

Set `diff` prop to display a trend delta below the value. Positive values are green,
negative values are red, zero is dimmed. The delta is formatted as a signed percentage:

<Demo data={StatDemos.diff} />

Use `diffFormatter` to change the delta text and `withDiffIcon={false}` to hide the arrow:

```tsx
import { Stat } from '@mantine/core';

function Demo() {
  return (
    <Stat
      label="New customers"
      value={482}
      diff={38}
      diffFormatter={(diff) => `${diff > 0 ? '+' : ''}${diff} this week`}
    />
  );
}
```

## Countdown

`Stat.Countdown` displays a live countdown to a target time. `value` is a `Date`
or a timestamp in milliseconds, keep it stable between renders: a new value restarts the countdown.

`format` prop accepts dayjs-style tokens:

- Units absent from the format roll into the leading token: `mm:ss` displays 62 minutes as `62:00`
- `S` displays tenths of a second, `SS` hundredths and `SSS` milliseconds
- Literal characters are escaped with square brackets, for example `D[d] HH:mm:ss`

<Demo data={StatDemos.countdown} />

`onFinish` is called once when the target time is reached, `onTick` is called on every
tick with the remaining time in milliseconds:

```tsx
import { useState } from 'react';
import { Stat } from '@mantine/core';

function Demo() {
  const [target] = useState(() => Date.now() + 1000 * 60 * 15);

  return (
    <Stat.Countdown
      label="Offer expires in"
      value={target}
      format="mm:ss"
      onFinish={() => console.log('Countdown finished')}
      onTick={(remainingMs) => console.log(remainingMs)}
    />
  );
}
```

## Size

`size` prop scales the label, value, diff and icon, change it in the configurator above to see the result.

## Color

Set `color` prop to change the value color:

```tsx
import { Stat } from '@mantine/core';

function Demo() {
  return <Stat label="Active users" value={92410} thousandSeparator color="blue" />;
}
```

## Accessibility

- `Stat.Countdown` value is not announced on every tick. To announce milestones,
  render your own live region and update it from `onTick`.
- When `loading` is set, the root element has `aria-busy="true"`.
- `Stat.Diff` renders a visually hidden direction text after the delta, screen readers
  announce `+12.4% increase`. Use `diffLabels` prop to translate these texts:

```tsx
import { Stat } from '@mantine/core';

function Demo() {
  return (
    <Stat
      label="Chiffre d'affaires"
      value={1340}
      diff={12.4}
      diffLabels={{ increase: 'hausse', decrease: 'baisse', neutral: 'stable' }}
    />
  );
}
```
