## Usage

`Stat` displays a single key metric: a label, a formatted value and an optional trend
indicator. Use it to build dashboard stat rows, KPI cards and summary blocks.

<Demo data={StatDemos.usage} />

## Value formatting

Numeric values are formatted with [NumberFormatter](/core/number-formatter), `Stat` supports
the same separator and decimal scale props. Use `prefix` and `suffix` to render units,
currency or icons before and after the value:

<Demo data={StatDemos.formatting} />

Numeric strings (`'1234.5'`) are formatted the same way as numbers. Other strings
(`'12k'`, `'N/A'`) are rendered as is.

To fully control value rendering, pass a `formatter` function. It receives the raw `value`
and returns any React node. Formatting props and `animate` are ignored when `formatter` is set:

```tsx
import { Stat } from '@mantine/core';

function Demo() {
  return (
    <Stat
      label="Temperature"
      value={21.5}
      formatter={(value) => `${value} °C`}
    />
  );
}
```

## Trend indicator

Set `diff` prop to display a trend delta below the value. Positive values are green with
an up arrow, negative values are red with a down arrow, zero is dimmed. By default,
the delta is rounded to at most one decimal and formatted as a signed percentage (`+0.3%`, `-12%`):

<Demo data={StatDemos.diff} />

Use `diffFormatter` to customize the delta text and `withDiffIcon={false}` to hide the arrow:

```tsx
import { Stat } from '@mantine/core';

function Demo() {
  return (
    <Stat
      label="New customers"
      value={482}
      diff={38}
      diffFormatter={(diff) => `${diff > 0 ? '+' : ''}${diff} this week`}
    />
  );
}
```

Values and deltas are never truncated. In narrow containers, use responsive columns
(for example, `SimpleGrid` with `cols={{ base: 1, sm: 3 }}`) instead of a fixed number of columns.

## Countdown

`Stat.Countdown` displays a live countdown to a target time. `value` is a `Date`
or a timestamp in milliseconds. Keep it stable between renders (create it with `useState`
or `useMemo`), a new value restarts the countdown.

<Demo data={StatDemos.countdown} />

`format` prop accepts dayjs-style tokens (`D`, `H`, `m`, `s`, `S`):

- Units absent from the format roll into the leading token: `mm:ss` displays 62 minutes
  as `62:00`
- `S` displays tenths of a second, `SS` hundredths and `SSS` milliseconds
- Literal characters are escaped with square brackets, for example `D[d] HH:mm:ss`
- The remaining time is rounded up: a 3 hour countdown starts at `03:00:00` and
  `00:00:00` is displayed only when it has finished

Note that these rules differ from the `format` of the [Timer](/core/timer) component.

`Stat.Countdown` supports the same display props and Styles API selectors as `Stat`:

```tsx
import { useState } from 'react';
import { Stat } from '@mantine/core';

function Demo() {
  const [target] = useState(() => Date.now() + 1000 * 60 * 15);

  return (
    <Stat.Countdown
      label="Offer expires in"
      value={target}
      format="mm:ss"
      onFinish={() => console.log('Countdown finished')}
      onTick={(remainingMs) => console.log(remainingMs)}
    />
  );
}
```

`onFinish` is called once when the target time is reached, and `onTick` is called on every
tick with the remaining time in milliseconds.

## Size

`size` prop scales the label, value, diff and icon. Change `size` in the configurator
above to see how it scales.

## Color

Set the `color` prop to change the value color. It accepts a value from `theme.colors` or any
valid CSS color:

```tsx
import { Stat } from '@mantine/core';

function Demo() {
  return <Stat label="Active users" value={92410} thousandSeparator color="blue" />;
}
```

## Compound components

For full control over the layout, use compound components instead of the shorthand props:

<Demo data={StatDemos.compound} />

- `Stat.Icon` – icon wrapper, always placed next to the value. Other components are rendered in the order they are declared.
- `Stat.Label` – caption displayed above the value
- `Stat.Value` – value wrapper, accepts `prefix` and `suffix` props
- `Stat.Diff` – trend delta, accepts `value`, `formatter`, `withIcon` and `labels` props (or custom children)

## Accessibility

- `Stat.Countdown` value is not announced on every tick. To announce milestones
  (for example "5 minutes left"), render your own live region and update it from `onTick`.
- When `loading` is set, the root element has `aria-busy="true"`.
- `Stat.Diff` renders a visually hidden direction text after the delta ("increase",
  "decrease" or "no change"), screen readers announce `+12.4% increase`. Use `diffLabels`
  on `Stat` or `labels` on `Stat.Diff` to translate these texts:

```tsx
import { Stat } from '@mantine/core';

function Demo() {
  return (
    <Stat
      label="Chiffre d'affaires"
      value={1340}
      diff={12.4}
      diffLabels={{ increase: 'hausse', decrease: 'baisse', neutral: 'stable' }}
    />
  );
}
```
