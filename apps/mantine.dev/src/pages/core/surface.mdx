## Usage

`Surface` is a container with background, optional shadow, border and border-radius.
Its background color depends on the depth level. `Surface` replaces the deprecated
[Paper](/core/paper) component and supports the same props:

<Demo data={SurfaceDemos.usage} />

## Surface levels

`Surface` has three depth levels, each level uses a surface color token of the [colors system](/theming/colors):

<DataTable
  head={['Level', 'Token', 'Light', 'Dark']}
  data={[
    ['0', <Code>--mantine-color-surface-page</Code>, <Code>white</Code>, <Code>dark-7</Code>],
    ['1', <Code>--mantine-color-surface-panel</Code>, <Code>white</Code>, <Code>dark-6</Code>],
    ['2', <Code>--mantine-color-surface-panel-2</Code>, <Code>white</Code>, <Code>dark-5</Code>],
  ]}
/>

In dark color scheme each level is one shade lighter than the previous one. In light color
scheme all levels are white by default, switch to dark color scheme to see the demos on this page.

## Automatic depth

By default, each `Surface` renders one level above its parent: a standalone `Surface`
has level 1, a `Surface` nested inside it has level 2. Deeper nesting stays at level 2:

<Demo data={SurfaceDemos.autoDepth} />

Set `autoDepth={false}` to render the surface at the same level as its parent:

```tsx
import { Surface } from '@mantine/core';

function Demo() {
  return (
    <Surface p="md">
      Level 1
      <Surface p="md" autoDepth={false}>
        Also level 1 – same background as the parent
      </Surface>
    </Surface>
  );
}
```

## level prop

Set `level` prop to set the depth explicitly. It accepts an absolute value (`0`–`2`)
or a value relative to the parent surface level (`"+1"`, `"-1"`):

<Demo data={SurfaceDemos.level} />

## Styling surfaces by level

The root element has `data-mantine-surface-level` attribute with the resolved level.
Use it to style surfaces depending on the depth, for example, to add a border only to the deepest surfaces:

```css
.surface {
  &[data-mantine-surface-level='2'] {
    border: 1px solid var(--mantine-color-border-subtle);
  }
}
```

## Customize surface colors

Use the `surfaces` key of the theme to change surface colors for each color scheme.
The change applies to all components that use these colors, not only to `Surface`.
Note that `page` is also the background of the page, modals and dropdowns, see the
[colors guide](/theming/colors) for all keys:

```tsx
import { createTheme, MantineProvider } from '@mantine/core';

const theme = createTheme({
  surfaces: {
    dark: {
      panel: '#101113',
      panel2: '#17181c',
    },
  },
});

function Demo() {
  return <MantineProvider theme={theme}>{/* Your app */}</MantineProvider>;
}
```

## Migrating from Paper

[Paper](/core/paper) is deprecated in 10.0 and will be removed in 11.0. `Surface` supports
all `Paper` props, in most cases it is enough to replace the component name:

```tsx
import { Paper, Surface } from '@mantine/core';

// ❌ Deprecated
function Demo() {
  return <Paper shadow="sm" p="md">Content</Paper>;
}

// ✅ Use Surface instead
function Demo() {
  return <Surface shadow="sm" p="md">Content</Surface>;
}
```

In dark color scheme a standalone `Surface` is one shade lighter than `Paper`.
Set `level={0}` to keep the `Paper` appearance:

```tsx
import { Surface } from '@mantine/core';

function Demo() {
  return <Surface level={0} shadow="sm" p="md">Same background as Paper</Surface>;
}
```
