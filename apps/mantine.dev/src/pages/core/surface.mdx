## Usage

`Surface` is a container with background, optional shadow, border and border-radius.
Its background color depends on the depth level. `Surface` replaces the deprecated
[Paper](/core/paper) component and supports the same props:

<Demo data={SurfaceDemos.usage} />

## Surface levels

`Surface` has three depth levels. Each level uses a surface color token
of the [colors system](/theming/colors):

<DataTable
  head={['Level', 'Token', 'Light', 'Dark']}
  data={[
    ['0', <Code>--mantine-color-surface-page</Code>, <Code>white</Code>, <Code>dark-7</Code>],
    ['1', <Code>--mantine-color-surface-panel</Code>, <Code>white</Code>, <Code>dark-6</Code>],
    ['2', <Code>--mantine-color-surface-panel-2</Code>, <Code>white</Code>, <Code>dark-5</Code>],
  ]}
/>

In dark color scheme each level is one shade lighter than the previous one. In light color
scheme all levels are white by default, so the demos on this page are best viewed in dark
color scheme.

## Automatic depth

By default, each `Surface` renders one level above its parent `Surface`: a standalone
`Surface` has level 1, a `Surface` nested inside it has level 2. Deeper nesting stays at level 2.

<Demo data={SurfaceDemos.autoDepth} />

Set `autoDepth={false}` to render the surface at the same level as its parent:

```tsx
import { Surface } from '@mantine/core';

function Demo() {
  return (
    <Surface p="md">
      Level 1
      <Surface p="md" autoDepth={false}>
        Also level 1 – same background as the parent
      </Surface>
    </Surface>
  );
}
```

## level prop

Set `level` prop to control the depth explicitly. It accepts an absolute value (`0`–`2`)
or a value relative to the parent surface level (`"+1"`, `"-1"`). `level` overrides `autoDepth`.

<Demo data={SurfaceDemos.level} />

## Styling surfaces by level

The root element has `data-mantine-surface-level` attribute with the resolved level
(`0`, `1` or `2`). Use it to change styles depending on the depth, for example to add
a border only to the deepest surfaces:

```css
.surface {
  &[data-mantine-surface-level='2'] {
    border: 1px solid var(--mantine-color-border-subtle);
  }
}
```

## Customize surface colors

Use the `surfaces` key of the [theme](/theming/theme-object) to change surface colors
for each color scheme. The change applies to all components that use these colors,
not only to `Surface`:

```tsx
import { createTheme, MantineProvider } from '@mantine/core';

const theme = createTheme({
  surfaces: {
    dark: {
      panel: '#101113',
      panel2: '#17181c',
    },
  },
});

function Demo() {
  return <MantineProvider theme={theme}>{/* Your app */}</MantineProvider>;
}
```

Each color scheme accepts `page`, `panel`, `panel2`, `sunken` and `muted` keys. Note that
`page` is also the background of the page, modals and dropdowns, see the
[colors guide](/theming/colors) for the full list.

## Migrating from Paper

[Paper](/core/paper) is deprecated in 10.0 and will be removed in 11.0. `Surface` supports
all `Paper` props, so in most cases it is enough to replace the component name:

```tsx
import { Paper, Surface } from '@mantine/core';

// ❌ Deprecated
function Demo() {
  return <Paper shadow="sm" p="md">Content</Paper>;
}

// ✅ Use Surface instead
function Demo() {
  return <Surface shadow="sm" p="md">Content</Surface>;
}
```

In light color scheme `Surface` looks the same as `Paper`. In dark color scheme `Paper`
has the body background (level 0), while a standalone `Surface` has level 1 and is one shade
lighter. To keep the `Paper` appearance, set `level={0}`:

```tsx
import { Surface } from '@mantine/core';

function Demo() {
  return <Surface level={0} shadow="sm" p="md">Same background as Paper</Surface>;
}
```
