## Usage

`FileSize` formats a number of bytes into a human-readable file size (`1.45 kB`, `4.8 GB`).
It renders text without a wrapping element:

<Demo data={FileSizeDemos.usage} />

## SI (decimal) and binary units

By default, `FileSize` scales by 1000 and displays `kB`, `MB`, `GB`.
Set `unitSystem="binary"` to scale by 1024 and display `KiB`, `MiB`, `GiB`:

<Demo data={FileSizeDemos.unitSystem} />

## Bytes and bits

Set `unit="bit"` to measure the value in bits instead of bytes, for example to display network speed:

<Demo data={FileSizeDemos.units} />

## Unit display

Set `unitDisplay` to `long` (`1.45 megabytes`) or `narrow` (`1.45MB`) to change how the unit is rendered:

<Demo data={FileSizeDemos.unitDisplay} />

## Locale

Set `locale` to format the number for a specific locale. Always set it when rendering
on the server, the server and client default locales may differ:

<Demo data={FileSizeDemos.locale} />

## Maximum fraction digits

Use `maximumFractionDigits` to limit the number of digits after the decimal point:

```tsx
import { FileSize } from '@mantine/core';

function Demo() {
  return <FileSize value={1_450_500} maximumFractionDigits={0} />; // -> 1 MB
}
```

## formatBytes function

Use `formatBytes` when you need a string instead of a component, for example in `aria-label`:

```tsx
import { formatBytes } from '@mantine/core';

formatBytes(1450); // -> '1.45 kB'
formatBytes(1450, { unitSystem: 'binary' }); // -> '1.42 KiB'
formatBytes(8_000_000, { unit: 'bit' }); // -> '8 Mb'
formatBytes(1450, { locale: 'de-DE' }); // -> '1,45 kB'
```
