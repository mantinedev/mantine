## Usage

`ComboboxPopover` adds a dropdown with options to any element. It does not render an input,
pass your own target to `ComboboxPopover.Target`. The target must be a single element
or a component that accepts `ref`:

<Demo data={ComboboxPopoverDemos.usage} />

## Data format

`ComboboxPopover` supports the same `data` format as [Select](/core/select):

<ComboboxData component="ComboboxPopover" />
