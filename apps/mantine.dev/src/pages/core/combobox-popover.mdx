## Usage

`ComboboxPopover` adds a dropdown with selectable options to any button. Unlike `Select`
and `MultiSelect`, it does not render an input: pass your own target element to
`ComboboxPopover.Target`. The target must be a single element or component that accepts a `ref`.

<Demo data={ComboboxPopoverDemos.usage} />

## Data format

`ComboboxPopover` supports the same `data` format as [Select](/core/select) component:
an array of strings, objects with `value` and `label`, or grouped items.

## Form submission

`ComboboxPopover` renders a hidden input with the selected value for native form submission.
Use `name` prop to set the input name. For multiple selection, values are joined with a comma
by default – use `hiddenInputValuesDivider` to change the separator.
