## Active

Set the `active` prop to add active styles to `NavLink`.

Note that if you're using a React Router `NavLink` inside `renderRoot`, the active styles will be based on the
[`aria-current` attribute that's set by React Router](https://reactrouter.com/en/main/components/nav-link#aria-current),
so you won't need to explicitly set the `active` prop.

You can customize active styles with the `color` and `variant` props:

## Rail variant

`variant="rail"` displays a bar in the `color` at the start of the active link over a neutral
background. It is designed for sidebars in which the active link should read as a position marker
rather than a highlighted button. Links with `rail` variant always have square corners, `radius` prop
is ignored:

<Demo data={NavLinkDemos.rail} />

## Size

`size` prop controls font size, padding, gap between sections and the default offset of nested
links. Icons in `leftSection` and `rightSection` are not scaled automatically, pass an appropriate
`size` prop to the icon. Nested links labels are aligned with the parent link label when the icon
size matches the link size: 14px for `xs`, 16px for `sm`, 18px for `md`, 20px for `lg` and 22px for
`xl`. Icon sizes in the code below change with the selected size:

<Demo data={NavLinkDemos.sizes} />

## Radius

`radius` prop sets `border-radius` of the link, by default `theme.defaultRadius` is used:

## Nested NavLinks

To create nested links, put `NavLink` as children of another `NavLink`. A parent with children
is rendered as a `button` that expands and collapses nested links. By default, nested links
are offset so that their labels align with the parent link label (28px for `size="sm"`). Use
`childrenOffset` prop to change the offset:

<Demo data={NavLinkDemos.nested} />

## Guideline
