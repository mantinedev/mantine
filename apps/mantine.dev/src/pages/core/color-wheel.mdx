## Usage

`ColorWheel` is a circular hue selector. Its value is a hue in degrees, from `0` at the top (red)
increasing clockwise to `360`:

<Demo data={ColorWheelDemos.usage} />

## Controlled

Convert the value to a color with `hsl(hue, 100%, 50%)` or any color conversion function:

<Demo data={ColorWheelDemos.controlled} />

## Ring colors

Use `saturation` and `lightness` props (0 to 100) to change the ring colors.
They change only the appearance, the value is always the hue:

<Demo data={ColorWheelDemos.ringColors} />

## Size and thickness

Use `size` prop to change the outer diameter of the wheel and `thickness` to change the ring width.
The thumb size is based on `thickness`, override it with `thumbSize`:

```tsx
import { ColorWheel } from '@mantine/core';

function Demo() {
  return <ColorWheel size={220} thickness={40} thumbSize={20} />;
}
```

## onChangeEnd

`onChangeEnd` is called when the user stops dragging the wheel or changes the value with the keyboard.
Use it as a debounced callback to avoid too frequent updates:

<Demo data={ColorWheelDemos.onChangeEnd} />

## Without thumb indicator

Set `withThumbIndicator={false}` to hide the thumb, the wheel stays interactive:

```tsx
import { ColorWheel } from '@mantine/core';

function Demo() {
  return <ColorWheel withThumbIndicator={false} />;
}
```

## ColorWheel with uncontrolled forms

Set `name` prop to include the hue value in the `FormData` object on form submission
and `defaultValue` to set the initial value:

```tsx
import { ColorWheel } from '@mantine/core';

function Demo() {
  return (
    <form
      onSubmit={(event) => {
        event.preventDefault();
        const formData = new FormData(event.currentTarget);
        console.log('Hue value:', formData.get('hue'));
      }}
    >
      <ColorWheel name="hue" defaultValue={120} />
      <button type="submit">Submit</button>
    </form>
  );
}
```

## Accessibility

Set `aria-label` to make the wheel accessible for screen readers:

```tsx
import { ColorWheel } from '@mantine/core';

function Demo() {
  return <ColorWheel aria-label="Hue" />;
}
```
