## Usage

`ColorWheel` is a circular hue selector. Its value is a hue in degrees (a number between 0 and 360).
Drag the thumb around the ring or use the keyboard to change the value:

<Demo data={ColorWheelDemos.usage} />

## Controlled

`ColorWheel` value is a number between 0 and 360 that represents the hue.
Convert it to a color with the `hsl(hue, 100%, 50%)` syntax or with any color conversion function:

<Demo data={ColorWheelDemos.controlled} />

The value starts at the top of the ring (`0°` is red) and increases clockwise:
`90°` is on the right, `180°` at the bottom, `270°` on the left.

## Ring colors

By default, the ring is rendered with fully saturated colors at 50% lightness. Use the
`saturation` and `lightness` props (both are numbers between 0 and 100) to change how the
ring colors are rendered. This only affects the appearance of the ring and the thumb – the
value is always the hue in degrees:

<Demo data={ColorWheelDemos.ringColors} />

## Size and thickness

Use the `size` prop to change the outer diameter of the wheel and the `thickness` prop to
change the ring width in px. The thumb size is calculated based on the `thickness` value,
you can override it with the `thumbSize` prop.

```tsx
import { ColorWheel } from '@mantine/core';

function Demo() {
  return <ColorWheel size={220} thickness={40} thumbSize={20} />;
}
```

## onChangeEnd

The `onChangeEnd` callback fires when the user stops dragging the wheel or changes its value
with the keyboard. Use it as a debounced callback to prevent frequent updates:

<Demo data={ColorWheelDemos.onChangeEnd} />

## Without thumb indicator

Set `withThumbIndicator={false}` to hide the thumb. The component stays interactive and
keyboard accessible:

```tsx
import { ColorWheel } from '@mantine/core';

function Demo() {
  return <ColorWheel withThumbIndicator={false} />;
}
```

## ColorWheel with uncontrolled forms

`ColorWheel` can be used with uncontrolled forms.
Set the `name` attribute to include the hue value in the `FormData` object on form submission.
To control the initial value in uncontrolled forms, use the `defaultValue` prop.

Props for usage with uncontrolled forms:
- `name` – name attribute passed to the hidden input
- `hiddenInputProps` – additional props passed to the hidden input

```tsx
import { ColorWheel } from '@mantine/core';

function Demo() {
  return (
    <form
      onSubmit={(event) => {
        event.preventDefault();
        const formData = new FormData(event.currentTarget);
        console.log('Hue value:', formData.get('hue'));
      }}
    >
      <ColorWheel name="hue" defaultValue={120} />
      <button type="submit">Submit</button>
    </form>
  );
}
```

## Accessibility

To make the component accessible for screen readers, set the `aria-label` prop:

```tsx
import { ColorWheel } from '@mantine/core';

function Demo() {
  return <ColorWheel aria-label="Hue" />;
}
```

selector using this hook if you need more control over the component's behavior.
