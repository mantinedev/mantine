## Usage

`EmptyState` displays a placeholder when there is nothing to show: empty search results,
empty tables, first-run states. Set `icon`, `title` and `description` props:

<Demo data={EmptyStateDemos.usage} />

## Compound components

For full control over the content, use compound components instead of the shorthand props:

<Demo data={EmptyStateDemos.compound} />

Both can be combined, `children` are rendered after the content from the props:

```tsx
import { Button, EmptyState } from '@mantine/core';

function Demo() {
  return (
    <EmptyState icon={<Icon />} title="No results found">
      {/* Rendered after the title */}
      <EmptyState.Actions>
        <Button variant="default">Reset filters</Button>
      </EmptyState.Actions>
    </EmptyState>
  );
}
```

## Variant

Set `variant` to `filled` or `light` to display the icon inside a colored circle,
use `color` to change its color:

<Demo data={EmptyStateDemos.variant} />

## Indicator background

Set `withIndicatorBackground` to display a neutral circle behind the icon without a `variant`:

<Demo data={EmptyStateDemos.indicatorBackground} />

## Title heading level

`EmptyState.Title` renders a `div` by default. Set `order` to render it as a heading:

```tsx
import { EmptyState } from '@mantine/core';

function Demo() {
  return (
    <EmptyState>
      <EmptyState.Title order={2}>No results found</EmptyState.Title>
    </EmptyState>
  );
}
```

## Accessibility

- `EmptyState.Title` is not a heading by default, set the `order` prop to change that
- Make sure that action buttons have accessible labels
