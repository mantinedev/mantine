## Usage

`Toolbar` is a group of toggle buttons with `role="toolbar"` and arrow keys navigation.
`Toolbar.Toggle` is stateless: pass `active` and update it in `onClick`, or use `Toolbar.ToggleGroup`
to manage a set of toggles. For a toggle that manages its own state, use [Toggle](/core/toggle/):

<Demo data={ToolbarDemos.usage} />

## Toggle groups

Use `Toolbar.ToggleGroup` with `Toolbar.ToggleItem` to create groups of toggle buttons.
Set `type="single"` to allow one active item at a time or `type="multiple"` to allow several.
With `type="single"`, clicking the active item deselects it and the value becomes `null`:

<Demo data={ToolbarDemos.toggleGroup} />

## Size, orientation, variant and color

`size` prop sets the size of all toggles, padding and gap. Set `orientation="vertical"`
to render a vertical toolbar. `variant` and `color` props change the appearance of active toggles:

<Demo data={ToolbarDemos.configurator} />

## Auto contrast

`Toolbar` adjusts the icon color to the active toggle background color, for example, with light colors
and `variant="filled"`. The behavior is controlled by [theme.autoContrast](/theming/theme-object/#autocontrast),
set `autoContrast={false}` to disable it for a single toolbar:

<Demo data={ToolbarDemos.autoContrast} />

## Auto width

By default, toggles are square buttons. Set `autoWidth` prop on `Toolbar.Toggle` or `Toolbar.ToggleItem`
to fit the width to the content, for example, a text label:

<Demo data={ToolbarDemos.autoWidth} />

## Disabled state

Set `disabled` prop on individual `Toolbar.ToggleItem` components, or on
`Toolbar.ToggleGroup` to disable all items in the group.
When `Toolbar.Toggle` is rendered as a non-button element, for example, `component="a"`, the `disabled` prop
sets `aria-disabled`, removes the element from the tab order and prevents clicks:

<Demo data={ToolbarDemos.disabled} />

## Accessibility

- `Toolbar` has `role="toolbar"` and `aria-orientation` that matches the `orientation` prop
- `Toolbar.ToggleItem` always has `aria-pressed` attribute. `Toolbar.Toggle` has it only when the `active` prop is passed, without it `Toolbar.Toggle` is a regular button
- Set `aria-label` on icon-only toggles

## Keyboard interactions

Toggles share a single tab stop, arrow keys move focus between them.
Other interactive children, for example, `ActionIcon` or `Button`, remain separate tab stops.
