## Usage

`Toolbar` is an accessible compound component that provides `role="toolbar"` with roving tabindex
keyboard navigation. It contains toggle buttons, toggle groups, dividers, and visual grouping.
`Toolbar.Toggle` is a polymorphic component – it can be rendered as any element, for example
as `a` tag for links.

<Demo data={ToolbarDemos.usage} />

## Toggle groups

Use `Toolbar.ToggleGroup` with `Toolbar.ToggleItem` to create groups of toggle buttons.
Set `type="single"` for radio-like behavior (one active at a time) or `type="multiple"` for
checkbox-like behavior (multiple active). Both modes support controlled and uncontrolled state.
With `type="single"`, clicking the active item deselects it — the value is `string | null`
where `null` means no selection.

<Demo data={ToolbarDemos.toggleGroup} />

## Size, orientation, variant and color

The `size` prop controls the size of all toggle components, padding, and gap.
Set `orientation="vertical"` to render a vertical toolbar — this changes layout direction,
divider orientation, group border merging, and keyboard navigation. `variant` and `color`
props control the appearance of active toggle buttons.

<Demo data={ToolbarDemos.configurator} />

## Auto contrast

Set `autoContrast` prop to automatically adjust icon color based on the active toggle
background color. This is useful when using `variant="filled"` with light colors.

<Demo data={ToolbarDemos.autoContrast} />

## Auto width

By default, `Toolbar.Toggle` renders as a square button. Set `autoWidth` prop to allow
the toggle width to adjust to its content — useful for text labels.

<Demo data={ToolbarDemos.autoWidth} />

## Disabled state

Set `disabled` prop on individual `Toolbar.ToggleItem` components, or on
`Toolbar.ToggleGroup` to disable all items within the group.

When `Toolbar.Toggle` is rendered as a non-button element (for example, `component="a"`), the `disabled` prop sets `aria-disabled`, removes the element from the tab order and prevents `onClick` from being called, since such elements do not support the native `disabled` attribute.

## Accessibility

`Toolbar` renders `role="toolbar"` with `aria-orientation` set based on the `orientation` prop. `Toolbar.ToggleItem` always exposes `aria-pressed` state. `Toolbar.Toggle` exposes `aria-pressed` only when the `active` prop is passed – without it, `Toolbar.Toggle` is a regular button (for example, an action or a link) and does not announce a pressed state. `Toolbar.Divider` renders `role="separator"` with `aria-orientation` matching the drawn line. When using icon-only toggles, always provide an `aria-label` prop so that screen readers can announce the button purpose.

## Keyboard interactions

Arrow keys, `Home` and `End` move focus only between `Toolbar.Toggle` and `Toolbar.ToggleItem` components – they share a single tab stop (roving tabindex). Other interactive children, for example `ActionIcon`, `Button`, `Menu.Target` or a standalone `Toggle`, are not part of the arrow key navigation and remain separate tab stops.
