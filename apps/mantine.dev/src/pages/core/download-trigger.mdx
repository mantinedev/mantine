## Usage

`DownloadTrigger` downloads generated content (CSV, JSON, images, QR codes) as a file
without a server request. It does not render any element – its children is a function
that receives an object with the following properties:

- `download` – function that must be called to trigger the download
- `loading` – `true` while an async `data` function is resolving

<Demo data={DownloadTriggerDemos.usage} />

`data` can be a string, a `Blob` or a `File`. Set `mimeType` prop when `data` is a string.
Use `fileName` prop to set the name of the downloaded file. When `fileName` is not set
and `data` is a `File`, the file name is used.

`onDownloadComplete` is called when the download is dispatched to the browser, not when the browser
finishes saving the file.

## Async data

`data` can be a function that returns a `Blob`/string or a promise that resolves with one.
The function is called when the download is triggered. While it is resolving, `loading`
is `true` and repeated `download` calls are ignored:

<Demo data={DownloadTriggerDemos.async} />

## Error handling

If resolving `data` or the download fails, the error is passed to `onError` callback.
If `onError` is not set, the error is rethrown:

<Demo data={DownloadTriggerDemos.error} />

## Custom trigger

Children can return any element – a [Button](/core/button), an [ActionIcon](/core/action-icon), a
[Menu.Item](/core/menu) or your own component. Call the `download` function from the element `onClick`
handler:

<Demo data={DownloadTriggerDemos.customTrigger} />

## Accessibility

When the trigger is icon-only, set `aria-label` to describe the action:

```tsx
import { ActionIcon, DownloadTrigger } from '@mantine/core';

function Demo() {
  return (
    <DownloadTrigger data="data" fileName="file.txt">
      {({ download }) => (
        <ActionIcon aria-label="Download file" onClick={download}>
          ⬇
        </ActionIcon>
      )}
    </DownloadTrigger>
  );
}
```
