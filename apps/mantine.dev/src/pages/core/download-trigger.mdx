## Usage

`DownloadTrigger` downloads generated content (CSV, JSON, images) as a file without a server request.
It does not render any element, its `children` is a function that receives:

- `download` – function that starts the download
- `loading` – `true` while an async `data` function is resolving

`data` can be a string, a `Blob` or a `File`. Set `mimeType` prop when `data` is a string:

<Demo data={DownloadTriggerDemos.usage} />

## Async data

`data` can be a function that returns the content or a promise that resolves with it.
While it is resolving, `loading` is `true` and repeated `download` calls are ignored:

<Demo data={DownloadTriggerDemos.async} />

## Error handling

If resolving `data` or the download fails, the error is passed to `onError`.
Without `onError`, the error is rethrown:

<Demo data={DownloadTriggerDemos.error} />

## Custom trigger

Children can return any element: a button, an action icon, a menu item or your own component.
Call `download` from its `onClick` handler:

<Demo data={DownloadTriggerDemos.customTrigger} />

## Accessibility

When the trigger is icon-only, set `aria-label` to describe the action:

```tsx
import { ActionIcon, DownloadTrigger } from '@mantine/core';

function Demo() {
  return (
    <DownloadTrigger data="data" fileName="file.txt">
      {({ download }) => (
        <ActionIcon aria-label="Download file" onClick={download}>
          ⬇
        </ActionIcon>
      )}
    </DownloadTrigger>
  );
}
```
