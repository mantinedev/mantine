## Usage

`QRCode` encodes a string into a QR code and renders it as an SVG. It has no external
dependencies and works with server-side rendering:

<Demo data={QRCodeDemos.usage} />

## Size

Set `size` prop to change the width and height of the code:

## Colors

Use `color` prop to change the color of the dark modules and
[bg style prop](/styles/style-props) to change the background color.
Keep a high contrast between the two colors so that the code stays scannable:

<Demo data={QRCodeDemos.colors} />

## Error correction level

`errorCorrectionLevel` prop controls how much of the code can be damaged or covered
while remaining readable, from `L` (about 7%) to `H` (about 30%). Higher levels produce
a denser code:

<Demo data={QRCodeDemos.errorCorrection} />

## Capacity

A QR code holds from about 1270 bytes with `errorCorrectionLevel="H"` to about 2950 bytes
with `"L"`. When the value is longer, `QRCode` renders an empty code. Use `encodeQR` to
validate user input, it throws when the value does not fit:

```tsx
import { encodeQR } from '@mantine/core';

function canEncode(value: string) {
  try {
    encodeQR(value, { errorCorrectionLevel: 'H' });
    return true;
  } catch {
    return false;
  }
}
```

## Logo

Pass any React node to the `logo` prop to display it in the center of the code.
The logo covers a part of the code, set `errorCorrectionLevel="H"` to keep it scannable:

<Demo data={QRCodeDemos.logo} />

## Custom rendering with encodeQR

To fully control the appearance, for example to render rounded dots or export to canvas,
use `encodeQR` function to get the module matrix and render it yourself:

```tsx
import { encodeQR } from '@mantine/core';

const { matrix, size } = encodeQR('https://mantine.dev', { errorCorrectionLevel: 'M' });
// matrix – boolean[][], `true` for dark modules
// size – number of modules per side (without the quiet zone)
```

The three large squares in the corners and the alignment patterns must stay solid squares,
other modules can have any shape:

<Demo data={QRCodeDemos.customRender} />

## Accessibility

By default, `aria-label` of the code is the encoded `value`. Set `aria-label`
or `aria-labelledby` prop to provide a more descriptive name:

```tsx
import { QRCode } from '@mantine/core';

function Demo() {
  return <QRCode value="https://mantine.dev" aria-label="Link to mantine.dev" />;
}
```

To hide a decorative code that is duplicated by nearby text, use `attributes` prop
of the [Styles API](/styles/styles-api):

```tsx
import { QRCode } from '@mantine/core';

function Demo() {
  return (
    <QRCode
      value="https://mantine.dev"
      attributes={{ svg: { 'aria-hidden': true } }}
    />
  );
}
```
