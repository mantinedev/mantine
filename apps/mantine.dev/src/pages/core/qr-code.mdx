## Usage

`QRCode` encodes a string into a QR code and renders it as an SVG. The encoder is
bundled with the component: no additional dependencies or network requests are
required, and the component works with server-side rendering:

<Demo data={QRCodeDemos.usage} />

## Size

Set `size` prop to control the width and height of the code. Numbers are
converted to rem, strings are used as is:

## Colors

Use `color` prop to change the color of the dark modules and
[bg style prop](/styles/style-props) to change the background color.
Keep a high contrast between the two colors so that the code stays scannable:

## Error correction level

`errorCorrectionLevel` prop controls how much of the code can be damaged or
covered while remaining readable. Higher levels produce a denser code:

- `L` – recovers up to ~7% of data
- `M` – recovers up to ~15% of data (default)
- `Q` – recovers up to ~25% of data
- `H` – recovers up to ~30% of data

<Demo data={QRCodeDemos.errorCorrection} />

## Capacity

The amount of data a QR code can hold depends on the error correction level.
The limits below are for text encoded as UTF-8 bytes, non-ASCII characters take 2–4 bytes each:

- `L` – about 2953 bytes
- `M` – about 2331 bytes
- `Q` – about 1663 bytes
- `H` – about 1273 bytes

When the value is longer than the capacity, `QRCode` renders an empty code.
`encodeQR` throws a `RangeError` in this case, use it to validate user input:

```tsx
import { encodeQR } from '@mantine/core';

function canEncode(value: string) {
  try {
    encodeQR(value, { errorCorrectionLevel: 'H' });
    return true;
  } catch {
    return false;
  }
}
```

## Custom rendering with encodeQR

To fully control the appearance (rounded dots, gradients, canvas export, etc.), use
`encodeQR` function to get the module matrix and render it yourself:

```tsx
import { encodeQR } from '@mantine/core';

const { matrix, size } = encodeQR('https://mantine.dev', { errorCorrectionLevel: 'M' });
// matrix – boolean[][], `true` for dark modules
// size – number of modules per side (without the quiet zone)
```

Finder patterns (the three large squares in the corners) and alignment patterns must
stay solid squares so that scanners can locate the code. Other modules can have any shape:

## Accessibility

By default, `aria-label` of the code is the encoded `value`. Set `aria-label`
or `aria-labelledby` prop to provide a more descriptive name:

```tsx
import { QRCode } from '@mantine/core';

function Demo() {
  return <QRCode value="https://mantine.dev" aria-label="Link to mantine.dev" />;
}
```

To hide a decorative code that is duplicated by nearby text, use `attributes` prop
of the [Styles API](/styles/styles-api):

```tsx
import { QRCode } from '@mantine/core';

function Demo() {
  return (
    <QRCode
      value="https://mantine.dev"
      attributes={{ svg: { 'aria-hidden': true } }}
    />
  );
}
```
