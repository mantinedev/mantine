## Usage

`ImageCropper` lets users pan, zoom, rotate and flip an image behind a fixed crop window.
Drag the image to pan and use the mouse wheel to zoom:

<Demo data={ImageCropperDemos.usage} />

## Interactions

- **Pan** – drag the image or focus the viewport and use the arrow keys
- **Zoom** – scroll the mouse wheel over the viewport, press `+`/`-` while the viewport is
  focused or use the zoom slider. Zoom is limited by `minZoom` (`1` by default) and
  `maxZoom` (`5` by default).
- **Rotate and flip** – use the default controls or the controller actions. When rotation
  changes, the crop window is refitted to the rotated image.

The image always covers the crop window while it is panned and zoomed.

Set `withControls` to display the zoom slider and rotate, flip and reset buttons
under the viewport. Pinch-to-zoom is not supported, see [Limitations](#limitations).

## Aspect ratio

Set `aspectRatio` to control the shape of the crop window, for example `1` for a square or
`16 / 9` for a widescreen crop. When `aspectRatio` is not set, the crop window matches the viewport
aspect ratio:

<Demo data={ImageCropperDemos.aspectRatio} />

## Circle crop

Set `cropShape="circle"` to display a circular crop window, for example for avatars.
The crop is always square and the exported image has a circular mask:

<Demo data={ImageCropperDemos.circle} />

## Rule-of-thirds grid

Set `withGrid` to display a rule-of-thirds grid over the crop window:

```tsx
import { ImageCropper } from '@mantine/core';

function Demo() {
  return <ImageCropper src="/image.png" withGrid />;
}
```

## useImageCropper hook

`ImageCropper` supports the [controller pattern](/guides/controllers). Pass the `useImageCropper`
return value to the `controller` prop to control the cropper from outside. The hook accepts the same
zoom, rotation, flip, crop shape and aspect ratio options as the [props](/core/image-cropper?t=props).
When `controller` is set, those props are ignored.

<Demo data={ImageCropperDemos.controller} />

```tsx
import { useImageCropper } from '@mantine/core';

function Demo() {
  const controller = useImageCropper({ cropShape: 'circle', maxZoom: 4 });

  controller.zoom; // -> number, current zoom
  controller.rotation; // -> number, current rotation in degrees
  controller.flip; // -> { horizontal: boolean, vertical: boolean }
  controller.crop; // -> { x, y }, pan offset in viewport pixels relative to the center
  controller.cropSize; // -> { width, height } of the crop window in viewport pixels, or null

  controller.setZoom(2); // clamped to minZoom/maxZoom
  controller.zoomBy(0.5);
  controller.setRotation(90);
  controller.rotateBy(-90);
  controller.flipHorizontal();
  controller.flipVertical();
  controller.setCrop({ x: 20, y: 0 }); // constrained to keep the crop window covered
  controller.reset(); // zoom, rotation, flip and pan back to their initial values

  controller.getCropData(); // -> ImageCropperArea in natural source pixels, or null
  controller.getCroppedImage({ type: 'image/png' }); // -> Promise<Blob | string>

  return null;
}
```

The controller exposes the following actions and queries:

- `getZoom()`, `getRotation()`, `getFlip()`, `getCrop()` – current zoom, rotation, flip and crop position
- `getCropSize()` – size of the crop window, `null` until the image and viewport are measured
- `setZoom(value)` / `zoomBy(delta)` – set or change zoom, clamped to `minZoom`/`maxZoom`
- `setRotation(degrees)` / `rotateBy(delta)` – set or change rotation
- `flipHorizontal()` / `flipVertical()` – toggle mirroring on each axis
- `reset()` – reset zoom, rotation, flip and crop position to their initial values
- `getCropData()` – get the current crop rectangle in natural source pixels
- `getCroppedImage(options)` – rasterize and return the cropped image

`getCropData()` returns the crop rectangle in pixels of the source image as
`{ x, y, width, height, rotation }`, or `null` while no image is loaded.
`onCropChange` callback is called with `{ pixels, percent }`: the same rectangle
in pixels and in percentages (0–100) of the source image. To render the crop data,
store the value from `onCropChange` in state.

## Controlled state

Zoom, rotation and flip can be controlled or uncontrolled, both on `ImageCropper` and in
`useImageCropper`:

- `zoom` / `defaultZoom` / `onZoomChange` – zoom value, `1` by default
- `rotation` / `defaultRotation` / `onRotationChange` – rotation in degrees, `0` by default
- `flip` / `defaultFlip` / `onFlipChange` – `{ horizontal, vertical }` mirroring, not flipped by default

```tsx
import { useState } from 'react';
import { ImageCropper } from '@mantine/core';

function Demo() {
  const [zoom, setZoom] = useState(1.5);
  const [rotation, setRotation] = useState(0);

  return (
    <ImageCropper
      src="/image.png"
      zoom={zoom}
      onZoomChange={setZoom}
      rotation={rotation}
      onRotationChange={setRotation}
      defaultFlip={{ horizontal: true }}
      withControls
    />
  );
}
```

`reset()` and the reset button of the default controls restore the initial (`default*`) values.
The pan position is not a controlled prop – set it with the controller `setCrop` action.

## Exporting the crop

`getCroppedImage` draws the current crop (including rotation and flip) to a canvas and returns a
promise that resolves with a `Blob` (default) or a data URL. Use `type`, `quality` and `output`
options to change the result format:

<Demo data={ImageCropperDemos.exportImage} />

```tsx
const blob = await controller.getCroppedImage({ type: 'image/jpeg', quality: 0.9 });
const dataURL = await controller.getCroppedImage({ output: 'dataURL' });
```

The promise is rejected when no image is loaded and when the canvas cannot be exported.

To export a remote image, the image host must send permissive CORS headers and the
`crossOrigin="anonymous"` prop must be set on `ImageCropper`. Otherwise `getCroppedImage` rejects.
Images loaded from object URLs or data URLs (for example from `@mantine/dropzone` or a file
input) do not require any extra configuration.

With `cropShape="circle"`, the area outside the circle is transparent. Use `'image/png'`
(default) or `'image/webp'` – with `'image/jpeg'` the corners are filled with an opaque color.

## Server-side cropping

If you crop the image on the server, use `getCropData()` or the `onCropChange` callback to get the
crop rectangle instead of exporting the image on the client. `onCropChange` is called with the
[crop data](#useimagecropper-hook) every time the crop rectangle changes.

```tsx
import { ImageCropper } from '@mantine/core';

function Demo() {
  return (
    <ImageCropper
      src="/image.png"
      onCropChange={({ pixels, percent }) => console.log(pixels, percent)}
    />
  );
}
```

The crop rectangle is measured in the **rotated** image: `x`, `y`, `width` and `height` refer to the
bounding box of the natural image after `rotation` is applied. Flip is not part of the crop data
and does not trigger `onCropChange`. To reproduce the crop on the server:

1. Apply the flip (`controller.flip` or the value from `onFlipChange`) to the natural image.
2. Rotate the flipped image by `pixels.rotation` degrees, expanding the canvas to the rotated
   bounding box.
3. Extract the `pixels` rectangle from the result.

## Custom layout

Pass compound components as children to change the layout, for example to render the
controls above the viewport:

<Demo data={ImageCropperDemos.customLayout} />

- `ImageCropper.Viewport` – the crop viewport, handles pan, zoom and keyboard interactions
- `ImageCropper.Image` – the image element
- `ImageCropper.Controls` – the default controls. Pass custom children to replace them.

## Disabled state

Set `disabled` to make the cropper non-interactive, for example to display a preview
of a saved crop. The default controls are disabled as well.

## Changing the image

When `src` changes to a different image, zoom, rotation, flip and the pan position are reset
to their initial values. The state is kept when the cropper is remounted with the same `src`
and a controller created outside of it, for example in a `Modal` or a `Tabs` panel.

## Pairing with Dropzone

`ImageCropper` does not include a file input. Use [Dropzone](/x/dropzone/) or a native file
input to let users pick an image, create an object URL with `URL.createObjectURL(file)` and
pass it to `src`:

```tsx
import { useEffect, useState } from 'react';
import { Button, ImageCropper, useImageCropper } from '@mantine/core';
import { Dropzone, IMAGE_MIME_TYPE } from '@mantine/dropzone';

function Demo() {
  const controller = useImageCropper({ aspectRatio: 1 });
  const [src, setSrc] = useState<string | null>(null);

  useEffect(
    () => () => {
      if (src) {
        URL.revokeObjectURL(src);
      }
    },
    [src]
  );

  const upload = async () => {
    const blob = await controller.getCroppedImage({ type: 'image/webp', quality: 0.9 });
    // upload blob to your server
  };

  return (
    <>
      <Dropzone accept={IMAGE_MIME_TYPE} onDrop={(files) => setSrc(URL.createObjectURL(files[0]))}>
        Drop an image here
      </Dropzone>

      {src && (
        <>
          <ImageCropper src={src} controller={controller} withControls />
          <Button onClick={upload}>Upload</Button>
        </>
      )}
    </>
  );
}
```

## Accessibility

The viewport is a focusable `group` with the accessible name `Image cropper` – override it with
`aria-label` on `ImageCropper.Viewport` in a custom layout. It supports keyboard interactions:

- `ArrowLeft`, `ArrowRight`, `ArrowUp`, `ArrowDown` – move the image in the arrow direction by 10px (50px with `Shift`)
- `+` or `=` – zoom in by `zoomStep`
- `-` – zoom out by `zoomStep`

The default controls have English labels. To localize them, render your own controls
with `ImageCropper.Controls` children or a `useImageCropper` controller.

## Limitations

- **No pinch-to-zoom.** Touch input supports single-finger panning only. On touch devices, provide
  zoom with `withControls` or your own buttons connected to a `useImageCropper` controller.
- **Rotated images at arbitrary angles.** At angles that are not multiples of 90° (for example 45°),
  the crop window corners can show empty areas – zoom in to cover them.
