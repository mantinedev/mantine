## Usage

`ImageCropper` lets users pan, zoom, rotate and flip an image behind a fixed crop window.
Drag the image to pan and use the mouse wheel to zoom:

<Demo data={ImageCropperDemos.usage} />

## Interactions

- **Pan** – drag the image or focus the viewport and use the arrow keys
- **Zoom** – scroll the mouse wheel over the viewport, press `+`/`-` while the viewport is
  focused or use the zoom slider. Zoom is limited by `minZoom` and `maxZoom` props.
- **Rotate and flip** – use the default controls or the controller actions

Set `withControls` to display the zoom slider and rotate, flip and reset buttons
under the viewport. Pinch-to-zoom is not supported, see [Limitations](#limitations).

## Aspect ratio

Set `aspectRatio` to control the shape of the crop window, for example `1` for a square or
`16 / 9` for a widescreen crop. When `aspectRatio` is not set, the crop window matches the viewport
aspect ratio:

<Demo data={ImageCropperDemos.aspectRatio} />

## Circle crop

Set `cropShape="circle"` to display a circular crop window, for example for avatars.
The crop is always square and the exported image has a circular mask:

<Demo data={ImageCropperDemos.circle} />

## Rule-of-thirds grid

Set `withGrid` to display a rule-of-thirds grid over the crop window:

```tsx
import { ImageCropper } from '@mantine/core';

function Demo() {
  return <ImageCropper src="/image.png" withGrid />;
}
```

## useImageCropper hook

`ImageCropper` supports the [controller pattern](/guides/controllers). Use the `useImageCropper`
hook to control the cropper from outside. The hook accepts the zoom, rotation, flip, crop shape
and aspect ratio options, when `controller` is set, the same props of `ImageCropper` are ignored:

<Demo data={ImageCropperDemos.controller} />

```tsx
import { useImageCropper } from '@mantine/core';

function Demo() {
  const controller = useImageCropper({ cropShape: 'circle', maxZoom: 4 });

  controller.zoom; // -> number, current zoom
  controller.rotation; // -> number, current rotation in degrees
  controller.flip; // -> { horizontal: boolean, vertical: boolean }
  controller.crop; // -> { x, y }, pan offset in viewport pixels relative to the center
  controller.cropSize; // -> { width, height } of the crop window in viewport pixels, or null

  controller.setZoom(2); // clamped to minZoom/maxZoom
  controller.zoomBy(0.5);
  controller.setRotation(90);
  controller.rotateBy(-90);
  controller.flipHorizontal();
  controller.flipVertical();
  controller.setCrop({ x: 20, y: 0 }); // constrained to keep the crop window covered
  controller.reset(); // zoom, rotation, flip and pan back to their initial values

  controller.getCropData(); // -> ImageCropperArea in natural source pixels, or null
  controller.getCroppedImage({ type: 'image/png' }); // -> Promise<Blob | string>

  return null;
}
```

## Controlled state

Zoom, rotation and flip can be controlled or uncontrolled with `value`, `defaultValue` and
`onChange` style props, both on `ImageCropper` and in `useImageCropper`:

```tsx
import { useState } from 'react';
import { ImageCropper } from '@mantine/core';

function Demo() {
  const [zoom, setZoom] = useState(1.5);
  const [rotation, setRotation] = useState(0);

  return (
    <ImageCropper
      src="/image.png"
      zoom={zoom}
      onZoomChange={setZoom}
      rotation={rotation}
      onRotationChange={setRotation}
      defaultFlip={{ horizontal: true }}
      withControls
    />
  );
}
```

The pan position cannot be controlled with props, set it with the controller `setCrop` action.

## Exporting the crop

`getCroppedImage` returns a promise that resolves with the cropped image as a `Blob` or a data URL.
Use `type`, `quality` and `output` options to change the result format:

<Demo data={ImageCropperDemos.exportImage} />

```tsx
const blob = await controller.getCroppedImage({ type: 'image/jpeg', quality: 0.9 });
const dataURL = await controller.getCroppedImage({ output: 'dataURL' });
```

To export a remote image, set `crossOrigin="anonymous"` on `ImageCropper` and make sure the
image host sends permissive CORS headers, otherwise the promise is rejected. Object URLs and
data URLs, for example from a file input, do not need extra configuration.

With `cropShape="circle"`, the area outside the circle is transparent. Use `image/png` or
`image/webp` type, with `image/jpeg` the corners are filled with an opaque color.

## Server-side cropping

If you crop the image on the server, use `getCropData()` or the `onCropChange` callback instead
of exporting the image on the client. Both provide the crop rectangle in pixels of the source image
as `{ x, y, width, height, rotation }`, `onCropChange` also receives it in percentages:

```tsx
import { ImageCropper } from '@mantine/core';

function Demo() {
  return (
    <ImageCropper
      src="/image.png"
      onCropChange={({ pixels, percent }) => console.log(pixels, percent)}
    />
  );
}
```

The rectangle is measured in the rotated image. Flip is not part of the crop data, get it from
`controller.flip` or `onFlipChange`. To reproduce the crop on the server:

1. Apply the flip to the source image.
2. Rotate the flipped image by `pixels.rotation` degrees, expanding the canvas to the rotated
   bounding box.
3. Extract the `pixels` rectangle from the result.

## Custom layout

Use `ImageCropper.Viewport`, `ImageCropper.Image` and `ImageCropper.Controls` compound
components to change the layout, for example to render the controls above the viewport.
Pass children to `ImageCropper.Controls` to replace the default controls:

<Demo data={ImageCropperDemos.customLayout} />

## Disabled state

Set `disabled` to make the cropper non-interactive, for example to display a preview
of a saved crop. The default controls are disabled as well.

## Changing the image

When `src` changes to a different image, zoom, rotation, flip and the pan position are reset
to their initial values.

## Pairing with Dropzone

`ImageCropper` does not include a file input. Use [Dropzone](/x/dropzone/) or a native file
input to let users pick an image, then pass an object URL of the file to `src`:

```tsx
import { useEffect, useState } from 'react';
import { Button, ImageCropper, useImageCropper } from '@mantine/core';
import { Dropzone, IMAGE_MIME_TYPE } from '@mantine/dropzone';

function Demo() {
  const controller = useImageCropper({ aspectRatio: 1 });
  const [src, setSrc] = useState<string | null>(null);

  useEffect(
    () => () => {
      if (src) {
        URL.revokeObjectURL(src);
      }
    },
    [src]
  );

  const upload = async () => {
    const blob = await controller.getCroppedImage({ type: 'image/webp', quality: 0.9 });
    // upload blob to your server
  };

  return (
    <>
      <Dropzone accept={IMAGE_MIME_TYPE} onDrop={(files) => setSrc(URL.createObjectURL(files[0]))}>
        Drop an image here
      </Dropzone>

      {src && (
        <>
          <ImageCropper src={src} controller={controller} withControls />
          <Button onClick={upload}>Upload</Button>
        </>
      )}
    </>
  );
}
```

## Accessibility

The viewport is focusable and has the accessible name `Image cropper`, set `aria-label` on
`ImageCropper.Viewport` to change it. Keyboard interactions:

- Arrow keys – move the image, hold `Shift` for larger steps
- `+` or `=` – zoom in by `zoomStep`
- `-` – zoom out by `zoomStep`

The default controls have English labels. To localize them, render your own controls
with `ImageCropper.Controls` children or a `useImageCropper` controller.

## Limitations

- **No pinch-to-zoom.** Touch input supports single-finger panning only. On touch devices, provide
  zoom with `withControls` or your own buttons connected to a `useImageCropper` controller.
- **Arbitrary rotation angles.** At angles that are not multiples of 90°, the crop window corners
  can show empty areas, zoom in to cover them.
