## Width

The list fits items into the width it gets from its parent. Inside a flex row, for example [Group](/core/group), set `flex={1}` on the list. Inside an absolutely positioned element, set a width on that element. Otherwise the list does not show more items when more space becomes available.

## Data type

`data` prop accepts an array of any type. By default, the type is inferred from the array.
To set it explicitly, pass a generic type argument:

```tsx
import { OverflowList } from '@mantine/core';

function Demo() {
  return (
    <OverflowList<{ value: string; label: string }>
      data={[{ value: '1', label: 'Item 1' }]}
      renderItem={(item) => <div>{item.label}</div>}
      renderOverflow={(items) => <div>+{items.length} more</div>}
    />
  );
}
```

## Item keys

The visible items are recalculated when `data` changes. For object items, set `getItemKey` to return a unique key, otherwise reordering items without changing the array length is not detected:

```tsx
import { OverflowList } from '@mantine/core';

function Demo() {
  return (
    <OverflowList
      data={[{ id: '1', label: 'Item 1' }]}
      getItemKey={(item) => item.id}
      renderItem={(item) => <div>{item.label}</div>}
      renderOverflow={(items) => <div>+{items.length} more</div>}
    />
  );
}
```

## Collapse from

By default, items are collapsed from the end. Set `collapseFrom="start"` to collapse
items from the beginning, for example to keep the last breadcrumbs visible:
