## Usage

Notification is a base component for the notification system.
Build your own or use the [@mantine/notifications](/x/notifications/) package.

<Demo data={NotificationDemos.configurator} />

## Notifications system features

When you use [@mantine/notifications](/x/notifications/), notifications can be dismissed by:

- dragging them left or right
- horizontal scroll swipe while hovered

You can disable these interactions on the `Notifications` component with
`allowDragDismiss={false}` and `allowScrollDismiss={false}`.

See the [notifications package documentation](/x/notifications/) for configuration details.

## Variants

Use the `variant` prop to control how the icon is rendered. `filled` (default) renders the icon
in a solid circle with a contrast color, `light` renders it in a tinted circle with a colored icon,
`transparent` renders the icon without background in the text shade of the given color, the same
as [Alert](/core/alert) icon. Colors are resolved with `theme.variantColorResolver`, so custom
variants work as well:

<Demo data={NotificationDemos.variants} />

The `variant` prop affects only the icon. The accent line displayed when `icon` is not set and
the loader always use the `color` prop color. To customize icon colors, set
`--notification-icon-bg` and `--notification-icon-color` with the `vars` prop or
[Styles API](/styles/styles-api).

## Accessibility

To support screen readers, set the close button's aria-label or title with `closeButtonProps`:

```tsx
import { Notification } from '@mantine/core';

function Demo() {
  return (
    <Notification
      closeButtonProps={{ 'aria-label': 'Hide notification' }}
    />
  );
}
```
