## Controlled and uncontrolled

Set `defaultActive` for an uncontrolled `Toggle`, `active` and `onActiveChange` props to control it:

```tsx
import { useState } from 'react';
import { Toggle } from '@mantine/core';

// Uncontrolled
function UncontrolledDemo() {
  return <Toggle defaultActive />;
}

// Controlled
function ControlledDemo() {
  const [active, setActive] = useState(false);
  return <Toggle active={active} onActiveChange={setActive} />;
}
```

## Auto contrast

`Toggle` adjusts the icon color to the active background color, for example, with light colors
and `variant="filled"`. The behavior is controlled by [theme.autoContrast](/theming/theme-object/#autocontrast),
set `autoContrast={false}` to disable it for a single toggle:

## Accessibility

`Toggle` renders a `button` with `aria-pressed` attribute that reflects the active state.
Set `aria-label` on icon-only toggles so that screen readers can announce the button purpose.

When `Toggle` is rendered as a non-button element, for example, `component="a"`, the `disabled` prop
sets `aria-disabled`, removes the element from the tab order and prevents clicks.
