## Usage

`MaskInput` is an input with a fixed format, for example a phone number or a credit card.
The `mask` string defines the format, see [mask pattern syntax](#mask-pattern-syntax).
All [useMask](/hooks/use-mask) options and standard input props are supported:

## With use-form

`MaskInput` works with [use-form](/form/use-form) like any other input. The form receives
the raw value without the mask, for example `1234567890` for `(123) 456-7890`.
`form.setFieldValue` and `form.reset` accept both raw and masked values:

## Mask pattern syntax

Each character of the mask string is either a token, an editable slot, or a literal,
a fixed character inserted automatically.

### Built-in tokens

- `9` – any single digit (`[0-9]`)
- `a` – any single letter (`[A-Za-z]`)
- `A` – any uppercase letter (`[A-Z]`)
- `*` – any alphanumeric character (`[A-Za-z0-9]`)
- `#` – digit or sign (`[-+0-9]`)

### Optional segments

Append `?` after the last required character to mark remaining slots as optional:

```tsx
<MaskInput mask="(999) 999-9999? x9999" /> // Extension is optional
```

### Escaping

Prefix a token character with `\` to treat it as a literal:

```tsx
<MaskInput mask="\A999" /> // "A" is literal, not a token
```
