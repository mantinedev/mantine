## Usage

`MaskInput` is a wrapper around [useMask](/hooks/use-mask) hook. It supports all mask options
and standard input props (label, description, error, etc.). The `mask` string defines the expected
format, see [mask pattern syntax](#mask-pattern-syntax).

## Reset value

`MaskInput` is uncontrolled internally – setting `value` from a parent will not clear it.
Use the `resetRef` prop to get a function that clears the input value imperatively.
Values written by [use-form](#with-use-form) are an exception, the form writes them to the input:

<Demo data={MaskInputDemos.resetRef} />

## With use-form

`MaskInput` works with [use-form](/form/use-form) like any other input, spread
`form.getInputProps('field')` on it. The form receives the raw (unmasked) value, for example
`1234567890` for `(123) 456-7890`. `form.setFieldValue` and `form.reset` accept both raw and
masked values:

## Mask pattern syntax

Each character of the mask string is either a **token** (editable slot)
or a **literal** (fixed character inserted automatically).

### Built-in tokens

- `9` – any single digit (`[0-9]`)
- `a` – any single letter (`[A-Za-z]`)
- `A` – any uppercase letter (`[A-Z]`)
- `*` – any alphanumeric character (`[A-Za-z0-9]`)
- `#` – digit or sign (`[-+0-9]`)

### Optional segments

Append `?` after the last required character to mark remaining slots as optional:

```tsx
<MaskInput mask="(999) 999-9999? x9999" /> // Extension is optional
```

### Escaping

Prefix a token character with `\` to treat it as a literal:

```tsx
<MaskInput mask="\A999" /> // "A" is literal, not a token
```
