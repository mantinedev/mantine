## Usage

Mantine does not include typography global styles.
Use `Typography` to add typography styles to your html content.
Sanitize untrusted HTML (for example, with [DOMPurify](https://github.com/cure53/DOMPurify)) before passing it to `dangerouslySetInnerHTML`:

```tsx
import { Typography } from '@mantine/core';

function Demo() {
  return (
    <Typography>
      <div
        dangerouslySetInnerHTML={{ __html: '<p>Your html here</p>' }}
      />
    </Typography>
  );
}
```

- blockquotes
- tables
- links
- images
- hr
- kbd
- mark
- code and pre
- details and summary
