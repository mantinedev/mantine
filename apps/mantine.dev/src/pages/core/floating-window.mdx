## Usage

`FloatingWindow` creates a draggable element with a fixed position:

<Demo data={FloatingWindowDemos.usage} />

## Constrain to viewport

By default, the window cannot be dragged outside the viewport.
Set `constrainToViewport={false}` to allow it:

<Demo data={FloatingWindowDemos.constrainToViewport} />

## Constrain offset

Use the `constrainOffset` prop to set the offset from the viewport edges when constraining the element:

<Demo data={FloatingWindowDemos.constrainOffset} />

## Drag handle selector

By default, the whole window can be dragged. Set `dragHandleSelector` to drag the window
only by the matching elements. Use `excludeDragHandleSelector` to exclude elements inside the
handle, for example the close button:

<Demo data={FloatingWindowDemos.dragHandleSelector} />

## Enabled prop

Set `enabled={false}` to disable dragging:

<Demo data={FloatingWindowDemos.enabled} />

## Set position

Pass a ref to the `setPositionRef` prop to move the window programmatically.
Call it with offsets from the viewport edges, for example `{ top: 20, left: 20 }`.
Axes you omit keep their current position:

<Demo data={FloatingWindowDemos.setPosition} />

## Keyboard support

The window root element is focusable. When it has focus, arrow keys move the window,
hold `Shift` for larger steps. Keys pressed inside window content, for example in inputs,
do not move the window.

## Resize handle

Add `FloatingWindow.ResizeHandle` to make the window resizable. Set the initial, minimum and
maximum size with the `dimensions` prop. The handle supports keyboard: arrow keys resize the
window, `Home` and `End` set the minimum and maximum size:

<Demo data={FloatingWindowDemos.resizeHandle} />

## Resize callbacks

Resize callbacks require the `dimensions` prop and `FloatingWindow.ResizeHandle`:

- `onSizeChange` – called with the `{ width, height }` of the window every time it is resized
- `onResizeStart` – called when the resize starts, pointer resize only
- `onResizeEnd` – called when the resize stops, pointer resize only

<Demo data={FloatingWindowDemos.resizeCallbacks} />
