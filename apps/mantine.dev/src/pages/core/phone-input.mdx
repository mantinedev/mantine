## Country auto-detection

Set `withCountryAutoDetect` to automatically detect and switch the country when the user
types a dial code. For example, typing `+44` will switch to United Kingdom.
Without the prop, the country still changes when a number starting with `+` and another dial code is typed or pasted.
Area codes, for example `+1 204` for Canada, are detected only with the prop:

<Demo data={PhoneInputDemos.countryAutoDetect} />

## Shared dial codes

Countries sharing a dial code are selected by area code and priority by default.
Use `resolveCountry` to choose one by ISO2 code, or return `undefined` to keep the default:

```tsx
<PhoneInput
  defaultCountry="ru"
  withCountryAutoDetect
  resolveCountry={(value, countries) =>
    value.startsWith('+77') && countries.some((country) => country.iso2 === 'kz') ? 'kz' : undefined
  }
/>
```

## National prefixes

`PhoneInput` removes known trunk prefixes from pasted national numbers. For example, pasting
`8 999 123-45-67` with Russia selected produces `+79991234567`. Clearing the input emits `''`.

Ambiguous digits typed after a dial code are preserved by default. Set `nationalPrefixBehavior="strip"`
when users should enter numbers in national form, or `"preserve"` to disable prefix removal.

With `"strip"`, unprefixed numbers use the selected country. Include `+` to enter another country's dial code:

```tsx
<PhoneInput defaultCountry="ru" nationalPrefixBehavior="strip" />
```

## Localization

Use `renderCountryOption` to customize how countries are displayed in the dropdown.
This can be used to translate country names to a different language.

`getCountryLabel` returns the translated name of a country. It is used as the
country button label for screen readers and in the dropdown search, so users
can search by translated names. `searchPlaceholder` and `selectCountryLabel`
translate the search input placeholder and the button label shown before a
country is selected:

## Use within Popover

To use `PhoneInput` within `Popover` or other overlay, set `comboboxProps={{ withinPortal: false }}`.
Pressing `Escape` while the country list is open closes both the list and the `Popover`.
Set `closeOnEscape={false}` on the `Popover` to keep it open. The country list still closes on `Escape`:
