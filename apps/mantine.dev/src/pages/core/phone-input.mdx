## Usage

`PhoneInput` is an international phone number input with a country selector
and per-country formatting. Set `defaultCountry` prop: without it, no country is selected
until the user picks one or types a dial code:

<Demo data={PhoneInputDemos.usage} />

## Loading state

Set `loading` prop to display a loading indicator in the input:

<Demo data={PhoneInputDemos.loading} />

## Controlled

`onChange` is called with the raw value and a details object with the formatted value and
the selected country:

<Demo data={PhoneInputDemos.controlled} />

## Preferred countries

Use `preferredCountries` prop to pin countries to the top of the dropdown:

<Demo data={PhoneInputDemos.preferredCountries} />

## Filter countries

Use `onlyCountries` to show only specific countries or `excludeCountries` to hide some of them:

<Demo data={PhoneInputDemos.onlyCountries} />
<Demo data={PhoneInputDemos.excludeCountries} />

## Custom flags

Use `renderFlag` prop to render custom flags, for example emoji flags:

<Demo data={PhoneInputDemos.emojiFlag} />

## Searchable

Country search is enabled by default. Set `searchable={false}` to disable it:

<Demo data={PhoneInputDemos.searchable} />

## Country auto-detection

Set `withCountryAutoDetect` to switch the country when the user types a dial code,
for example `+44` for United Kingdom:

<Demo data={PhoneInputDemos.countryAutoDetect} />

## Localization

Use `renderCountryOption` to change how countries are displayed in the dropdown,
for example to translate country names:

<Demo data={PhoneInputDemos.localization} />
