## Usage

`PhoneInput` provides an international phone number input with country selector
and formatting masks.

<Demo data={PhoneInputDemos.usage} />

## Input features

<InputFeatures component="PhoneInput" element="input" />

<Demo data={PhoneInputDemos.configurator} />

## Loading state

Set `loading` prop to display a loading indicator in the input:

<Demo data={PhoneInputDemos.loading} />

## Controlled

Use `value` and `onChange` props to control the input value. The `onChange` callback
receives the raw value and a details object containing the formatted value and country data.

<Demo data={PhoneInputDemos.controlled} />

## Preferred countries

Use `preferredCountries` prop to pin countries to the top of the dropdown.

<Demo data={PhoneInputDemos.preferredCountries} />

## Filter countries

Use `onlyCountries` to show only specific countries or `excludeCountries` to hide specific countries.

<Demo data={PhoneInputDemos.onlyCountries} />
<Demo data={PhoneInputDemos.excludeCountries} />

## Custom flags

Use `renderFlag` prop to render custom flag elements, for example emoji flags.
The function receives country data and should return a React node.

<Demo data={PhoneInputDemos.emojiFlag} />

## Searchable

Country dropdown search is enabled by default. Set `searchable={false}` to disable it.

<Demo data={PhoneInputDemos.searchable} />

## Country auto-detection

Set `withCountryAutoDetect` to automatically detect and switch the country when the user
types a dial code. For example, typing `+44` will switch to United Kingdom.

<Demo data={PhoneInputDemos.countryAutoDetect} />

## Localization

Use `renderCountryOption` to customize how countries are displayed in the dropdown.
This can be used to translate country names to a different language.

<Demo data={PhoneInputDemos.localization} />

<Demo data={PhoneInputDemos.dropdownPosition} />
