## Usage

`BackgroundImage` renders the given `src` as a CSS `background-image` of the root element and
stretches it to cover the element. Any content passed as `children` is rendered on top of it:

Use the `radius` prop to set the `border-radius` of the root element – it accepts a key of
`theme.radius` or any valid CSS value:
