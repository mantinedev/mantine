## Usage

`Persona` displays a person identity: an avatar, an optional presence badge and up to
four text lines. Use it in people pickers, contact lists, comment authors and profile headers:

<Demo data={PersonaDemos.usage} />

## Avatar

`avatar` prop accepts [Avatar](/core/avatar) props or a custom React node. When it is not set,
initials generated from the `name` prop are displayed. To render `Persona` without an avatar,
use the [presenceOnly](#presence-only) prop:

<Demo data={PersonaDemos.initials} />

By default, the avatar color is generated from the `name` prop. Set `color` in the `avatar`
prop to override it:

```tsx
import { Avatar, Persona } from '@mantine/core';

function Demo() {
  return (
    <>
      {/* Avatar with an image */}
      <Persona name="Jane Doe" avatar={{ src: 'https://example.com/avatar.png' }} />

      {/* Avatar with initials and a custom color */}
      <Persona name="Jane Doe" avatar={{ color: 'blue' }} />

      {/* Custom avatar node, aria-hidden because the name is rendered next to it */}
      <Persona
        name="Jane Doe"
        avatar={
          <Avatar color="grape" aria-hidden>
            JD
          </Avatar>
        }
      />
    </>
  );
}
```

## Presence

Set `presence` prop to display a status badge on the avatar. It accepts a status string or
an object with `outOfOffice` and `processing` modifiers:

<Demo data={PersonaDemos.presence} />

```tsx
import { Persona } from '@mantine/core';

function Demo() {
  return (
    <>
      <Persona name="Jane Doe" presence="available" />
      <Persona name="Jane Doe" presence={{ status: 'available', outOfOffice: true }} />
      <Persona name="Jane Doe" presence={{ status: 'available', processing: true }} />
    </>
  );
}
```

## Text lines

`Persona` renders up to four text lines. Long lines are truncated with an ellipsis:

```tsx
import { Persona } from '@mantine/core';

function Demo() {
  return (
    <Persona
      name="Vitaly Rtishchev"
      secondaryText="Creator of Mantine"
      tertiaryText="Remote, Berlin"
      quaternaryText="Local time 4:32 PM"
    />
  );
}
```

## Size

`size` prop scales the avatar, the presence badge, the text and the gap between them.
Change `size` in the configurator above to see how it works.

## Text position and alignment

Use `textPosition` prop to place the text after, before or below the avatar and
`textAlignment` prop to align the text block. Change these props in the configurator
above to see how they work.

## Radius

Set `radius` prop to change the avatar `border-radius`, the presence badge follows the avatar
shape. With compound components, set `radius` on `Persona`, not on `Persona.Avatar`:

<Demo data={PersonaDemos.radius} />

## Polymorphic component

`Persona` is a [polymorphic component](/guides/polymorphic), set `component` prop to render it
as a link or a button. A `button` root shrinks to its content, set `w="100%"` to stretch it:

```tsx
import { Persona } from '@mantine/core';

function Demo() {
  return (
    <Persona
      component="a"
      href="https://mantine.dev"
      name="Vitaly Rtishchev"
      secondaryText="Open profile"
      presence="available"
    />
  );
}
```

## Compound components

For full control over the layout, use `Persona.Avatar`, `Persona.Presence` and `Persona.Text`
compound components instead of the shorthand props. `level` prop of `Persona.Text` sets the
line importance, `1` is the person name:

## Accessibility

- The status is announced after the name and text lines, for example "Jane Doe, Product designer, Available"
- Statuses are announced in English by default. Use `labels` prop to translate them:

```tsx
import { Persona } from '@mantine/core';

function Demo() {
  return (
    <Persona
      name="Jane Doe"
      presence={{ status: 'busy', outOfOffice: true }}
      labels={{
        available: 'Verfügbar',
        away: 'Abwesend',
        busy: 'Beschäftigt',
        outOfOffice: 'nicht im Büro',
      }}
    />
  );
}
```

- When a text line already displays the status, set that status label to an empty string,
  for example `labels={{ available: '' }}`, so it is not announced twice
- The avatar is hidden from assistive technologies, because the name is rendered next to it.
  Set `alt` in the `avatar` prop when the avatar is displayed without text.
- A custom node passed to the `avatar` prop is not hidden, add `aria-hidden` to it if it is decorative
