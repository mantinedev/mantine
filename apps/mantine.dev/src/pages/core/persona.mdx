## Usage

`Persona` displays a person identity: an [Avatar](/core/avatar), an optional presence
badge and up to four text lines. Use it in people pickers, contact and chat lists,
comment authors and profile headers.

<Demo data={PersonaDemos.usage} />

## Avatar

`avatar` prop accepts [Avatar](/core/avatar) props or a custom React node. When `avatar` is
not set, an avatar with initials generated from the `name` prop is displayed. To render
`Persona` without an avatar, use the [presenceOnly](#presence-only) prop or
[compound components](#compound-components) without `Persona.Avatar`.

<Demo data={PersonaDemos.initials} />

By default, the avatar color is generated from the `name` prop. Set `color` in the `avatar`
prop to override it:

```tsx
import { Avatar, Persona } from '@mantine/core';

function Demo() {
  return (
    <>
      {/* Avatar with an image */}
      <Persona name="Jane Doe" avatar={{ src: 'https://example.com/avatar.png' }} />

      {/* Avatar with initials and a custom color */}
      <Persona name="Jane Doe" avatar={{ color: 'blue' }} />

      {/* Custom avatar node, aria-hidden because the name is rendered next to it */}
      <Persona
        name="Jane Doe"
        avatar={
          <Avatar color="grape" aria-hidden>
            JD
          </Avatar>
        }
      />
    </>
  );
}
```

## Presence

Set `presence` prop to display a status badge on the avatar. It accepts a status string or a
configuration object:

<Demo data={PersonaDemos.presence} />

The configuration object supports two modifiers: `outOfOffice` renders the badge as a ring
for any status, `processing` adds a pulsing animation.

```tsx
import { Persona } from '@mantine/core';

function Demo() {
  return (
    <>
      <Persona name="Jane Doe" presence="available" />
      <Persona name="Jane Doe" presence={{ status: 'available', outOfOffice: true }} />
      <Persona name="Jane Doe" presence={{ status: 'available', processing: true }} />
    </>
  );
}
```

## Text lines

`Persona` renders up to four text lines. Long lines are truncated with an ellipsis,
the full text of string lines is available on hover:

```tsx
import { Persona } from '@mantine/core';

function Demo() {
  return (
    <Persona
      name="Vitaly Rtishchev"
      secondaryText="Creator of Mantine"
      tertiaryText="Remote, Berlin"
      quaternaryText="Local time 4:32 PM"
    />
  );
}
```

## Size

`size` prop scales the avatar, the presence badge, the text and the gap between
the avatar and the text. Change `size` in the configurator above to see how it scales.

## Text position and alignment

Use `textPosition` prop to place the text `after` (default), `before` or `below` the avatar.
`textAlignment` prop (`start` or `center`) controls how the text block is aligned.
Change these props in the configurator above to see how they work.

## Radius

Set `radius` prop to change the avatar `border-radius`. The presence badge position is
adjusted to the avatar shape: it sits on the circle edge of round avatars and on the corner
of square ones. With compound components, set `radius` on `Persona`, not on `Persona.Avatar`.

## Polymorphic component

`Persona` is a [polymorphic component](/guides/polymorphic), its default root element is
`div`. Set `component` prop to render it as a link or a button. Browser default styles of
`a` and `button` elements are reset. A `button` root shrinks to its content – set `w="100%"`
to stretch it to the container width:

```tsx
import { Persona } from '@mantine/core';

function Demo() {
  return (
    <Persona
      component="a"
      href="https://mantine.dev"
      name="Vitaly Rtishchev"
      secondaryText="Open profile"
      presence="available"
    />
  );
}
```

## Compound components

For full control over the layout, use compound components instead of the shorthand props:

<Demo data={PersonaDemos.compound} />

- `Persona.Avatar` – avatar, accepts [Avatar](/core/avatar) props. Initials are generated
  from the `name` prop of `Persona` or from its own `name` prop.
- `Persona.Presence` – presence badge, accepts `presence` and `labels` props
- `Persona.Text` – text line, `level` prop (`1`–`4`) controls its importance: `1` is the
  primary line (person name), `2`–`4` are secondary lines

`Persona.Avatar` and `Persona.Presence` can be wrapped in a component that does not render
its own element, for example [Tooltip](/core/tooltip).

## Accessibility

- The status is rendered as visually hidden text. Screen readers announce the name first
  and the status last, for example "Jane Doe, Product designer, Available".
- Statuses are announced in English by default. Use `labels` prop to translate them,
  `outOfOffice` is the suffix added when the `outOfOffice` modifier is set:

```tsx
import { Persona } from '@mantine/core';

function Demo() {
  return (
    <Persona
      name="Jane Doe"
      presence={{ status: 'busy', outOfOffice: true }}
      labels={{
        available: 'Verfügbar',
        away: 'Abwesend',
        busy: 'Beschäftigt',
        outOfOffice: 'nicht im Büro',
      }}
    />
  );
}
```

- When a text line already displays the status (for example `tertiaryText="Available"`),
  set that status label to an empty string (`labels={{ available: '' }}`), so the status
  is not announced twice.
- The avatar is hidden from assistive technologies by default, because the name
  is rendered next to it. Set `alt` in the `avatar` prop or on `Persona.Avatar` when the
  avatar is displayed without text.
- A custom node passed to the `avatar` prop is not hidden. Add `aria-hidden` to it if it is
  decorative.
