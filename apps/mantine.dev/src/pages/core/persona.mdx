## Usage

`Persona` displays a person identity: an [Avatar](/core/avatar), an optional presence
badge and up to four stacked text lines. It composes existing Mantine components into a
single primitive that is useful in people pickers, contact and chat lists, comment authors
and profile headers. The most common way to use it is with shorthand props:

<Demo data={PersonaDemos.usage} />

## Avatar

The `avatar` prop accepts [Avatar](/core/avatar) props (`src`, `color`, `radius`,
`variant`, etc.) or a custom React node rendered in place of the avatar. When `avatar` is
not set (or set to `false`, `null` or `''`), an avatar with initials generated from the
`name` prop is displayed. The avatar follows the same fallback chain as the `Avatar`
component: image → initials → placeholder icon. To render `Persona` without an avatar, use
the [presenceOnly](#presence-only) prop or [compound components](#compound-components)
without `Persona.Avatar`.

<Demo data={PersonaDemos.initials} />

By default, the avatar color is generated from the `name` prop (`color="initials"`). Pass a
`color` in the `avatar` prop to override it, or provide a custom node for full control:

```tsx
import { Avatar, Persona } from '@mantine/core';

function Demo() {
  return (
    <>
      {/* Avatar with an image */}
      <Persona name="Jane Doe" avatar={{ src: 'https://example.com/avatar.png' }} />

      {/* Avatar with initials and a custom color */}
      <Persona name="Jane Doe" avatar={{ color: 'blue' }} />

      {/* Custom avatar node, aria-hidden because the name is rendered next to it */}
      <Persona
        name="Jane Doe"
        avatar={
          <Avatar color="grape" aria-hidden>
            JD
          </Avatar>
        }
      />
    </>
  );
}
```

## Presence

The `presence` prop renders a status badge on the avatar. It accepts a status string or a
configuration object. By default, `presence` is `'none'` and no badge is displayed – set it
to one of the following statuses to show a badge:

<Demo data={PersonaDemos.presence} />

Statuses are colored by meaning:

- `available` → green
- `away` → yellow
- `busy` and `do-not-disturb` → red
- `blocked` → red ring
- `offline` and `unknown` → gray ring
- `out-of-office` → grape ring

Statuses that need a cue beyond color (`do-not-disturb`, `blocked`, `out-of-office`) also
render a glyph, and the status is always exposed to assistive technologies as visually
hidden text, see the [accessibility](#accessibility) section.

The configuration object supports `outOfOffice` and `processing` modifiers. `outOfOffice`
renders the badge as a ring for any status (the `blocked` glyph is kept), and `processing`
adds a pulsing animation (disabled when the user prefers reduced motion):

```tsx
import { Persona } from '@mantine/core';

function Demo() {
  return (
    <>
      <Persona name="Jane Doe" presence="available" />
      <Persona name="Jane Doe" presence={{ status: 'available', outOfOffice: true }} />
      <Persona name="Jane Doe" presence={{ status: 'available', processing: true }} />
    </>
  );
}
```

## Text lines

`Persona` renders up to four text lines: `name` (primary), `secondaryText`, `tertiaryText`
and `quaternaryText`. Only the lines that are set are rendered. Long lines are truncated
with an ellipsis, so the component works well inside fixed-width containers such as picker
options. When a line content is a string, it is also set as the `title` attribute, so the full
text is available on hover when the line is truncated:

```tsx
import { Persona } from '@mantine/core';

function Demo() {
  return (
    <Persona
      name="Vitaly Rtishchev"
      secondaryText="Creator of Mantine"
      tertiaryText="Remote, Berlin"
      quaternaryText="Local time 4:32 PM"
    />
  );
}
```

## Size

`Persona` supports `xs`, `sm`, `md`, `lg` and `xl` sizes. The `size` prop scales the avatar,
presence badge, text sizes and the gap between the avatar and the text. Change the `size`
prop in the configurator above to see how it scales.

## Text position and alignment

Use the `textPosition` prop to control where the text is placed relative to the avatar:
`after` (default), `before` or `below`. The `textAlignment` prop (`start` or `center`)
controls how the text block is aligned. Change these props in the configurator above to see
how they work.

## Radius

Set the `radius` prop to change the avatar `border-radius`. It accepts a value from
`theme.radius` or any valid CSS value. The presence badge sits on the circle edge when the
radius is at least half the avatar size (the default `1000px`, percentages and, for example,
`radius="xl"` on a `md` avatar), otherwise it is placed on the avatar corner. `radius` set
in the `avatar` prop counts. In compound mode, the radius of `Persona.Avatar` is not read –
set `radius` on `Persona` instead.

## Polymorphic component

`Persona` is a [polymorphic component](/guides/polymorphic), its default root element is
`div`. Set the `component` prop to render it as a link or a button, for example to build a
clickable people-picker row. When rendered as `a` or `button`, the browser default styles
(underline, link color, button background, border and padding) are reset, the element
gets a focus ring on keyboard focus, and `type="button"` is set on buttons. A `button` root
shrinks to its content – pass `w="100%"` to stretch it to the container width:

```tsx
import { Persona } from '@mantine/core';

function Demo() {
  return (
    <Persona
      component="a"
      href="https://mantine.dev"
      name="Vitaly Rtishchev"
      secondaryText="Open profile"
      presence="available"
    />
  );
}
```

## Compound components

For full control over the layout, use compound components instead of the shorthand props.
`Persona.Avatar` and `Persona.Presence` are placed on the avatar, all other children are
rendered in the text block. A component whose only child is `Persona.Avatar` or
`Persona.Presence`, for example [Tooltip](/core/tooltip), is placed on the avatar. A part
wrapped in an HTML element or `Persona.Text`, nested among other children or rendered by
your own component stays in the text block at its position. A wrapper component that renders
its own element around the part (for example `Box`) is placed on the avatar too, but the
badge is not positioned correctly inside it:

<Demo data={PersonaDemos.compound} />

In compound mode, `Persona.Avatar` generates initials from the `name` prop of the root
`Persona` or from its own `name` prop, `Persona.Text` children are not used for initials.

Available components:

- `Persona.Avatar` – avatar element, accepts [Avatar](/core/avatar) props
- `Persona.Presence` – presence badge, accepts `presence` and `labels` props
- `Persona.Text` – text line, `level` prop (`1`–`4`) controls its importance: `1` is the
  primary line (person name), `2`–`4` are secondary lines

## Accessibility

- The presence badge is hidden from assistive technologies (`aria-hidden`), the status is
  rendered as visually hidden text next to it. The text lines come before the avatar in the
  DOM (the avatar is positioned visually with CSS), so screen readers announce the name first
  and the status last, for example "Jane Doe, Product designer, Available", including when
  the root element is a link or a button.
- Statuses are announced in English by default. Use the `labels` prop to translate them;
  `outOfOffice` is the suffix added when the `outOfOffice` modifier is set. `labels` set on
  `Persona.Presence` are merged over the `labels` of the parent `Persona`:

```tsx
import { Persona } from '@mantine/core';

function Demo() {
  return (
    <Persona
      name="Jane Doe"
      presence={{ status: 'busy', outOfOffice: true }}
      labels={{
        available: 'Verfügbar',
        away: 'Abwesend',
        busy: 'Beschäftigt',
        outOfOffice: 'nicht im Büro',
      }}
    />
  );
}
```

- When a text line already displays the status (for example `tertiaryText="Available"`),
  set that status label to an empty string (`labels={{ available: '' }}`) – no visually
  hidden status text is rendered for it, so the status is not announced twice.
- Avatars rendered from `avatar` props or with `Persona.Avatar` are decorative by default:
  images get `alt=""` and the avatar is hidden from assistive technologies, because the name
  is rendered next to it. Set `alt` in the `avatar` props (or on `Persona.Avatar`) when the
  avatar is displayed without adjacent text or when the image conveys information that the
  text lines do not.
- A custom avatar node passed to the `avatar` prop is rendered as given and is exposed to
  assistive technologies. Add `aria-hidden` to a decorative custom node (or an `alt` to an
  image that conveys information).
- When the root element is rendered as a link or a button with the `component` prop, make
  sure it has an accessible name – the text lines provide it by default.
