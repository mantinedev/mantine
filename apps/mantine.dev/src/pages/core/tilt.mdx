## Usage

`Tilt` rotates its content in 3D following the pointer. It is built on top of the
[use-tilt](/hooks/use-tilt) hook, use the hook directly for full control over the transforms.
Wrap any element with a defined size:

<Demo data={TiltDemos.usage} />

<Demo data={TiltDemos.configurator} />

## Layers

Use `Tilt.Layer` to build a depth effect. Each layer shifts towards the pointer,
`depth` prop controls how far it shifts: layers with a higher `depth` appear closer to the viewer:

<Demo data={TiltDemos.layers} />

## Glare

Set `withGlare` to display a light reflection that follows the pointer:

<Demo data={TiltDemos.glare} />

The reflection is the `::before` pseudo-element of the `glare` selector, change it with `classNames`:

```tsx
import { Tilt } from '@mantine/core';
import classes from './Demo.module.css';

function Demo() {
  return (
    <Tilt withGlare classNames={{ glare: classes.glare }}>
      {/* content */}
    </Tilt>
  );
}
```

```css
.glare::before {
  background: radial-gradient(circle at 50% 50%, rgba(255, 220, 150, 0.6), transparent 60%);
}
```

## React to the whole page

By default, `Tilt` reacts only while the element is hovered. Set `trackWindow` to make it follow
the pointer anywhere on the page:

<Demo data={TiltDemos.trackWindow} />

## Reduced motion

`Tilt` does not tilt the content when the user has requested reduced motion.

## Device orientation

On supported mobile devices, `Tilt` reacts to the device orientation instead of the pointer.
iOS requires a permission, see [use-tilt](/hooks/use-tilt#device-orientation-permission) for details.
