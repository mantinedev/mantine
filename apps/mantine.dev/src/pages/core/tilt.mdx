## Usage

`Tilt` rotates its content in 3D in response to the pointer position and, on supported mobile
devices, the device orientation. Wrap any element with a defined size:

<Demo data={TiltDemos.usage} />

`Tilt` is based on the [use-tilt](/hooks/use-tilt) hook. Use the hook directly if you need
full control over the transforms.

<Demo data={TiltDemos.configurator} />

## Layers

Use `Tilt.Layer` to build a layered depth effect. Each layer shifts towards the
pointer: `depth` prop controls how far (`0` – static, `1` – full shift), `shift` prop sets
the full shift distance in px (`20` by default). Layers with a higher `depth` appear closer
to the viewer:

<Demo data={TiltDemos.layers} />

## Glare

Set `withGlare` to display a light reflection that follows the pointer:

<Demo data={TiltDemos.glare} />

The reflection is the `::before` pseudo-element of the `glare` [Styles API](/styles/styles-api)
selector. To change it, pass a class with `classNames`:

```tsx
import { Tilt } from '@mantine/core';
import classes from './Demo.module.css';

function Demo() {
  return (
    <Tilt withGlare classNames={{ glare: classes.glare }}>
      {/* content */}
    </Tilt>
  );
}
```

```css
.glare::before {
  background: radial-gradient(circle at 50% 50%, rgba(255, 220, 150, 0.6), transparent 60%);
}
```

## React to the whole page

By default, `Tilt` reacts only while the element is hovered. Set `trackWindow` to make it follow
the pointer anywhere on the page:

<Demo data={TiltDemos.trackWindow} />

## Reduced motion

`Tilt` respects the `prefers-reduced-motion` setting: when reduced motion is requested,
the content does not tilt.

## Device orientation

On supported mobile devices, `Tilt` reacts to the device orientation instead of the
pointer. On iOS 13+, access to device orientation requires a permission –
see the [use-tilt](/hooks/use-tilt#device-orientation-permission) documentation for details on requesting it.
