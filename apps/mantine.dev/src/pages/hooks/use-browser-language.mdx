## Usage

`use-browser-language` returns the browser language from
[navigator.language](https://developer.mozilla.org/en-US/docs/Web/API/Navigator/language):

<Demo data={UseBrowserLanguageDemos.usage} />

## usePreferredLanguages

`usePreferredLanguages` returns the user's preferred languages from
[navigator.languages](https://developer.mozilla.org/en-US/docs/Web/API/Navigator/languages), most preferred first.
Use it to pick the best match among the locales your application supports:

<Demo data={UseBrowserLanguageDemos.languages} />

## Definition

```tsx
function useBrowserLanguage(): string | undefined;
function usePreferredLanguages(): readonly string[];
```

## Reacting to changes

Both hooks update the value when the user changes the preferred language in the browser or operating system settings.

## Server-side rendering

On the server and during the first client render, `useBrowserLanguage` returns `undefined`
and `usePreferredLanguages` returns an empty array.
