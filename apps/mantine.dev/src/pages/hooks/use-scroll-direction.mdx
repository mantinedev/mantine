## Usage

`use-scroll-direction` returns `'up'` or `'down'` depending on the direction of the last scroll,
and `'unknown'` before the first scroll event:

<Demo data={UseScrollDirectionDemos.usage} />

## Definition

```tsx
function useScrollDirection(): 'up' | 'down' | 'unknown';
```
