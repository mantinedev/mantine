## Usage

`use-debounced-effect` works like `useEffect`, but the effect runs only after its
dependencies stop changing for the specified `delay`. Use it for side effects that
depend on rapidly changing values, for example data fetching for a search input:

<Demo data={UseDebouncedEffectDemos.usage} />

## Difference from useEffect

Unlike `useEffect`, the effect is **not** executed immediately on mount: it runs
`delay` milliseconds after the mount and after each dependencies change. Set the
`leading` option to run the effect immediately.

The effect may return a cleanup function. It is called before the next execution
and when the component unmounts. A pending effect is canceled on unmount.

## Options

The third argument is either a number (a `delay` shorthand) or an options object
with the same shape as [use-debounced-callback](/hooks/use-debounced-callback):

```tsx
import { useDebouncedEffect } from '@mantine/hooks';

// Delay shorthand
useDebouncedEffect(() => fetchResults(query), [query], 300);

// Options object
useDebouncedEffect(() => fetchResults(query), [query], {
  delay: 300,
  // Run the effect immediately on the first change, then ignore changes within the delay window
  leading: true,
  // Guarantee that the effect runs at least once every 1000ms while the deps keep changing
  maxWait: 1000,
});
```

With `leading: true`, the effect runs on the first change and does not run again
on the trailing edge. Use `maxWait` to also run it periodically while the deps keep changing.

## Definition

```tsx
interface UseDebouncedEffectOptions {
  delay: number;
  leading?: boolean;
  maxWait?: number;
}

function useDebouncedEffect(
  effect: React.EffectCallback,
  deps: React.DependencyList,
  options: number | UseDebouncedEffectOptions
): void;
```

## Exported types

`UseDebouncedEffectOptions` type is exported from the `@mantine/hooks` package,
you can import it in your application:

```tsx
import type { UseDebouncedEffectOptions } from '@mantine/hooks';
```
