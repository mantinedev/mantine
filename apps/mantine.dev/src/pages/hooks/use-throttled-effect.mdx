## Usage

`use-throttled-effect` works like `useEffect`, but runs the effect at most once per `wait`
milliseconds while its dependencies keep changing. Use it for effects that follow a stream of
updates, for example scroll position or a slider value:

<Demo data={UseThrottledEffectDemos.usage} />

## Difference from useEffect

The effect runs immediately on mount and on the first change. Changes during the next `wait`
milliseconds run it once more at the end of that time with the latest values.

The effect may return a cleanup function. It is called before the next run and on unmount.
A pending run is canceled on unmount.

Unlike [use-debounced-effect](/hooks/use-debounced-effect), the hook has no `leading` and `maxWait` options.

## Definition

```tsx
function useThrottledEffect(
  effect: React.EffectCallback,
  deps: React.DependencyList,
  wait: number
): void;
```
