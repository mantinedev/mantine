## Usage

`use-countdown` is a headless countdown hook. It supports two modes: counting down from a given
duration (`countStart`) with `start`/`stop`/`reset` controls, and counting down to a target date
(`targetDate`). It returns the remaining time in milliseconds, along with the same value split into
`days`/`hours`/`minutes`/`seconds`/`milliseconds` segments – you decide how to render it.

The example below uses `countStart` mode to implement a resend code cooldown. The countdown does not
start automatically in `countStart` mode – call `start` to begin. Once it reaches `0`, calling
`start` again restarts it from `countStart`:

<Demo data={UseCountdownDemos.usage} />

## Count down to a target date

Pass a `targetDate` (`Date`, timestamp or date string) to count down to a specific moment. In this
mode the countdown starts automatically and the remaining time is recomputed from the target on
every tick, so it stays accurate even if the tab was in the background. When `targetDate` changes,
the remaining time is recalculated. An invalid `targetDate` results in `count` of `0`, the countdown
does not run and `onComplete` is not called:

<Demo data={UseCountdownDemos.targetDate} />

## Controls

The hook returns `start`, `stop` and `reset` functions in both modes:

- `start` – begins the countdown. In `countStart` mode resumes from the current `count` if it was
  stopped, or restarts from `countStart` if it has already reached `0`.
- `stop` – pauses the countdown and keeps the current `count`.
- `reset` – stops the countdown and restores `count` to `countStart`, or to the time remaining until
  `targetDate` in `targetDate` mode.

Changing `countStart` while the countdown is not running resets `count` to the new value:

## Interval and sub-second precision

The `interval` option controls how often the countdown updates (`1000`ms by default). Use a smaller
interval to display milliseconds:

<Demo data={UseCountdownDemos.subSecond} />

The remaining time is always computed from a stored end timestamp rather than by decrementing a
counter, so the countdown does not drift when ticks are delayed by slow frames or background tabs.

## onComplete and onTick

`onComplete` is called once when the countdown reaches `0`, `onTick` is called on every tick with
the remaining number of milliseconds:

```tsx
import { useCountdown } from '@mantine/hooks';

function Demo() {
  useCountdown({
    countStart: 10_000,
    interval: 1000,
    autoStart: true,
    onTick: (count) => console.log('Remaining', count),
    onComplete: () => console.log('Done'),
  });

  return null;
}
```

## API

```tsx
import { useCountdown } from '@mantine/hooks';

const { count, formatted, running, start, stop, reset } = useCountdown({
  countStart: 30_000,
  interval: 1000,
});
```

Options:

- `targetDate` – date to count down to (mutually exclusive with `countStart`)
- `countStart` – duration in milliseconds to count down from
- `interval` – amount of milliseconds between each tick, `1000` by default
- `autoStart` – whether to start automatically, `true` for `targetDate`, `false` for `countStart`
- `onComplete` – called once when the countdown reaches `0`
- `onTick` – called on every tick with the remaining milliseconds

Return object:

- `count` – remaining time in milliseconds, never less than `0`
- `formatted` – `count` split into `days`, `hours`, `minutes`, `seconds` and `milliseconds`
- `running` – whether the countdown is currently running
- `start` – start/resume the countdown
- `stop` – stop the countdown, keep the current `count`
- `reset` – stop the countdown and reset `count` to `countStart` or to the time remaining until `targetDate`

## Definition

```tsx
interface UseCountdownFormatted {
  days: number;
  hours: number;
  minutes: number;
  seconds: number;
  milliseconds: number;
}

interface UseCountdownOptions {
  targetDate?: Date | number | string;
  countStart?: number;
  interval?: number;
  autoStart?: boolean;
  onComplete?: () => void;
  onTick?: (count: number) => void;
}

interface UseCountdownReturnValue {
  count: number;
  formatted: UseCountdownFormatted;
  running: boolean;
  start: () => void;
  stop: () => void;
  reset: () => void;
}

function useCountdown(options?: UseCountdownOptions): UseCountdownReturnValue
```

## Exported types

`UseCountdownOptions`, `UseCountdownReturnValue` and `UseCountdownFormatted` types are exported from
the `@mantine/hooks` package, you can import them in your application:

```tsx
import type {
  UseCountdownOptions,
  UseCountdownReturnValue,
  UseCountdownFormatted,
} from '@mantine/hooks';
```
