## Usage

`use-countdown` counts down from a duration in milliseconds (`countStart`) or to a date (`targetDate`).
It returns the remaining time and the same value split into days, hours, minutes and seconds.

With `countStart`, call `start` to begin the countdown. Once it reaches `0`, `start` restarts it:

## Count down to a target date

Pass `targetDate` to count down to a specific moment. The countdown starts automatically:

## Controls

Use `start`, `stop` and `reset` functions to control the countdown. `start` resumes a stopped countdown:

## Interval and sub-second precision

`interval` controls how often the countdown updates, one second by default.
Use a smaller interval to display milliseconds:

## onComplete and onTick

`onComplete` is called once when the countdown reaches `0`. `onTick` is called on every tick with
the remaining milliseconds:

```tsx
import { useCountdown } from '@mantine/hooks';

function Demo() {
  useCountdown({
    countStart: 10_000,
    interval: 1000,
    autoStart: true,
    onTick: (count) => console.log('Remaining', count),
    onComplete: () => console.log('Done'),
  });

  return null;
}
```

## API

```tsx
import { useCountdown } from '@mantine/hooks';

const { count, formatted, running, start, stop, reset } = useCountdown({
  countStart: 30_000,
  interval: 1000,
});
```

## Definition

```tsx
interface UseCountdownFormatted {
  days: number;
  hours: number;
  minutes: number;
  seconds: number;
  milliseconds: number;
}

interface UseCountdownOptions {
  /** Date to count down to, cannot be used with `countStart` */
  targetDate?: Date | number | string;

  /** Duration in milliseconds to count down from */
  countStart?: number;

  /** Milliseconds between ticks, `1000` by default */
  interval?: number;

  /** Starts the countdown on mount, `true` for `targetDate`, `false` for `countStart` */
  autoStart?: boolean;

  /** Called once when the countdown reaches `0` */
  onComplete?: () => void;

  /** Called on every tick with the remaining milliseconds */
  onTick?: (count: number) => void;
}

interface UseCountdownReturnValue {
  /** Remaining time in milliseconds, never less than `0` */
  count: number;

  /** `count` split into days, hours, minutes, seconds and milliseconds */
  formatted: UseCountdownFormatted;

  /** `true` while the countdown is running */
  running: boolean;

  /** Starts or resumes the countdown */
  start: () => void;

  /** Stops the countdown and keeps the current `count` */
  stop: () => void;

  /** Stops the countdown and resets `count` to the initial value */
  reset: () => void;
}

function useCountdown(options?: UseCountdownOptions): UseCountdownReturnValue
```

## Exported types

`UseCountdownOptions`, `UseCountdownReturnValue` and `UseCountdownFormatted` types are exported from
the `@mantine/hooks` package, you can import them in your application:

```tsx
import type {
  UseCountdownOptions,
  UseCountdownReturnValue,
  UseCountdownFormatted,
} from '@mantine/hooks';
```
