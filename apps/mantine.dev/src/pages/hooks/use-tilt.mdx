## Usage

`use-tilt` returns `roll` and `tilt` values based on the pointer position over the target
element or, on mobile devices, the device orientation. Map them to CSS transforms to create
a tilt effect. Assign `ref` to a static wrapper and transform its child: an element that
rotates itself flickers near its edges.

If you need a ready-to-use component with glare and layers, use [Tilt](/core/tilt):

## Definition

```tsx
interface UseTiltOptions {
  /** If set, the hook reacts to the pointer position anywhere on the page instead of only
   *  when the target element is hovered, false by default */
  trackWindow?: boolean;

  /** If set, roll and tilt reset to 0 when the pointer leaves the target element.
   *  Ignored when the trackWindow option is set to true, true by default */
  resetOnLeave?: boolean;

  /** Adjusts normalized device orientation roll value before it is returned */
  deviceOrientationRollAdjust?: (value: number) => number;

  /** Adjusts normalized device orientation tilt value before it is returned */
  deviceOrientationTiltAdjust?: (value: number) => number;

  /** Adjusts normalized mouse roll value before it is returned */
  mouseRollAdjust?: (value: number) => number;

  /** Adjusts normalized mouse tilt value before it is returned */
  mouseTiltAdjust?: (value: number) => number;
}

interface UseTiltReturnValue<T extends HTMLElement = any> {
  /** Ref callback that must be assigned to the target element */
  ref: React.RefCallback<T | null>;

  /** Vertical tilt normalized to `[-0.5, 0.5]` for mouse input, positive when the pointer is above the center of the element */
  roll: number;

  /** Horizontal tilt normalized to `[-0.5, 0.5]` for mouse input, positive when the pointer is right of the center of the element */
  tilt: number;

  /** Input source that produced the current `roll` and `tilt` values */
  source: 'mouse' | 'deviceOrientation';
}

function useTilt<T extends HTMLElement = any>(
  options?: UseTiltOptions,
): UseTiltReturnValue<T>;
```

## roll and tilt values

`roll` is the vertical tilt and `tilt` is the horizontal tilt. Both are `0` at the center of
the element and reach `-0.5` and `0.5` at its edges. `roll` is positive above the center,
`tilt` is positive to the right of it.

Multiply the values by the number of degrees you need. With `rotateX(roll)` and `rotateY(tilt)`,
the edge under the pointer moves away from the viewer:

```tsx
import { useTilt } from '@mantine/hooks';

function Demo() {
  const { ref, roll, tilt } = useTilt<HTMLDivElement>();

  return (
    <div ref={ref} style={{ perspective: 800 }}>
      <div
        style={{
          transform: `rotateX(${roll * 20}deg) rotateY(${tilt * 20}deg)`,
        }}
      >
        Tilting card
      </div>
    </div>
  );
}
```

## Reset on leave

By default, `roll` and `tilt` reset to `0` when the pointer leaves the target element.
Set `resetOnLeave: false` to keep the last values:

```tsx
import { useTilt } from '@mantine/hooks';

function Demo() {
  // The element keeps its last tilt after the cursor leaves
  const { ref, roll, tilt } = useTilt<HTMLDivElement>({ resetOnLeave: false });
  // ...
}
```

## React to the whole page

By default, the values change only while the target element is hovered. Set `trackWindow: true`
to react to the pointer anywhere on the page. The values are then not clamped: they grow the
further the cursor is from the element.

## Adjusting values

Use the adjust options to amplify, dampen, clamp or invert the values of each input source.
In this example, the mouse values are inverted and amplified, so the edge under the cursor
moves towards the viewer:

<Demo data={UseTiltDemos.adjust} />

```tsx
import { useTilt } from '@mantine/hooks';

function Demo() {
  const { ref, roll, tilt } = useTilt<HTMLDivElement>({
    // Amplify the mouse effect
    mouseRollAdjust: (value) => value * 2,
    mouseTiltAdjust: (value) => value * 2,
    // Invert the device orientation effect
    deviceOrientationRollAdjust: (value) => -value,
    deviceOrientationTiltAdjust: (value) => -value,
  });

  // ...
}
```

## Source selection

`source` is the active input, `'mouse'` or `'deviceOrientation'`. Once the device reports
orientation data, the hook switches to it and stays there. Use `source` to show a hint,
for example "move the cursor" or "tilt the device".

## Device orientation permission

On iOS, device orientation requires a permission. `use-tilt` does not request it: call
`DeviceOrientationEvent.requestPermission()` from a user event, for example a button click.
Until the permission is granted, the hook uses the pointer position:

```tsx
async function requestOrientationPermission() {
  const DeviceOrientationEventTyped = DeviceOrientationEvent as unknown as {
    requestPermission?: () => Promise<'granted' | 'denied'>;
  };

  if (typeof DeviceOrientationEventTyped.requestPermission === 'function') {
    await DeviceOrientationEventTyped.requestPermission();
  }
}
```
