## Usage

`use-hold-repeat-handlers` is built on top of [use-hold-repeat](/hooks/use-hold-repeat). It returns
event handlers that add press-and-hold-to-repeat behavior to an element. The hook is used
in increment/decrement controls of [NumberInput](/core/number-input). Press and hold the buttons
to change the value:

## Definition

```tsx
type UseHoldRepeatEvent = 'pointer' | 'mouse' | 'touch' | 'keyboard';

interface UseHoldRepeatHandlersOptions extends UseHoldRepeatOptions {
  /** Which event handlers to produce. Do not combine `pointer` with `mouse`/`touch`. @default ['pointer'] */
  events?: UseHoldRepeatEvent[];

  /** When `events` includes `keyboard`, only these keys start the hold (e.g. `['ArrowUp']`).
   *  Omit to react to any key. */
  keys?: string[];

  /** Call `event.preventDefault()` on the pointer, mouse and keyboard start event.
   *  Touch start events are exempt (React registers `touchstart` as a passive listener). @default true */
  preventDefault?: boolean;
}

interface UseHoldRepeatHandlersReturnValue {
  onPointerDown?: (event: React.PointerEvent) => void;
  onPointerUp?: (event: React.PointerEvent) => void;
  onPointerLeave?: (event: React.PointerEvent) => void;
  onPointerCancel?: (event: React.PointerEvent) => void;

  onMouseDown?: (event: React.MouseEvent) => void;
  onMouseUp?: (event: React.MouseEvent) => void;
  onMouseLeave?: (event: React.MouseEvent) => void;

  onTouchStart?: (event: React.TouchEvent) => void;
  onTouchEnd?: (event: React.TouchEvent) => void;
  onTouchCancel?: (event: React.TouchEvent) => void;

  onKeyDown?: (event: React.KeyboardEvent) => void;
  onKeyUp?: (event: React.KeyboardEvent) => void;
  onBlur?: (event: React.FocusEvent) => void;

  /** Imperative passthrough from useHoldRepeat for custom wiring */
  start: () => void;
  stop: () => void;
}

function useHoldRepeatHandlers(
  onTrigger: () => void,
  options?: UseHoldRepeatHandlersOptions,
): UseHoldRepeatHandlersReturnValue
```

The hook supports all [use-hold-repeat](/hooks/use-hold-repeat) options. The function is called
once per press unless both `delay` and `interval` are set.

## Event sources

By default, the hook returns pointer event handlers. Use the `events` option to choose
which events start and stop the hold:

```tsx
import { useHoldRepeatHandlers } from '@mantine/hooks';

function Demo() {
  const handlers = useHoldRepeatHandlers(() => console.log('tick'), {
    delay: 500,
    interval: 100,
    events: ['mouse', 'touch'],
  });

  return <button {...handlers}>Hold me</button>;
}
```

- `pointer` – `onPointerDown` starts, `onPointerUp`, `onPointerLeave` and `onPointerCancel` stop
- `mouse` – `onMouseDown` starts, `onMouseUp` and `onMouseLeave` stop
- `touch` – `onTouchStart` starts, `onTouchEnd` and `onTouchCancel` stop
- `keyboard` – `onKeyDown` starts, `onKeyUp` and `onBlur` stop

Do not combine `pointer` with `mouse` or `touch`: `pointer` already handles both, and the
function will be called twice per interaction.

## Keyboard

When `events` includes `keyboard`, the hold starts on `keydown` and stops on `keyup` or `blur`.
Use the `keys` option to restrict which keys start the hold:

```tsx
import { useHoldRepeatHandlers } from '@mantine/hooks';

function Demo() {
  const handlers = useHoldRepeatHandlers(() => console.log('tick'), {
    delay: 500,
    interval: 100,
    events: ['keyboard'],
    keys: ['ArrowUp'],
  });

  return <button {...handlers}>Focus and hold ArrowUp</button>;
}
```

To handle several keys on one element, call the hook once per action with different `keys`
and merge the returned handlers with [mergeEventHandlers](#combining-handler-bundles).
Focus the input and hold <kbd>ArrowUp</kbd> or <kbd>ArrowDown</kbd> to change the value:

## Combining handler bundles

`mergeEventHandlers` function exported from `@mantine/hooks` merges several objects with event
handlers into one. Handlers with the same name are all called in order with the same event:

```tsx
import { mergeEventHandlers, useHoldRepeatHandlers } from '@mantine/hooks';

function Demo() {
  const up = useHoldRepeatHandlers(increment, { events: ['keyboard'], keys: ['ArrowUp'] });
  const down = useHoldRepeatHandlers(decrement, { events: ['keyboard'], keys: ['ArrowDown'] });

  return <input {...mergeEventHandlers(up, down)} />;
}
```

`mergeEventHandlers` returns new functions on every call, wrap it in `useMemo` if you need
stable references.

## preventDefault

By default `event.preventDefault()` is called on the start event (pointer down, mouse down or key
down). Set `preventDefault: false` to keep the browser default behavior. `preventDefault()` has
no effect on touch start events, use the
[touch-action](https://developer.mozilla.org/en-US/docs/Web/CSS/touch-action) CSS
property to prevent scrolling during a touch hold:

```tsx
import { useHoldRepeatHandlers } from '@mantine/hooks';

function Demo() {
  const handlers = useHoldRepeatHandlers(() => console.log('tick'), {
    delay: 500,
    interval: 100,
    preventDefault: false,
  });

  return <button {...handlers}>Hold me</button>;
}
```

## Imperative start/stop

The returned object also includes `start` and `stop` functions from
[use-hold-repeat](/hooks/use-hold-repeat). Use them to control the hold from events that
are not covered by the handlers. They are not passed to the element when the handlers are spread:

```tsx
import { useHoldRepeatHandlers } from '@mantine/hooks';

function Demo() {
  const handlers = useHoldRepeatHandlers(() => console.log('tick'), {
    delay: 500,
    interval: 100,
  });

  // handlers.start() / handlers.stop() are available for custom control
  return <button {...handlers}>Hold me</button>;
}
```

## Exported types

`UseHoldRepeatEvent`, `UseHoldRepeatHandlersOptions` and `UseHoldRepeatHandlersReturnValue` types
are exported from the `@mantine/hooks` package; you can import them in your application:

```tsx
import type {
  UseHoldRepeatEvent,
  UseHoldRepeatHandlersOptions,
  UseHoldRepeatHandlersReturnValue,
} from '@mantine/hooks';
```
