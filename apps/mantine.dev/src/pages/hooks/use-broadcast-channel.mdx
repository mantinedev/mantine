## Usage

`use-broadcast-channel` sends messages between tabs, windows, iframes and workers of the same origin
with the [BroadcastChannel API](https://developer.mozilla.org/en-US/docs/Web/API/BroadcastChannel).
Use it to sync logout, theme or cart between tabs.

Open this page in a second browser tab to see the reactions synced between tabs:

## Definition

```tsx
interface UseBroadcastChannelReturnValue<T> {
  /** `true` if the BroadcastChannel API is available in the current environment */
  supported: boolean;

  /** The underlying BroadcastChannel instance, `null` on the server and after `close` */
  channel: BroadcastChannel | null;

  /** Data of the last message received from another context, `undefined` until a message arrives */
  data: T | undefined;

  /** Posts a message to all other contexts subscribed to the same channel name */
  post: (data: T) => void;

  /** The last `messageerror` event, `null` otherwise */
  error: MessageEvent | null;

  /** Closes the channel manually, after which `post` becomes a no-op until it is recreated */
  close: () => void;
}

function useBroadcastChannel<T = any>(name: string): UseBroadcastChannelReturnValue<T>;
```

## Sending and receiving

Call `post` to send a message to every other context with the same channel name.
`data` updates whenever another context posts a message:

```tsx
import { useBroadcastChannel } from '@mantine/hooks';

function Demo() {
  const { data, post } = useBroadcastChannel<string>('notifications');

  return (
    <button type="button" onClick={() => post('Hello from another tab')}>
      Last message: {data ?? 'none'}
    </button>
  );
}
```

## Self-exclusion

A message is not delivered back to the tab that sent it, `data` is never updated by your own `post` calls.
To update the sending tab, change its local state in addition to calling `post`:

```tsx
import { useState } from 'react';
import { useBroadcastChannel } from '@mantine/hooks';

function Demo() {
  const [value, setValue] = useState('light');
  const { post } = useBroadcastChannel<string>('theme');

  const setTheme = (theme: string) => {
    setValue(theme); // update the current tab
    post(theme); // update every other tab
  };

  // ...
}
```

## Structured data

`post` accepts any [structured-cloneable](https://developer.mozilla.org/en-US/docs/Web/API/Web_Workers_API/Structured_clone_algorithm)
value, for example objects, arrays or dates. Pass a type argument to type the message data:

## Handling errors

`error` holds the last `messageerror` event, emitted when a received message cannot be deserialized:

```tsx
import { useBroadcastChannel } from '@mantine/hooks';

function Demo() {
  const { error } = useBroadcastChannel('data-sync');

  if (error) {
    return <div>Failed to read a broadcast message</div>;
  }

  // ...
}
```

## Closing the channel

The channel is closed automatically on unmount or when the `name` changes.
Call `close` to close it earlier, after that `post` does nothing.

## Server-side rendering

On the server and in browsers without the BroadcastChannel API, `supported` is `false` and `post` does nothing.

## Difference from use-local-storage

[use-local-storage](/hooks/use-local-storage) also syncs state across tabs, but it persists the value.
`use-broadcast-channel` does not store anything, use it for messaging, including with workers and iframes.

## Definition of exported types

`UseBroadcastChannelReturnValue` type is exported from the `@mantine/hooks` package, you can
import it in your application:

```tsx
import type { UseBroadcastChannelReturnValue } from '@mantine/hooks';
```
