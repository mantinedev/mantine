## Example

`CodeHighlight` displays code snippets with syntax highlighting. It works with any highlighting library through [adapters](/code-highlight/getting-started/#adapters).
Example with shiki:

<Demo data={CodeHighlightDemos.usage} />

## Copy button

Use `copyLabel` and `copiedLabel` props to change copy button labels. Set `withCopyButton={false}` to remove the button:

<Demo data={CodeHighlightDemos.copy} />

## With tabs
