## Diff method

Use `diffMethod` prop to highlight changes by characters, words or whole lines:

<Demo data={DiffDemos.diffMethod} />

## Context lines

Set `contextLines` prop to limit the number of unchanged lines displayed around changes. Other lines are collapsed behind an expand button:

<Demo data={DiffDemos.contextLines} />

Use `expandLabel` prop to change the expand button label:

```tsx
<Diff
  previousValue={previousValue}
  currentValue={currentValue}
  contextLines={2}
  expandLabel={(hiddenCount) => `${hiddenCount} more`}
/>
```
