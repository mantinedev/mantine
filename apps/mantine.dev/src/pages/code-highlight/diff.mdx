## Usage

`Diff` component highlights differences between two strings. By default, it uses
word-level diff granularity and unified display mode:

<Demo data={DiffDemos.usage} />

## Split mode

Set `mode="split"` to display the diff in a side-by-side layout:

<Demo data={DiffDemos.split} />

## Diff method

The `diffMethod` prop controls the granularity of inline highlighting within changed lines.
Supported values are `"chars"`, `"words"` (default), and `"lines"`:

<Demo data={DiffDemos.diffMethod} />

## Context lines

Set `contextLines` prop to control how many unchanged lines are shown around changes.
Lines beyond this range are collapsed and can be expanded by clicking the expand button:

<Demo data={DiffDemos.contextLines} />

Use `expandLabel` prop to change the expand button label:

```tsx
<Diff
  previousValue={previousValue}
  currentValue={currentValue}
  contextLines={2}
  expandLabel={(hiddenCount) => `${hiddenCount} more`}
/>
```

## Custom colors

Use `addColor` and `removeColor` props to customize the highlight colors.
By default, `addColor` is `teal` and `removeColor` is `red`:
