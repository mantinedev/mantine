## Usage

`JsonViewer` is an interactive component for viewing complex JSON structures.
It supports expand/collapse, type indicators, copy to clipboard, and many other features.

<Demo data={JsonViewerDemos.usage} />

## Default expand depth

Use `defaultExpandDepth` prop to control how many levels are expanded by default.
Set it to `0` to collapse all nodes, or to a higher number to expand more levels:

<Demo data={JsonViewerDemos.expandDepth} />

## Root name

Use `rootName` prop to display a label for the root node. Set it to `false` (default) to hide it:

<Demo data={JsonViewerDemos.rootName} />

## Expand all / collapse all controls

Set `withControls` prop to display expand all and collapse all buttons:

<Demo data={JsonViewerDemos.controls} />

## Type badges and size

Set `withTypes` prop to display type badges next to values and `withSize` prop
to display the number of items in arrays and objects:

<Demo data={JsonViewerDemos.withTypes} />

## Copy button

Set `withCopy` prop to display a copy to clipboard button:

<Demo data={JsonViewerDemos.withCopy} />

## Collapse long strings

Use `collapseStringsAfterLength` prop to truncate long strings. Truncated strings
display a "show more" button that reveals the full value:

<Demo data={JsonViewerDemos.collapseStrings} />

## Sort keys

Set `sortKeys` prop to sort object keys alphabetically. You can also pass a custom
comparator function:

## Highlight items

Use `highlightItems` prop to highlight specific properties with diff-style colors.
Pass a `Record<string, 'added' | 'removed'>` where keys are serialized property
paths (use `serializeJsonViewerPath` helper to build them) and values indicate the highlight type:

<Demo data={JsonViewerDemos.highlight} />

This is useful when you want to display the full JSON structure without allowing

## Keyboard navigation

`JsonViewer` supports keyboard navigation similar to the [Tree](/core/tree) component:

- `↑` / `↓` – move focus between visible nodes
- `→` – expand a collapsed node, or move focus to the first child if already expanded
- `←` – collapse an expanded node, or move focus to the parent node if already collapsed
- `Enter` / `Space` – toggle expand/collapse on collapsible nodes, trigger `onValueSelect` on primitive nodes
