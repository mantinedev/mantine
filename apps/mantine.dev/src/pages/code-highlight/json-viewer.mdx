## Usage

`JsonViewer` displays JSON data as a collapsible tree. Values are serialized the same way as with `JSON.stringify`,
for example, `Date` is displayed as a string and `Map` as an empty object:

<Demo data={JsonViewerDemos.usage} />

## Default expand depth

Use `defaultExpandDepth` prop to set how many levels are expanded initially, the root node is always expanded:

<Demo data={JsonViewerDemos.expandDepth} />

`defaultExpandDepth` is applied only on mount. If `value` is loaded later, change the `key` together with the data,
or control the expanded state with `expandedPaths` and `onExpandedPathsChange` props:

```tsx
import { JsonViewer } from '@mantine/code-highlight';

function Demo({ data }: { data: unknown }) {
  return <JsonViewer key={JSON.stringify(data)} value={data} defaultExpandDepth={2} />;
}
```

## Long arrays and objects

Use `maxDisplayLength` prop to limit the number of entries displayed in a single object or array. The rest is replaced with a "... N more items" row.

Set `groupArraysAfterLength` prop to split longer arrays into collapsible groups instead. `maxDisplayLength` does not apply to grouped arrays.

## Keyboard navigation

`JsonViewer` supports keyboard navigation similar to the [Tree](/core/tree) component:

- `↑` / `↓` – move focus between visible nodes
- `→` – expand a collapsed node, or move focus to its first child
- `←` – collapse an expanded node, or move focus to its parent
- `Enter` / `Space` – toggle expand/collapse on collapsible nodes, trigger `onValueSelect` on primitive nodes
- `Ctrl + C` / `⌘ + C` – copy the focused node value when `withCopy` prop is set

## Accessibility

The content is rendered as an ARIA tree labelled with `rootName`, or `JSON` when it is not set.
The component is always rendered left-to-right, regardless of the application [direction](/styles/rtl).
