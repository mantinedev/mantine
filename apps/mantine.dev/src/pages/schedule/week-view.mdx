## Overlap mode

`eventOverlapMode` prop controls how overlapping events share the horizontal space:

- `columns` (default) – the width is split evenly, every event is fully visible but narrow
- `cascade` – each event is indented and drawn on top of the previous one, use it when many events overlap

<Demo data={WeekViewDemos.eventOverlapMode} />

In `cascade` mode, a covered event is raised above the others on hover and focus.
Use `eventOverlapRaiseDelay` prop to change the hover delay in milliseconds:

```tsx
import { WeekView } from '@mantine/schedule';

function Demo() {
  return <WeekView date={new Date()} eventOverlapMode="cascade" eventOverlapRaiseDelay={250} />;
}
```

## Background events

Set `display="background"` on an event to render it as a block behind regular events,
for example to mark unavailability or breaks. Background events cannot be clicked, dragged or resized by default:

<Demo data={WeekViewDemos.backgroundEvents} />

## Interactive background events

Set `withInteractiveBackgroundEvents` prop to make background events clickable. `onEventClick`
is called with the background event, check `event.display === 'background'` to tell it apart.
An interactive background event covers the time slots underneath it, clicks in its range go to the event:

<Demo data={WeekViewDemos.interactiveBackgroundEvents} />

## Resizable background events

Set `withEventResize` together with `withInteractiveBackgroundEvents` to make background events resizable.
All-day background events are never resizable. To keep background events fixed while
regular events stay resizable, return `false` from `canResizeEvent`:

```tsx
<WeekView
  withEventResize
  withInteractiveBackgroundEvents
  canResizeEvent={(event) => event.display !== 'background'}
/>
```

## Responsive styles

WeekView uses [container queries](https://caniuse.com/css-container-queries) for responsive styles.
Labels are hidden and paddings are reduced when the container is narrow.

## Accessibility

### Focus management

The weekdays row, the all-day row and the time slots grid each have only their first element
in the tab order, other elements are reached with arrow keys.

### Slot labels

Each time slot button has an `aria-label` with its date and time range, for example "Time slot 2025-11-03 08:00:00 - 09:00:00".
All-day slots are labeled "All day 2025-11-03" and weekday buttons "Weekday 2025-11-03".
