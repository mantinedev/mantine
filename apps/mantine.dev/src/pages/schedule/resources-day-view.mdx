## Usage

`ResourcesDayView` displays resources as rows and time slots as columns.
Events are assigned to a resource with `resourceId` property:

<Demo data={ResourcesDayViewDemos.usage} />

## All-day events

Events that start at midnight and end at the next midnight are all-day events.
They are pinned to the top of the resource row, all-day background events tint the whole row:

<Demo data={ResourcesDayViewDemos.allDayEvents} />

## Interactive background events

Set `withInteractiveBackgroundEvents` prop to make background events clickable. `onEventClick`
is called with the background event, check `event.display === 'background'` to tell it apart.
An interactive background event covers the time slots underneath it, clicks in its range go to the event:

<Demo data={ResourcesDayViewDemos.interactiveBackgroundEvents} />

## Resizable background events

Set `withEventResize` together with `withInteractiveBackgroundEvents` to make background events resizable.
All-day background events are never resizable. To keep background events fixed while
regular events stay resizable, return `false` from `canResizeEvent`:

```tsx
<ResourcesDayView
  withEventResize
  withInteractiveBackgroundEvents
  canResizeEvent={(event) => event.display !== 'background'}
/>
```

## Drag and drop

Set `withEventsDragAndDrop` prop to allow dragging events between resources and time slots.
`onEventDrop` receives `resourceId` of the target resource, use it to update the event's resource.
To reject a drop, for example to prevent double booking, see [drop validation](/schedule/schedule/#drop-validation):

<Demo data={ResourcesDayViewDemos.dragDrop} />

## Drag interval

Dragged events snap to `intervalMinutes` by default. Set `eventDragInterval` to use a different step,
for example to move events in 15-minute increments on a grid with 30-minute slots:

<Demo data={ResourcesDayViewDemos.eventDragInterval} />

## External drag and drop

Use `onExternalEventDrop` to accept items dragged from outside the schedule:

<Demo data={ResourcesDayViewDemos.externalDragDrop} />

## Bidirectional drag and drop

Combine `onExternalEventDrop` with `withEventsDragAndDrop` to drag items both to and from the schedule:

<Demo data={ResourcesDayViewDemos.bidirectionalDragDrop} />

The indicator is positioned based on the user's local time, `@mantine/schedule` does not convert timezones.
To display it in a different timezone, return the current time from `getCurrentTime` prop.
The example below uses the [dayjs timezone plugin](https://day.js.org/docs/en/plugin/timezone):
