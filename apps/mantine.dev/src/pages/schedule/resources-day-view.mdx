## Usage

ResourcesDayView displays resources as rows and time slots as columns. Each row represents
a resource (e.g., conference room, person, equipment) and shows events assigned to that
resource via the `resourceId` property on event data.

<Demo data={ResourcesDayViewDemos.usage} />

## All-day events

Events that span the entire day (start at `00:00:00` and end at the next day `00:00:00`)
are rendered as full-width bars. Foreground all-day events are pinned to the top of the
resource row and stack when there are several; all-day events with `display: 'background'`
tint the whole row.

<Demo data={ResourcesDayViewDemos.allDayEvents} />

## Interactive background events

Set `withInteractiveBackgroundEvents` prop to make background events clickable. `onEventClick`
is called the same way as for regular events, use `event.display === 'background'` to tell them apart.
Interactive background events cover the time slots underneath them and cannot be dragged.

<Demo data={ResourcesDayViewDemos.interactiveBackgroundEvents} />

## Resizable background events

Set both `withEventResize` and `withInteractiveBackgroundEvents` to allow resizing
background events. All-day background events cannot be resized. To resize only regular
events, return `false` from `canResizeEvent`:

```tsx
<ResourcesDayView
  withEventResize
  withInteractiveBackgroundEvents
  canResizeEvent={(event) => event.display !== 'background'}
/>
```

## Drag and drop

Enable drag and drop with `withEventsDragAndDrop` prop. The `onEventDrop` callback receives
the `resourceId` of the target resource, use it to update the event's resource.

To reject a drop based on where the event lands, for example to prevent double booking, use
`preventEventOverlap` and `canDropEvent`, see [drop validation](/schedule/schedule/#drop-validation).
In resource views, the event is checked against the events of the target resource.

<Demo data={ResourcesDayViewDemos.dragDrop} />

## Drag interval

By default, dragged events snap to `intervalMinutes`. Set `eventDragInterval` to use a different
step, for example to move events in 15-minute increments on a grid with 30-minute slots.
A ghost preview shows where the event will land:

<Demo data={ResourcesDayViewDemos.eventDragInterval} />

## Event resize

Enable event resizing with `withEventResize` prop. Events can be resized by dragging
their left or right edges.

To reject a resize based on the new range, use `preventEventOverlap` and `canResizeEventTo`, see
[drop validation](/schedule/schedule/#drop-validation).

<Demo data={ResourcesDayViewDemos.eventResize} />

## Resize interval

By default, resized events snap to `intervalMinutes`. Set `eventResizeInterval` to use a different
step, for example to resize events in 15-minute increments on a grid with 30-minute slots:

<Demo data={ResourcesDayViewDemos.eventResizeInterval} />

## Current time indicator in a different timezone

`@mantine/schedule` does not perform timezone conversions, the current time indicator
is positioned based on the user's local time. To display it in a different timezone, pass
a function that returns the current time to `getCurrentTime` prop. The example below uses
the [dayjs timezone plugin](https://day.js.org/docs/en/plugin/timezone):

<Demo data={ResourcesDayViewDemos.timezone} />
