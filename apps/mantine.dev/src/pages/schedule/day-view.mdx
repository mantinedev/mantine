## Slot label interval

By default, the time column shows one label per hour. Set `slotLabelInterval` prop to display
labels more often, for example every 15 or 30 minutes. The value must be a multiple of
`intervalMinutes`, other values are rounded up to the next valid one. Increase `slotHeight` so
that the labels have enough space:

<Demo data={DayViewDemos.slotLabelInterval} />

## Sub-hour grid lines

Set `withSubHourGridLines={false}` to display one grid line per hour when `intervalMinutes` is smaller than `60`.
Events are still created and resized with the smaller interval:

## Current time indicator

A line at the current time is displayed for today by default.

## Overlap mode

`eventOverlapMode` prop controls how overlapping events share the horizontal space:

- `columns` (default) – the width is split evenly, every event is fully visible but narrow
- `cascade` – each event is indented and drawn on top of the previous one, use it when many events overlap

<Demo data={DayViewDemos.eventOverlapMode} />

In `cascade` mode, a covered event is raised above the others on hover and focus.
Use `eventOverlapRaiseDelay` prop to change the hover delay in milliseconds:

```tsx
import { DayView } from '@mantine/schedule';

function Demo() {
  return <DayView date={new Date()} eventOverlapMode="cascade" eventOverlapRaiseDelay={250} />;
}
```

## Drag and drop

Set `withEventsDragAndDrop` prop to allow dragging events, `onEventDrop` is called with the new range.
All-day events cannot be dragged. To reject a drop, for example to prevent double booking,
see [drop validation](/schedule/schedule/#drop-validation):

<Demo data={DayViewDemos.dragDrop} />

## Drag interval

Dragged events snap to `intervalMinutes` by default. Set `eventDragInterval` to use a different step,
for example to move events in 15-minute increments on a grid with 30-minute slots:

<Demo data={DayViewDemos.eventDragInterval} />

## External drag and drop

Use `onExternalEventDrop` to accept items dragged from outside the schedule.
External items must set data in `dataTransfer` during their `onDragStart`.
The callback receives the `DataTransfer` object and the drop target datetime:

<Demo data={DayViewDemos.externalDragDrop} />

## Bidirectional drag and drop

Combine `onExternalEventDrop` with `withEventsDragAndDrop` to drag items both to and from
the schedule. A dragged event sets `application/json` data with `{ eventId }` in `dataTransfer`,
read it in your drop zone to identify the event:

<Demo data={DayViewDemos.bidirectionalDragDrop} />

## Background events

Set `display="background"` on an event to render it as a block behind regular events,
for example to mark unavailability or breaks. Background events cannot be clicked, dragged or resized by default:

<Demo data={DayViewDemos.backgroundEvents} />

## Interactive background events

Set `withInteractiveBackgroundEvents` prop to make background events clickable. `onEventClick`
is called with the background event, check `event.display === 'background'` to tell it apart.
An interactive background event covers the time slots underneath it, clicks in its range go to the event:

<Demo data={DayViewDemos.interactiveBackgroundEvents} />

## Resizable background events

Set `withEventResize` together with `withInteractiveBackgroundEvents` to make background events resizable.
All-day background events are never resizable. To keep background events fixed while
regular events stay resizable, return `false` from `canResizeEvent`:

```tsx
<DayView
  withEventResize
  withInteractiveBackgroundEvents
  canResizeEvent={(event) => event.display !== 'background'}
/>
```

<Demo data={DayViewDemos.resizableBackgroundEvents} />

## Responsive styles

DayView uses [container queries](https://caniuse.com/css-container-queries) for responsive styles.
Labels are hidden and paddings are reduced when the container is narrow.

## Accessibility

### Focus management

The all-day slot and the first time slot are included in the tab order.
Other time slots are reached with arrow keys.
