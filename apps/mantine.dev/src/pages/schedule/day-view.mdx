## Usage

`DayView` displays events for a single day with time slots.

<Demo data={DayViewDemos.usage} />

## Time range

Use `startTime` and `endTime` props to set the visible time range. Times should be in `HH:mm:ss` format.

<Demo data={DayViewDemos.timeRange} />

## Start scroll time

Use `startScrollTime` prop to set the initial scroll position, for example to open the view
at the start of business hours instead of midnight. The value must be in `HH:mm:ss` format.

<Demo data={DayViewDemos.startScrollTime} />

## Interval minutes

`intervalMinutes` prop controls the granularity of time slots. Default is `15` minutes.

<Demo data={DayViewDemos.intervalMinutes} />

## Sub-hour grid lines

When `intervalMinutes` is smaller than `60`, set `withSubHourGridLines={false}` to display only one
grid line per hour. Events are still created and resized with the smaller interval.

<Demo data={DayViewDemos.subHourGridLines} />

## All-day events

Events that span the entire day are displayed in a dedicated all-day section at the top.
When there are more than 2 all-day events, the component shows a "+N more" indicator.

<Demo data={DayViewDemos.allDayEvents} />

## Overlapping events

When multiple events overlap in time, they are automatically positioned side by side
with appropriate widths and offsets.

<Demo data={DayViewDemos.overlappingEvents} />

## Current time indicator

Set `withCurrentTimeIndicator` to display a line showing the current time.
By default, it's only shown for the current day. Set `withCurrentTimeBubble={false}`
to hide the time bubble.

<Demo data={DayViewDemos.currentTimeIndicator} />

## Current time indicator in a different timezone

`@mantine/schedule` does not perform timezone conversions. By default, the current time indicator
is positioned based on the user's local time.

To display the indicator in a different timezone, use `getCurrentTime` prop – a function
that returns the current time. In the example below, the current time is converted to the selected
timezone with the [dayjs timezone plugin](https://day.js.org/docs/en/plugin/timezone):

<Demo data={DayViewDemos.timezone} />

## Business hours

Use `highlightBusinessHours` and `businessHours` props to visually distinguish business hours
from non-business hours. The `businessHours` prop accepts a tuple with start and end times
in `HH:mm:ss` format.

<Demo data={DayViewDemos.businessHours} />

## Custom time slot props

Use `getTimeSlotProps` to add props to individual time slots, for example `data-business-hours`
or event handlers. The function receives `{ start, end }` datetime strings in `YYYY-MM-DD HH:mm:ss`
format and returns an object of props or `undefined`. Event handlers returned by the function
do not override internal handlers, both are called.

<Demo data={DayViewDemos.getTimeSlotProps} />

## Slot height

Customize the height of time slots and the all-day section using `slotHeight` and
`allDaySlotHeight` props. The `slotHeight` represents the height of a 1-hour slot.

<Demo data={DayViewDemos.slotHeight} />

## Radius

Use `radius` prop to change the border radius of the view and events.

<Demo data={DayViewDemos.radius} />

## Overlap mode

`eventOverlapMode` prop controls how overlapping events share the horizontal space:

- `columns` (default) – the width is split evenly between overlapping events. Every event
  is fully visible, but gets narrower as more events overlap.
- `cascade` – each event is indented from the previous one and drawn on top of it. Events keep
  a readable width, but cover the events underneath. Use it when many events overlap at the same time.

<Demo data={DayViewDemos.eventOverlapMode} />

In `cascade` mode, a covered event is raised above the others when it is hovered or focused.
Use `eventOverlapRaiseDelay` prop to change the hover delay in milliseconds, `600` by default:

```tsx
import { DayView } from '@mantine/schedule';

function Demo() {
  return <DayView date={new Date()} eventOverlapMode="cascade" eventOverlapRaiseDelay={250} />;
}
```

## Drag and drop

Enable drag and drop by setting `withEventsDragAndDrop` prop. Use `onEventDrop` callback to handle
event drops. All-day events cannot be dragged.

<Demo data={DayViewDemos.dragDrop} />

To reject a drop based on where the event lands – for example to prevent double booking – use
`preventEventOverlap` and `canDropEvent`, see [drop validation](/schedule/schedule/#drop-validation).

## Drag interval

By default events snap to `intervalMinutes` when moved by drag and drop. Set `eventDragInterval`
to use a different snap step for dragging – for example, a grid with 30-minute slots whose events
can be moved in 15-minute increments. A ghost preview shows where the event will land:

<Demo data={DayViewDemos.eventDragInterval} />

## External drag and drop

Use `onExternalEventDrop` to allow dragging items from outside the component into
the schedule. External items must set data in `dataTransfer` during their `onDragStart`.
The callback receives the `DataTransfer` object and the drop target datetime.

<Demo data={DayViewDemos.externalDragDrop} />

## Bidirectional drag and drop

Combine `onExternalEventDrop` with `withEventsDragAndDrop` to drag items both into and out of
the schedule. When an event is dragged, the schedule sets `application/json` data with `{ eventId }`
in `dataTransfer`. Read it in your drop zone to identify the event.

<Demo data={DayViewDemos.bidirectionalDragDrop} />

## Selective drag permissions

Use `canDragEvent` callback to control which events can be dragged.
Events that return `false` will not be draggable.

<Demo data={DayViewDemos.canDragEvent} />

## Event resize

Enable event resizing by setting `withEventResize` prop. Users can drag the top or bottom
edge of an event to adjust its start or end time. Use `onEventResize` callback to handle
the resize.

<Demo data={DayViewDemos.eventResize} />

To reject a resize based on the new range, use `preventEventOverlap` and `canResizeEventTo`, see
[drop validation](/schedule/schedule/#drop-validation).

## Resize interval

By default events snap to `intervalMinutes` when resized. Set `eventResizeInterval` to use a
different snap step for resizing – for example, a grid with 30-minute slots whose events can be
resized in 15-minute increments:

<Demo data={DayViewDemos.eventResizeInterval} />

## Selective resize permissions

Use `canResizeEvent` callback to control which events can be resized.
Events that return `false` will not show resize handles.

<Demo data={DayViewDemos.canResizeEvent} />

## Custom event rendering

Use `renderEventBody` prop to customize how events are displayed. This allows you to
add custom icons, badges, or any other content to events.

<Demo data={DayViewDemos.renderEventBody} />

## Full event customization

Use `renderEvent` prop to fully customize event rendering. The function receives the event
as the first argument and the props of the event root element (including children) as the second
argument. Use it to wrap events in `HoverCard`, `Tooltip` or other components.

<Demo data={DayViewDemos.renderEvent} />

## Recurring events

DayView automatically expands recurring events for the visible day.
See [Recurring events guide](/schedule/recurring-events) for full documentation.

<Demo data={DayViewDemos.recurringEvents} />

## Background events

Set `display="background"` on an event to render it as a full-width, semi-transparent block
behind regular events. By default it cannot be clicked, dragged, or resized. Background events
are useful for marking unavailability, lunch breaks, focus time, or other blocked periods.

<Demo data={DayViewDemos.backgroundEvents} />

## Interactive background events

Set `withInteractiveBackgroundEvents` prop to make background events clickable. `onEventClick`
is called with the background event, use `event.display === 'background'` to tell it apart
from regular events.

An interactive background event covers the time slots underneath it: clicks and drag-to-select
in its range go to the event. Interactive background events still cannot be dragged.

<Demo data={DayViewDemos.interactiveBackgroundEvents} />

## Resizable background events

Set `withEventResize` together with `withInteractiveBackgroundEvents` to make background events
resizable. `onEventResize` is called with the background event, the same way as for regular events.

All-day background events are never resizable. To keep background events fixed while
regular events stay resizable, return `false` from `canResizeEvent`:

```tsx
<DayView
  withEventResize
  withInteractiveBackgroundEvents
  canResizeEvent={(event) => event.display !== 'background'}
/>
```

<Demo data={DayViewDemos.resizableBackgroundEvents} />

## Responsive styles

DayView uses [@container queries](https://caniuse.com/css-container-queries) for responsive styles.
The component automatically adjusts its layout based on the container width, hiding labels
and reducing padding on smaller screens. Container queries are supported in all modern browsers.

## Accessibility

### Focus management

Only the first time slot is included in the tab order. All other time slots can be reached
with arrow keys.
