## Usage

`YearView` displays all months of a year, events are shown as colored dots in day cells:

<Demo data={YearViewDemos.usage} />

## With week numbers

Set `withWeekNumbers` to display week numbers in the first column of each month:

<Demo data={YearViewDemos.withWeekNumbers} />

## Without week days

Set `withWeekDays={false}` to hide the weekday names row in each month:

<Demo data={YearViewDemos.withoutWeekDays} />

## Render day

Use `renderDay` to replace the content of a day cell, for example with a count or a badge instead of dots.
The function receives the date and all events of that day:

<Demo data={YearViewDemos.renderDay} />

## Hide weekend days

Set `withWeekendDays={false}` to hide weekend days, events that fall only on hidden days are not displayed.
Use `weekendDays` prop or [DatesProvider](/dates/getting-started/#datesprovider) to change which days are weekend:

<Demo data={YearViewDemos.withoutWeekendDays} />

## Hide outside days

Set `withOutsideDays={false}` to hide days of adjacent months:

<Demo data={YearViewDemos.withOutsideDays} />

Set `firstDayOfWeek` to change the first day of the week:

<Demo data={YearViewDemos.firstDayOfWeek} />

## Localization

Use `locale` prop to set the dayjs locale for date formatting.
Combine it with `labels` prop to translate all UI text:

<Demo data={YearViewDemos.localization} />

## Responsive styles

YearView uses [container queries](https://caniuse.com/css-container-queries) for responsive styles.
Labels are hidden and paddings are reduced when the container is narrow.

## Accessibility

### Focus management

- Only the first day of each month is included in the tab order, all other days can be reached with arrow keys
- Outside days are not focusable
- Disabled days are skipped during keyboard navigation
