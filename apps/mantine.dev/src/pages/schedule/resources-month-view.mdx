## Usage

`ResourcesMonthView` displays resources as rows and days of a month as columns:

<Demo data={ResourcesMonthViewDemos.usage} />

## Static mode

Set `mode="static"` to disable interactions with events and days. Header navigation still works:

<Demo data={ResourcesMonthViewDemos.staticMode} />

## Drag and drop

Set `withEventsDragAndDrop` prop to allow dragging events between resources and time slots.
`onEventDrop` receives `resourceId` of the target resource, use it to update the event's resource.
To reject a drop, for example to prevent double booking, see [drop validation](/schedule/schedule/#drop-validation):

<Demo data={ResourcesMonthViewDemos.dragDrop} />

## Event resize

Set `withEventResize` prop to allow changing event start and end by dragging its edges,
`onEventResize` is called with the new range. Resize snaps to whole days and keeps the time of day.
To reject a resize, see [drop validation](/schedule/schedule/#drop-validation):

<Demo data={ResourcesMonthViewDemos.eventResize} />

## Event form

Use day and event click callbacks to open a form that creates and edits events.
Set `withDragSlotSelect` to allow selecting a date range by dragging across day cells:

<Demo data={ResourcesMonthViewDemos.eventForm} />

## Custom event rendering

Use `renderEvent` prop to replace the event element. The example below shows event details in a hover card:

<Demo data={ResourcesMonthViewDemos.renderEvent} />

## Custom resource label

Use `renderResourceLabel` prop to change resource labels content:

<Demo data={ResourcesMonthViewDemos.renderResourceLabel} />

## Resource groups

Use `groups` prop to group resources under labels displayed in a column to the left of resources.
Use `renderGroupLabel` to change the label content and `groupLabelWidth` to change the column width:

<Demo data={ResourcesMonthViewDemos.resourceGroups} />
