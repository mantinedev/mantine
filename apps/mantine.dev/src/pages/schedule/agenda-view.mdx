## Usage

`AgendaView` displays events of a date range as a list grouped by date:

<Demo data={AgendaViewDemos.usage} />

## All-day and multi-day events

All-day events display an "All day" label, multi-day events appear on each date they span:

<Demo data={AgendaViewDemos.allDayAndMultiday} />

## Date formats

Use `headerFormat` to change the range label in the header and `dateHeaderFormat` to change date group headers.
Both accept a [dayjs format string](https://day.js.org/docs/en/display/format) or a function:

<Demo data={AgendaViewDemos.dateFormats} />

## Custom event rendering

Use `renderEvent` to replace the event row. The function receives the event and the props of the root element,
spread them on your element:

<Demo data={AgendaViewDemos.renderEvent} />

## Event click

`onEventClick` is called when an event is clicked. The example below opens a modal with event details:

<Demo data={AgendaViewDemos.eventClick} />

## Localization

Use `locale` prop to translate date headers and `labels` prop to override built-in strings:

<Demo data={AgendaViewDemos.localization} />

## Static mode

Set `mode="static"` to make events not clickable:

<Demo data={AgendaViewDemos.staticMode} />
