## Drag and drop

Set `withEventsDragAndDrop` prop to allow moving events between days.
To reject a drop, for example to prevent double booking, see [drop validation](/schedule/schedule/#drop-validation):

<Demo data={MonthViewDemos.dragDrop} />

## External drag and drop

Use `onExternalEventDrop` to accept items dragged from outside the schedule.
External items must set data in `dataTransfer` during their `onDragStart`.
The callback receives the `DataTransfer` object and the drop target datetime:

<Demo data={MonthViewDemos.externalDragDrop} />

## Bidirectional drag and drop

Combine `onExternalEventDrop` with `withEventsDragAndDrop` to drag items both to and from
the schedule. A dragged event sets `application/json` data with `{ eventId }` in `dataTransfer`,
read it in your drop zone to identify the event:

<Demo data={MonthViewDemos.bidirectionalDragDrop} />

## Full event customization

Use `renderEvent` prop to replace the event element. The function receives the event and the props
of the root element, including `children`. Use it to wrap events in `HoverCard`, `Tooltip` or other components:

<Demo data={MonthViewDemos.renderEvent} />

## Timed events

Use `renderEvent` to render timed events differently from all-day events, for example as a dot with the start time:

<Demo data={MonthViewDemos.timedEvents} />

## Recurring events

Recurring events are expanded for the visible month, see [recurring events guide](/schedule/recurring-events):

<Demo data={MonthViewDemos.recurringEvents} />

## Background events

Set `display="background"` on an event to render it as a block behind regular events, spanning the full day cell.
Background events cannot be clicked, dragged or resized by default:

<Demo data={MonthViewDemos.backgroundEvents} />

## Interactive background events

Set `withInteractiveBackgroundEvents` prop to make background events clickable. `onEventClick`
is called with the background event, check `event.display === 'background'` to tell it apart.
An interactive background event covers the day cells underneath it, clicks in its range go to the event:

<Demo data={MonthViewDemos.interactiveBackgroundEvents} />

## Create and update events

Set `withDragSlotSelect` prop to allow selecting a date range by dragging across day cells.
`onSlotDragEnd` is called with the range start and end when the drag ends.
Combine it with `onDayClick` and `onEventClick` to create and edit events:

<Demo data={MonthViewDemos.eventForm} />

## Responsive styles

MonthView uses [container queries](https://caniuse.com/css-container-queries) for responsive styles.
Labels are hidden and paddings are reduced when the container is narrow.

## Accessibility

### Focus management

- Only the first day is included in the tab order, all other days can be reached with arrow keys
- Outside days can be focused with arrow keys when `withOutsideDays` is `true`
- Disabled days are skipped during keyboard navigation
