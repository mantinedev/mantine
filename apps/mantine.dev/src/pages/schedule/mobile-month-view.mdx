## Usage

`MobileMonthView` displays a month grid with a list of events of the selected day below it,
similar to calendar applications on iOS. It does not support drag and drop:

<Demo data={MobileMonthViewDemos.usage} />

## With week numbers

Set `withWeekNumbers` to display week numbers in the first column:

<Demo data={MobileMonthViewDemos.withWeekNumbers} />

## With outside days

Set `withOutsideDays` to display days of adjacent months:

<Demo data={MobileMonthViewDemos.withOutsideDays} />

## Highlight today

Set `highlightToday={false}` to remove the current day highlight:

<Demo data={MobileMonthViewDemos.highlightToday} />

## First day of week

Set `firstDayOfWeek` to change the first day of the week, `0` is Sunday, `1` is Monday:

<Demo data={MobileMonthViewDemos.firstDayOfWeek} />

## Custom header

Use `renderHeader` to wrap or replace the header. The function receives the default header element,
the current mode and the current date:

<Demo data={MobileMonthViewDemos.renderHeader} />

## Consistent weeks

Set `consistentWeeks={false}` to display only weeks that have days in the current month:

<Demo data={MobileMonthViewDemos.consistentWeeks} />

## Weekday format

Use `weekdayFormat` prop to change the dayjs format of weekday names:

<Demo data={MobileMonthViewDemos.weekdayFormat} />

## Without week days

Set `withWeekDays={false}` to hide the weekday names row:

<Demo data={MobileMonthViewDemos.withoutWeekDays} />

## Static mode

Set `mode="static"` to disable all interactions:

<Demo data={MobileMonthViewDemos.staticMode} />

## Localization

Use `locale` prop to set the dayjs locale for date formatting.
Combine it with `labels` prop to translate all UI text:

<Demo data={MobileMonthViewDemos.localization} />

## Accessibility

### Focus management

Only the first day of the month is included in the tab order, other days are reached with arrow keys.
The day focused with arrow keys becomes the new tab stop.

### Day labels

Each day button has an `aria-label` with the full date, for example "November 15, 2025".
