import { ResourcesDayViewDemos, ResourcesScheduleDemos } from '@docs/demos';

export default Layout(MDX_DATA.ResourcesSchedule);

## Usage

`ResourcesSchedule` combines resources day, week and month views in one component with view switching:

<Demo data={ResourcesScheduleDemos.usage} />

## Controlled state

Use `view`, `onViewChange`, `date` and `onDateChange` props to control the current view and date:

<Demo data={ResourcesScheduleDemos.controlled} />

## Drag and drop

Set `withEventsDragAndDrop` prop to allow dragging events in all views:

<Demo data={ResourcesScheduleDemos.dragDrop} />

## Week view

Set `defaultView="week"` to open the schedule in week view:

<Demo data={ResourcesScheduleDemos.weekView} />

## View-specific props

Use `dayViewProps`, `weekViewProps` and `monthViewProps` to pass props to a single view:

<Demo data={ResourcesScheduleDemos.viewProps} />

## Event form

Use slot, day and event click callbacks to open a form that creates and edits events in all views:

<Demo data={ResourcesScheduleDemos.eventForm} />

## External drag and drop

Use `onExternalEventDrop` to accept items dragged from outside the schedule.
The callback receives `resourceId` of the target resource:

<Demo data={ResourcesScheduleDemos.externalDragDrop} />

## Event resize

Set `withEventResize` prop to allow changing event start and end by dragging its edges.
In week view, an event cannot be resized across days. In month view, resize snaps to whole days:

<Demo data={ResourcesScheduleDemos.eventResize} />

## Drop validation

Use validation props to reject a drop or resize before it is committed, see [drop validation](/schedule/schedule/#drop-validation).
In resources views, overlap is checked against events of the target resource, its id is passed to the callbacks as `resourceId`:

<Demo data={ResourcesDayViewDemos.canDropEvent} />

## Static mode

Set `mode="static"` to disable all interactions:

<Demo data={ResourcesScheduleDemos.staticMode} />
