## Allow deselect

Set `allowDeselect` to allow users to deselect the currently selected date by clicking on it.
`allowDeselect` is disregarded when the `type` prop is `range` or `multiple`. When a date is
deselected, `onChange` is called with `null`.

## Single date in range

By default, it is not allowed to select a single date as a range – when the user clicks the same date a second time, it is deselected.
To change this behavior, set the `allowSingleDateInRange` prop. `allowSingleDateInRange` is ignored when the
`type` prop is not `range`.

## Default date

Use the `defaultDate` prop to set the date value that will be used to determine which year should be displayed initially.
For example, to display the `2015` year, set `defaultDate={new Date(2015, 1)}`. If the value is not specified,
then `defaultDate` will use `new Date()`. Month, day, minutes and seconds are ignored in the provided date object, only the year is used –
you can specify any date value.

Note that if you set the `date` prop, then the `defaultDate` value will be ignored.

<Demo data={MonthPickerDemos.defaultDate} />

By doing so, you can customize the date picking experience. For example, when the user selects the first date in a range,
you can add one year to the current date value:

<Demo data={MonthPickerDemos.controlledDate} />

## Controlling with useCalendar

`MonthPicker` accepts the same controller as [Calendar](/dates/calendar/#controlling-with-usecalendar):
create it with the `useCalendar` hook and pass it with the `controller` prop to drive the displayed
date and level from outside, for example from a toolbar. The controller does not own the selected
value – keep using `value`/`onChange` for it:

<Demo data={MonthPickerDemos.controller} />

When the `controller` prop is set, the `date`, `defaultDate`, `onDateChange`, `level`, `defaultLevel`
and `onLevelChange` props are ignored – pass them to `useCalendar` instead.

## Accessibility

### Aria labels

Set the `ariaLabels` prop to specify `aria-label` attributes for next/previous controls:

```tsx
import { MonthPicker } from '@mantine/dates';

function Demo() {
  return (
    <MonthPicker
      ariaLabels={{
        nextDecade: 'Next decade',
        previousDecade: 'Previous decade',
        nextYear: 'Next year',
        previousYear: 'Previous year',
        yearLevelControl: 'Change to decade view',
      }}
    />
  );
}
```

### Year/month control aria-label

Use `getYearControlProps`/`getMonthControlProps` to customize the `aria-label` attribute:

```tsx
import dayjs from 'dayjs';
import { MonthPicker } from '@mantine/dates';

function Demo() {
  return (
    <MonthPicker
      getYearControlProps={(date) => ({
        'aria-label': `Select year ${dayjs(date).year()}`,
      })}
      getMonthControlProps={(date) => ({
        'aria-label': `Select month ${dayjs(date).format('YYYY/MM')}`,
      })}
    />
  );
}
```

### Keyboard interactions

Note that the following events will only trigger if focus is on a month control.
When arrow navigation reaches the edge of the grid, the calendar switches to the
previous/next year and focuses the corresponding month.

<KeyboardEventsTable
  data={[
    {
      key: 'ArrowRight',
      description: 'Focuses next non-disabled month, switches to the next year if needed',
    },
    {
      key: 'ArrowLeft',
      description: 'Focuses previous non-disabled month, switches to the previous year if needed',
    },
    {
      key: 'ArrowDown',
      description:
        'Focuses next non-disabled month in the same column, switches to the next year if needed',
    },
    {
      key: 'ArrowUp',
      description:
        'Focuses previous non-disabled month in the same column, switches to the previous year if needed',
    },
  ]}
/>

When `presets` are used, only one preset button is in the tab order. With focus on a preset,
`ArrowDown` and `ArrowUp` move focus between presets without selecting them, `Enter` or `Space`
selects the focused preset, and `Tab` moves focus to the calendar.

When the level is changed with the keyboard (for example, `Enter` on the month label), focus
moves to the label of the new level or to the grid control in the tab order if the new level
does not have a clickable label.
