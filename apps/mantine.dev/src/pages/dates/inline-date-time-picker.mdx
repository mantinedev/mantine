## DatePicker props

`InlineDateTimePicker` supports most of the [DatePicker](/dates/date-picker/) props.
Read through the [DatePicker](/dates/date-picker/) documentation to learn about all component features that are not listed on this page.

## Usage

`InlineDateTimePicker` renders a calendar with a time picker inline, without a dropdown.

## Controlling with useInlineDateTimePicker

`InlineDateTimePicker` component supports the [controller pattern](/guides/controllers). Use the `useInlineDateTimePicker` hook to manage `InlineDateTimePicker` state:

<Demo data={InlineDateTimePickerDemos.controller} />

```tsx
import { useState } from 'react';
import { InlineDateTimePicker, useInlineDateTimePicker } from '@mantine/dates';

function Demo() {
  const [value, setValue] = useState<string | null>(null);
  const controller = useInlineDateTimePicker({
    defaultDate: '2024-06-15', // -> date displayed when there is no value
    defaultTimeValue: '09:00', // -> time used when a date is picked with empty time inputs
    // date, onDateChange, level, defaultLevel, onLevelChange -> same as on useCalendar
    // time, onTimeChange, endTime, onEndTimeChange -> time inputs in controlled mode
  });

  // Navigation actions, same as useCalendar
  controller.next();
  controller.setLevel('month');

  // Time actions
  controller.setTime('10:30'); // -> sets the time input and the time of the value
  controller.setEndTime('18:00'); // -> end time with type="range"
  controller.focusTime('minutes'); // -> focuses a field of the time input
  controller.focusEndTime('hours');

  // Queries
  controller.getTime(); // -> time of the time input, also before a date is picked
  controller.getEndTime(); // -> time of the end time input with type="range"

  return (
    <InlineDateTimePicker value={value} onChange={setValue} controller={controller} />
  );
}
```

The controller does not own the selected value – keep using `value`/`onChange` (or your form
library) for it. It owns what the value cannot express: the time entered before a date is picked
and the end time of an incomplete range. `getTime` returns the time of the value once a date is
picked, and `setTime` updates it. `focusTime` called while the time inputs are not displayed (the
calendar is not on the month level) focuses the field when they are displayed.

When the `controller` prop is set, the `date`, `defaultDate`, `onDateChange`, `level`,
`defaultLevel`, `onLevelChange` and `defaultTimeValue` props are ignored – pass them to
`useInlineDateTimePicker` instead. The time inputs are driven through the controller, so
`timePickerProps` and `endTimePickerProps` do not accept a `controller`. The controller is typed as
`InlineDateTimePickerController` and its options as `InlineDateTimePickerControllerOptions`, both
exported from `@mantine/dates`.
