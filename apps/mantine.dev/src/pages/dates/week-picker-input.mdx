## WeekPicker props

`WeekPickerInput` supports most of the [WeekPicker](/dates/week-picker/) props.
Read through the [WeekPicker](/dates/week-picker/) documentation to learn about all component features that are not listed on this page.

## Controlling with useWeekPickerInput

`WeekPickerInput` component supports the [controller pattern](/guides/controllers). Use the `useWeekPickerInput` hook to manage `WeekPickerInput` state:

<Demo data={WeekPickerInputDemos.controller} />

Every time the dropdown opens, the displayed month is reset to the selected week (or to `defaultDate`
when there is no value) and the level is reset to `defaultLevel` (`'month'` by default). To open on a
different level or date, call `setLevel` or `setDate` right after `openDropdown`, as the demo above does.

The controller does not own the selected value – keep using `value`/`onChange` (or your form
library) for it. When the `controller` prop is set, the `date`, `defaultDate`, `onDateChange`, `level`, `defaultLevel`, `onLevelChange`, `popoverProps.opened` and
`popoverProps.onChange` props are ignored – pass them to `useWeekPickerInput` instead (`dropdownOpened` and
`onDropdownOpenedChange` replace `popoverProps.opened` and `popoverProps.onChange`).

`openDropdown` does nothing while the input is `disabled` or `readOnly`. With `type="range"`, closing
the dropdown when only the first week of the range is picked clears the value, whether the dropdown is
closed by the user or with `closeDropdown`.

If you only need the dropdown state, `popoverProps={{ opened, onChange }}` controls it without a
controller in every dropdown type (`popover`, `modal` and `drawer`): `onChange` is called on every open and close, including the input click and the close
after a pick, and the input keeps opening and closing the dropdown through it.

The controller is typed as `PickerInputController` and its options as `PickerInputControllerOptions`,
both exported from `@mantine/dates`. The same types are used by `DatePickerInput`, `MonthPickerInput`,
`YearPickerInput`, `WeekPickerInput` and `QuarterPickerInput`.

## Dropdown type

The dropdown opens in a bottom [Drawer](/core/drawer/) below `theme.breakpoints.sm` and in a
[Popover](/core/popover/) above. Set `dropdownType` to `'popover'`, `'modal'`, `'drawer'` or an object
with breakpoints:

<Demo data={WeekPickerInputDemos.dropdownType} />

Object keys can be `theme.breakpoints` keys or custom values in px, for example,
`{ base: 'drawer', 600: 'popover' }`. Use `popoverProps`, `modalProps` and `drawerProps` to pass props
down to the underlying component. If the viewport crosses a breakpoint while the dropdown is open,
the dropdown switches to the other type and a selection that was not applied yet is discarded.

## Submit button

In `drawer` and `modal` dropdowns, the value is applied only when the submit button is pressed, and
closing the dropdown discards the selection. Set `applyOnSubmit={false}` to apply the value on selection:

<Demo data={WeekPickerInputDemos.applyOnSubmit} />

- The label is `Save` by default – change it with the `submitButtonLabel` prop or the `submitButtonLabel`
  setting of [DatesProvider](/dates/getting-started/#datesprovider)
- `submitButtonProps` are passed down to the [Button](/core/button/)
- With `type="range"`, the button is disabled until both dates are selected

## Value format

`valueFormat` is a [dayjs format](https://day.js.org/docs/en/display/format) applied to both the first and the last day
of the week. The default value is `MMM D, YYYY`:

<Demo data={WeekPickerInputDemos.valueFormat} />

## Value formatter

`valueFormatter` is a more powerful alternative to the `valueFormat` prop.
It allows formatting the value label with a custom function.
The function is the same for all component types (`default`, `multiple` and `range`)
– you need to perform additional checks inside the function to handle different types.

Example of using a custom formatter function with `type="multiple"`:

<Demo data={WeekPickerInputDemos.valueFormatter} />

`getWeekFormatter(firstDayOfWeek)` exported from `@mantine/dates` returns the default formatter.
Use it in your own formatter, for example to add the ISO week number:

<Demo data={WeekPickerInputDemos.weekNumberFormatter} />

## Week controls

Week numbers are the only focusable elements of the calendar, days can be clicked with the mouse only.
Use `getWeekControlProps` to change `aria-label` or disable specific weeks,
see [WeekPicker](/dates/week-picker/) documentation for details.
