## Usage

`QuarterPicker` works the same way as [MonthPicker](/dates/month-picker/), but with quarters
instead of months. The value is a date string in `YYYY-MM-DD` format that points to the first day
of the selected quarter, for example `2026-04-01` for Q2 2026. Use `getQuarterStart` exported from
`@mantine/dates` to get the first day of the quarter for any date:

<Demo data={QuarterPickerDemos.usage} />

## Allow deselect

Set `allowDeselect` to allow users to deselect the currently selected quarter by clicking on it.
`allowDeselect` is disregarded when the `type` prop is `range` or `multiple`. When a quarter is
deselected, `onChange` is called with `null`.

<Demo data={QuarterPickerDemos.deselect} />

## Quarters range

Set `type="range"` to allow users to pick a quarters range. The value is a tuple of the first day of

## Single quarter in range

By default, it is not allowed to select a single quarter as a range – when the user clicks the same quarter a second time, it is deselected.
To change this behavior, set the `allowSingleDateInRange` prop. `allowSingleDateInRange` is ignored when the
`type` prop is not `range`.

<Demo data={QuarterPickerDemos.singleRange} />

## Presets

Use the `presets` prop to add custom quarter presets. Presets are displayed next to the calendar.
Any date inside the quarter can be used as a preset value.

<Demo data={QuarterPickerDemos.presets} />

`@mantine/dates` registers the [dayjs quarterOfYear and advancedFormat plugins](https://day.js.org/docs/en/plugin/quarter-of-year):
you can use `dayjs().startOf('quarter')` and the `Q` format token. To use the `quarter` unit with TypeScript,
extend dayjs with the `quarterOfYear` plugin in your code, as shown in the demo above.

To use `presets` with `type="range"`, define the value as a tuple of two dates:

<Demo data={QuarterPickerDemos.presetsRange} />

## Default date

Use the `defaultDate` prop to set the date value that will be used to determine which year should be displayed initially.
Only the year part of the value is used. Note that if you set the `date` prop, then the `defaultDate` value will be ignored.

<Demo data={QuarterPickerDemos.defaultDate} />

## Min and max date

Set the `minDate` and `maxDate` props to define minimum and maximum dates. Quarters that end before `minDate`
or start after `maxDate` are disabled. If the previous/next year is not available, then the corresponding control will be disabled.

<Demo data={QuarterPickerDemos.minMax} />

## Accessibility

### Aria labels

Set the `ariaLabels` prop to specify `aria-label` attributes for next/previous controls:

```tsx
import { QuarterPicker } from '@mantine/dates';

function Demo() {
  return (
    <QuarterPicker
      ariaLabels={{
        nextDecade: 'Next decade',
        previousDecade: 'Previous decade',
        nextYear: 'Next year',
        previousYear: 'Previous year',
        yearLevelControl: 'Change to decade view',
      }}
    />
  );
}
```

### Year/quarter control aria-label

Use `getYearControlProps`/`getQuarterControlProps` to customize the `aria-label` attribute:

```tsx
import dayjs from 'dayjs';
import { QuarterPicker } from '@mantine/dates';

function Demo() {
  return (
    <QuarterPicker
      getYearControlProps={(date) => ({
        'aria-label': `Select year ${dayjs(date).year()}`,
      })}
      getQuarterControlProps={(date) => ({
        'aria-label': `Select ${dayjs(date).format('[Q]Q YYYY')}`,
      })}
    />
  );
}
```

### Keyboard interactions

Note that the following events will only trigger if focus is on a quarter control.
When arrow navigation reaches the edge of the grid, the calendar switches to the
previous/next year and focuses the corresponding quarter.

<KeyboardEventsTable
  data={[
    { key: 'ArrowRight', description: 'Focuses next non-disabled quarter, switches to the next year if needed' },
    { key: 'ArrowLeft', description: 'Focuses previous non-disabled quarter, switches to the previous year if needed' },
    { key: 'ArrowDown', description: 'Focuses the same quarter of the next year' },
    { key: 'ArrowUp', description: 'Focuses the same quarter of the previous year' },
  ]}
/>

When `presets` are used, only one preset button is in the tab order. With focus on a preset,
`ArrowDown` and `ArrowUp` move focus between presets without selecting them, `Enter` or `Space`
selects the focused preset, and `Tab` moves focus to the calendar.

When the level is changed with the keyboard (for example, `Enter` on the year label), focus
moves to the label of the new level or to the grid control in the tab order if the new level
does not have a clickable label.
