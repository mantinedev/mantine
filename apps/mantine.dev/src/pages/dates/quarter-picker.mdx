## Usage

`QuarterPicker` works the same way as [MonthPicker](/dates/month-picker/), but with quarters instead of months.
The value is a date string in `YYYY-MM-DD` format that points to the first day of the selected quarter, for example `2026-04-01` for Q2 2026.
Use `getQuarterStart` exported from `@mantine/dates` to get the first day of the quarter for any date:

<Demo data={QuarterPickerDemos.usage} />

Set `allowDeselect` to allow users to deselect the selected quarter by clicking on it, `onChange` is called with `null`.
`allowDeselect` is ignored when the `type` prop is `range` or `multiple`:

## Presets

Use the `presets` prop to add custom quarter presets. Presets are displayed next to the calendar.
Any date inside the quarter can be used as a preset value.
To use the dayjs `quarter` unit with TypeScript, extend dayjs with the [quarterOfYear plugin](https://day.js.org/docs/en/plugin/quarter-of-year) as shown in the demo:

## Controlling with useCalendar

`QuarterPicker` component supports the [controller pattern](/guides/controllers). Use the `useCalendar` hook to manage the displayed date and level.
The controller does not own the selected value, keep using `value` and `onChange` for it.
When the `controller` prop is set, the date and level props of the component are ignored, pass them to `useCalendar` instead:

<Demo data={QuarterPickerDemos.controller} />

## Accessibility

### Aria labels

Set the `ariaLabels` prop to specify `aria-label` attributes for next/previous controls:

```tsx
import { QuarterPicker } from '@mantine/dates';

function Demo() {
  return (
    <QuarterPicker
      ariaLabels={{
        nextDecade: 'Next decade',
        previousDecade: 'Previous decade',
        nextYear: 'Next year',
        previousYear: 'Previous year',
        yearLevelControl: 'Change to decade view',
      }}
    />
  );
}
```

### Year/quarter control aria-label

Use `getYearControlProps`/`getQuarterControlProps` to customize the `aria-label` attribute:

```tsx
import dayjs from 'dayjs';
import { QuarterPicker } from '@mantine/dates';

function Demo() {
  return (
    <QuarterPicker
      getYearControlProps={(date) => ({
        'aria-label': `Select year ${dayjs(date).year()}`,
      })}
      getQuarterControlProps={(date) => ({
        'aria-label': `Select ${dayjs(date).format('[Q]Q YYYY')}`,
      })}
    />
  );
}
```

### Keyboard interactions

The following events trigger only when focus is on a quarter control.

<KeyboardEventsTable
  data={[
    { key: 'ArrowRight', description: 'Focuses next non-disabled quarter, switches to the next year if needed' },
    { key: 'ArrowLeft', description: 'Focuses previous non-disabled quarter, switches to the previous year if needed' },
    { key: 'ArrowDown', description: 'Focuses the same quarter of the next year' },
    { key: 'ArrowUp', description: 'Focuses the same quarter of the previous year' },
  ]}
/>

When `presets` are used, only one preset button is in the tab order.
`ArrowDown` and `ArrowUp` move focus between presets, `Enter` or `Space` selects the focused preset and `Tab` moves focus to the calendar.
