## Usage

`MaskedDateInput` is similar to [TimePicker](/dates/time-picker) but for dates.
It renders masked fields for day, month and year with an optional calendar dropdown:

<Demo data={MaskedDateInputDemos.usage} />

## Controlled

The value is a string in `YYYY-MM-DD` format, or `YYYY-MM-DD HH:mm:ss` when `withTime` is set.
`null` represents no value. `onChange` is called when all fields are filled or when all fields are cleared:

<Demo data={MaskedDateInputDemos.controlled} />

## Controlling with useMaskedDateInput

`MaskedDateInput` component supports the [controller pattern](/guides/controllers). Use the `useMaskedDateInput` hook to manage `MaskedDateInput` state.
When the `controller` prop is set, the value, time, format and date limit props of the component are ignored, pass them to `useMaskedDateInput` instead:

<Demo data={MaskedDateInputDemos.controller} />

`useMaskedDateInput` accepts the state options that `MaskedDateInput` accepts as props, and returns actions and queries:

```tsx
import { MaskedDateInput, useMaskedDateInput } from '@mantine/dates';

function Demo() {
  const controller = useMaskedDateInput({
    defaultValue: '2024-03-15', // -> uncontrolled initial value
    // value, onChange -> controlled state, same as on MaskedDateInput
    // withTime, withSeconds, format, amPmLabels, minDate, maxDate, pasteSplit -> same as on MaskedDateInput
  });

  // Actions
  controller.setValue('2024-03-15'); // -> sets all fields, a date without time keeps the time fields
  controller.setValue(null); // -> clears all fields
  controller.setDay(15);
  controller.setMonth(3); // -> 1-12
  controller.setYear(2024);
  controller.setHours(14);
  controller.setMinutes(30);
  controller.setSeconds(0);
  controller.setAmPm('pm'); // -> 'am' | 'pm' | null
  controller.clear(); // -> clears all fields and focuses the first field of fieldsOrder
  controller.focus('year'); // -> 'day' | 'month' | 'year' | 'hours' | 'minutes' | 'seconds' | 'amPm'

  // Queries
  controller.getValue(); // -> complete value, null if it is not complete or outside of minDate/maxDate
  controller.getDay(); // -> number | null
  controller.getMonth(); // -> number | null
  controller.getYear(); // -> number | null
  controller.getHours(); // -> number | null
  controller.getMinutes(); // -> number | null
  controller.getSeconds(); // -> number | null
  controller.getAmPm(); // -> 'am' | 'pm' | null, always null in 24h format
  controller.hasValue(); // -> boolean, true if at least one field has a value

  return <MaskedDateInput controller={controller} />;
}
```

## Usage with forms

A controller and `form.getInputProps()` cannot be spread on the same component: the controller ignores `value` and `onChange`.
Instead, wrap `MaskedDateInput` in a component that owns the controller and bind the form to that component, see the [controllers guide](/guides/controllers#usage-with-forms).
A partially entered date is `null` for the form, use `controller.hasValue()` and the field queries to report it with a specific message:

## Get refs

Every field has a ref prop, for example `dayRef` or `hoursRef`, to get the ref of its input:

```tsx
import { useRef } from 'react';
import { MaskedDateInput } from '@mantine/dates';

function Demo() {
  const dayRef = useRef<HTMLInputElement>(null);
  const monthRef = useRef<HTMLInputElement>(null);
  const yearRef = useRef<HTMLInputElement>(null);

  return (
    <MaskedDateInput
      dayRef={dayRef}
      monthRef={monthRef}
      yearRef={yearRef}
    />
  );
}
```

## onFocus and onBlur

`onFocus` is called when one of the inputs receives focus and `onBlur` is called when focus
leaves all inputs:

```tsx
import { MaskedDateInput } from '@mantine/dates';

function Demo() {
  return (
    <MaskedDateInput
      onFocus={() => console.log('Focused')}
      onBlur={() => console.log('Blurred')}
    />
  );
}
```

## Accessibility

Set a label for each field with the corresponding prop, and an `aria-label` for the clear button when `clearable` is set:

```tsx
import { MaskedDateInput } from '@mantine/dates';

function Demo() {
  return (
    <MaskedDateInput
      dayInputLabel="Day"
      monthInputLabel="Month"
      yearInputLabel="Year"
      hoursInputLabel="Hours"
      minutesInputLabel="Minutes"
      secondsInputLabel="Seconds"
      amPmInputLabel="AM/PM"
      clearButtonProps={{ 'aria-label': 'Clear date' }}
    />
  );
}
```
