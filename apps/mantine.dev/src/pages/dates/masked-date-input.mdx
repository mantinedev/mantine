## Usage

`MaskedDateInput` is similar to [TimePicker](/dates/time-picker) but for dates.
It provides individual masked input fields for day, month, and year with an optional
calendar dropdown for date selection.

<Demo data={MaskedDateInputDemos.usage} />

## Controlled

The `MaskedDateInput` value is a string in `YYYY-MM-DD` format (for example `2000-06-15`).
When `withTime` is set, the value uses `YYYY-MM-DD HH:mm:ss` format (for example `2000-06-15 14:30:00`).
`null` is used to represent no value. The `onChange` function is called when all fields are filled
or when all fields are cleared.

## Controlling with useMaskedDateInput

`value`/`defaultValue`/`onChange` report only complete dates: while the user is halfway through
entering a date, `onChange` is called with `null`, so from the outside every incomplete state looks
the same. Create a controller with the `useMaskedDateInput` hook and pass it to `MaskedDateInput`
with the `controller` prop to read the individual fields, move focus between them and set or clear
the value from anywhere in your application. The [Controllers](/guides/controllers) guide covers how
the pattern works across all components:

<Demo data={MaskedDateInputDemos.controller} />

`useMaskedDateInput` accepts the state options that `MaskedDateInput` accepts as props, and returns
the current state, actions and queries:

```tsx
import { MaskedDateInput, useMaskedDateInput } from '@mantine/dates';

function Demo() {
  const controller = useMaskedDateInput({
    defaultValue: '2024-03-15', // -> uncontrolled initial value
    // value, onChange -> controlled state, same as on MaskedDateInput
    // withTime, withSeconds, format, amPmLabels, minDate, maxDate, pasteSplit -> same as on MaskedDateInput
  });

  // Actions
  controller.setValue('2024-03-15'); // -> sets all fields, a date without time keeps the time fields
  controller.setValue(null); // -> clears all fields
  controller.setDay(15);
  controller.setMonth(3); // -> 1-12
  controller.setYear(2024);
  controller.setHours(14);
  controller.setMinutes(30);
  controller.setSeconds(0);
  controller.setAmPm('PM');
  controller.clear(); // -> clears all fields and focuses the first field of fieldsOrder
  controller.focus('year'); // -> 'day' | 'month' | 'year' | 'hours' | 'minutes' | 'seconds' | 'amPm'

  // Queries
  controller.getValue(); // -> complete value, null if it is not complete or outside of minDate/maxDate
  controller.getDay(); // -> number | null
  controller.getMonth(); // -> number | null
  controller.getYear(); // -> number | null
  controller.getHours(); // -> number | null
  controller.getMinutes(); // -> number | null
  controller.getSeconds(); // -> number | null
  controller.getAmPm(); // -> string | null, always null in 24h format
  controller.hasValue(); // -> boolean, true if at least one field has a value

  return <MaskedDateInput controller={controller} />;
}
```

The controller owns the state, so when the `controller` prop is set, the `value`, `defaultValue`,
`onChange`, `withTime`, `withSeconds`, `format`, `amPmLabels`, `minDate`, `maxDate` and `pasteSplit`
props of `MaskedDateInput` are ignored – pass them to `useMaskedDateInput` instead. `withTime`,
`withSeconds`, `format` and `amPmLabels` also decide which fields are rendered, and `minDate` and
`maxDate` also limit the calendar dropdown.

Options that reach `MaskedDateInput` through `theme.components.MaskedDateInput.defaultProps` do not
reach a controller you create yourself – pass them to `useMaskedDateInput` as well.

`focus` is a no-op until a `MaskedDateInput` is mounted with the controller, because it works on the
fields that component renders.

## Usage with forms

`form.getInputProps()` returns `value`, `onChange`, `error`, `onFocus` and `onBlur`, which bind to
the props of `MaskedDateInput`. When the `controller` prop is set, the `value` and `onChange` props
are ignored, so a controller and `form.getInputProps()` cannot be spread on the same component.
Instead, create a component that accepts the same props as `MaskedDateInput`, passes the props that
the controller supersedes (`value`, `defaultValue`, `onChange`, `withTime`, `withSeconds`, `format`,
`amPmLabels`, `minDate`, `maxDate` and `pasteSplit`) to `useMaskedDateInput` and forwards the rest to
`MaskedDateInput`. The form binds to the props of that component, and the component owns the
controller. `error`, `onFocus` and `onBlur` reach `MaskedDateInput` as usual, so validation errors and
touched/dirty tracking work without extra code:

<Demo data={MaskedDateInputDemos.form} />

The controller adds what the form cannot see on its own: a partially entered date is `null` for the
form, so validation reports it as missing, while `controller.hasValue()` lets the field replace that
error with a more specific message.

Use `mode: 'uncontrolled'` and set `key={form.key('birthday')}` on the component that calls
`useMaskedDateInput`. In this mode `form.reset()` and `form.setFieldValue()` remount the field, and
the controller with it, so a partially entered date is cleared along with the value. In
`mode: 'controlled'`, the form can only change the `value` prop: when the user has entered a part of
a date, the form value is `null` before and after `form.reset()`, so the controller receives no
change and the partial entry stays on screen. See the
[Controllers guide](/guides/controllers#usage-with-forms) for the details of the pattern.

## Get refs

Use `dayRef`, `monthRef`, `yearRef`, `hoursRef`, `minutesRef`, `secondsRef` and `amPmRef` props
to get refs of the inner inputs:

```tsx
import { useRef } from 'react';
import { MaskedDateInput } from '@mantine/dates';

function Demo() {
  const dayRef = useRef<HTMLInputElement>(null);
  const monthRef = useRef<HTMLInputElement>(null);
  const yearRef = useRef<HTMLInputElement>(null);

  return (
    <MaskedDateInput
      dayRef={dayRef}
      monthRef={monthRef}
      yearRef={yearRef}
    />
  );
}
```

## onFocus and onBlur

`onFocus` is called when one of the inputs receives focus and `onBlur` is called when focus
leaves all inputs:

```tsx
import { MaskedDateInput } from '@mantine/dates';

function Demo() {
  return (
    <MaskedDateInput
      onFocus={() => console.log('Focused')}
      onBlur={() => console.log('Blurred')}
    />
  );
}
```

## Accessibility

Set `aria-label` for each field using the corresponding props. Also set an `aria-label` for the
clear button if `clearable` is used:

```tsx
import { MaskedDateInput } from '@mantine/dates';

function Demo() {
  return (
    <MaskedDateInput
      dayInputLabel="Day"
      monthInputLabel="Month"
      yearInputLabel="Year"
      hoursInputLabel="Hours"
      minutesInputLabel="Minutes"
      secondsInputLabel="Seconds"
      amPmInputLabel="AM/PM"
      clearButtonProps={{ 'aria-label': 'Clear date' }}
    />
  );
}
```
