## QuarterPicker props

`QuarterPickerInput` supports most of the [QuarterPicker](/dates/quarter-picker/) props.
Features that are not listed on this page are documented there.

## Controlling with useQuarterPickerInput

`QuarterPickerInput` component supports the [controller pattern](/guides/controllers). Use the `useQuarterPickerInput` hook to manage `QuarterPickerInput` state.
The controller does not own the selected value, keep using `value` and `onChange` for it.
When the `controller` prop is set, the date, level and dropdown state props of the component are ignored, pass them to `useQuarterPickerInput` instead.

The dropdown resets the displayed date and level every time it opens.
To open it on another level or date, call `setLevel` or `setDate` after `openDropdown`:

<Demo data={QuarterPickerInputDemos.controller} />

## Dropdown type

By default, the dropdown is a bottom [Drawer](/core/drawer/) below `theme.breakpoints.sm` and a popover above.
Set `dropdownType` to `popover`, `modal`, `drawer` or an object with breakpoints.
Use `popoverProps`, `modalProps` and `drawerProps` to pass props down to the underlying component:

<Demo data={QuarterPickerInputDemos.dropdownType} />

## Submit button

In `drawer` and `modal` dropdowns, the value is applied when the submit button is pressed.
Set `applyOnSubmit={false}` to apply the value on selection.
Change the button label with the `submitButtonLabel` prop or the same [DatesProvider](/dates/getting-started/#datesprovider) setting, and pass other props with `submitButtonProps`:

<Demo data={QuarterPickerInputDemos.applyOnSubmit} />

## Value format

Use the `valueFormat` prop to change the [dayjs format](https://day.js.org/docs/en/display/format) of the value label.
The default format is `[Q]Q YYYY`, for example `Q2 2026`:

<Demo data={QuarterPickerInputDemos.valueFormat} />

## Value formatter

`valueFormatter` formats the value label with a custom function.
The same function is called for all `type` values, so check the value type inside it.
