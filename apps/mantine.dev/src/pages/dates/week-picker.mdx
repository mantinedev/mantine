## Usage

`WeekPicker` renders the same calendar as [DatePicker](/dates/date-picker/), but selects whole weeks:
hovering any day highlights its week and clicking selects it. Week numbers are always displayed.

<Demo data={WeekPickerDemos.usage} />

## Week value

The value is a date string in `YYYY-MM-DD` format that points to the first day of the selected week.
The first day of the week is determined by the `firstDayOfWeek` prop or by the
[DatesProvider](/dates/getting-started/) settings (Monday by default). Use `getStartOfWeek` and `getEndOfWeek`
exported from `@mantine/dates` to get the week boundaries from the value.

<Demo data={WeekPickerDemos.weekValue} />

## Allow deselect

Set `allowDeselect` to allow users to deselect the currently selected week by clicking on it.
`allowDeselect` is disregarded when the `type` prop is `range` or `multiple`. When a week is
deselected, `onChange` is called with `null`.

<Demo data={WeekPickerDemos.deselect} />

## Multiple weeks

Set `type="multiple"` to allow users to pick multiple weeks:

<Demo data={WeekPickerDemos.multiple} />

## Weeks range

Set `type="range"` to allow users to pick a weeks range. The value is a tuple of the first day of the
first week and the first day of the last week:

<Demo data={WeekPickerDemos.range} />

## Single week in range

By default, it is not allowed to select a single week as a range – when the user clicks the same week a second time, it is deselected.
To change this behavior, set the `allowSingleDateInRange` prop. `allowSingleDateInRange` is ignored when the
`type` prop is not `range`.

<Demo data={WeekPickerDemos.singleRange} />

## First day of week

Set the `firstDayOfWeek` prop to change which day starts the week (0 – Sunday, 6 – Saturday). It changes both the
calendar layout and the value that is emitted:

<Demo data={WeekPickerDemos.firstDayOfWeek} />

## Week controls

Every week number is a button that selects its week. Days are not focusable, they can only be
clicked with the mouse. Use `getWeekControlProps` to pass props to week controls based on the first
date of the week, for example to disable specific weeks:

<Demo data={WeekPickerDemos.weekControlProps} />

## Presets

Use the `presets` prop to add custom week presets. Presets are displayed next to the calendar.
Any date inside the week can be used as a preset value:

## Default date

Use the `defaultDate` prop to set the date value that will be used to determine which month should be displayed initially.
Note that if you set the `date` prop, then the `defaultDate` value will be ignored.

<Demo data={WeekPickerDemos.defaultDate} />

## Hide outside dates

Set `hideOutsideDates` to hide days of the selected week that are outside of the displayed month.
When `numberOfColumns` is larger than 1, outside dates are hidden by default,
set `hideOutsideDates={false}` to display whole weeks:

<Demo data={WeekPickerDemos.hideOutsideDates} />

## Controlling with useCalendar

`WeekPicker` accepts the same controller as [Calendar](/dates/calendar/#controlling-with-usecalendar):
create it with the `useCalendar` hook and pass it with the `controller` prop to drive the displayed
date and level from outside, for example from a toolbar. The controller does not own the selected
value – keep using `value`/`onChange` for it:

<Demo data={WeekPickerDemos.controller} />

When the `controller` prop is set, the `date`, `defaultDate`, `onDateChange`, `level`, `defaultLevel`
and `onLevelChange` props are ignored – pass them to `useCalendar` instead.

## Min and max date

Set the `minDate` and `maxDate` props to define minimum and maximum dates. A week can be selected
if it contains at least one enabled day. Note that the value is the first day of the week,
it can be before `minDate`.

## Accessibility

### Aria labels

Set the `ariaLabels` prop to specify `aria-label` attributes for next/previous controls:

```tsx
import { WeekPicker } from '@mantine/dates';

function Demo() {
  return (
    <WeekPicker
      ariaLabels={{
        nextDecade: 'Next decade',
        previousDecade: 'Previous decade',
        nextYear: 'Next year',
        previousYear: 'Previous year',
        nextMonth: 'Next month',
        previousMonth: 'Previous month',
        yearLevelControl: 'Change to decade view',
        monthLevelControl: 'Change to year view',
      }}
    />
  );
}
```

### Week control aria-label

By default, week controls have an `aria-label` with the first and the last day of the week. Use `getWeekControlProps` to customize it:

```tsx
import { WeekPicker } from '@mantine/dates';

function Demo() {
  return (
    <WeekPicker
      getWeekControlProps={(weekStart) => ({
        'aria-label': `Select week starting on ${weekStart}`,
      })}
    />
  );
}
```

### Keyboard interactions

Only week controls (week numbers) can be focused with the keyboard.

<KeyboardEventsTable
  data={[
    { key: 'ArrowDown', description: 'Focuses next non-disabled week control, switches to the next month if needed' },
    { key: 'ArrowUp', description: 'Focuses previous non-disabled week control, switches to the previous month if needed' },
    { key: 'Enter/Space', description: 'Selects the focused week' },
  ]}
/>

When `presets` are used, only one preset button is in the tab order. With focus on a preset,
`ArrowDown` and `ArrowUp` move focus between presets without selecting them, `Enter` or `Space`
selects the focused preset, and `Tab` moves focus to the calendar.

When the level is changed with the keyboard (for example, `Enter` on the month label), focus
moves to the label of the new level or to the grid control in the tab order if the new level
does not have a clickable label.
