## Usage

`WeekPicker` renders the same calendar as [DatePicker](/dates/date-picker/), but selects whole weeks:
hovering any day highlights its week and clicking selects it. Week numbers are displayed by default.

<Demo data={WeekPickerDemos.usage} />

## Week value

The value is a date string in `YYYY-MM-DD` format that points to the first day of the selected week.
The first day of the week is determined by the `firstDayOfWeek` prop or by the
[DatesProvider](/dates/getting-started/) settings (Monday by default). Use `getStartOfWeek` and `getEndOfWeek`
exported from `@mantine/dates` to get the week boundaries from the value. If you pass a controlled value that
falls in the middle of a week, the whole week that contains it is highlighted.

<Demo data={WeekPickerDemos.weekValue} />

## Allow deselect

Set `allowDeselect` to allow users to deselect the currently selected week by clicking on it.
`allowDeselect` is disregarded when the `type` prop is `range` or `multiple`. When a week is
deselected, `onChange` is called with `null`.

<Demo data={WeekPickerDemos.deselect} />

## Multiple weeks

Set `type="multiple"` to allow users to pick multiple weeks:

## Weeks range

Set `type="range"` to allow users to pick a weeks range. The value is a tuple of the first day of the
first week and the first day of the last week:

<Demo data={WeekPickerDemos.range} />

## Single week in range

By default, it is not allowed to select a single week as a range – when the user clicks the same week a second time, it is deselected.
To change this behavior, set the `allowSingleDateInRange` prop. `allowSingleDateInRange` is ignored when the
`type` prop is not `range`.

<Demo data={WeekPickerDemos.singleRange} />

## First day of week

Set the `firstDayOfWeek` prop to change which day starts the week (0 – Sunday, 6 – Saturday). It changes both the
calendar layout and the value that is emitted:

<Demo data={WeekPickerDemos.firstDayOfWeek} />

## Week controls

Week numbers are always displayed and act as controls: every week number is a button that
selects its week. Days are not focusable, they can only be clicked with the mouse and serve as
a visual representation of the value. Use `getWeekControlProps` to pass props to week controls
based on the first date of the week, for example to change the `aria-label` or disable specific weeks:

<Demo data={WeekPickerDemos.weekControlProps} />

## Presets

Use the `presets` prop to add custom week presets. Presets are displayed next to the calendar.
Preset values are normalized to the first day of their week before `onChange` is called, so any date
inside the week can be used as a preset value:

<Demo data={WeekPickerDemos.presets} />

To use `presets` with `type="range"`, define the value as a tuple of two dates:

<Demo data={WeekPickerDemos.presetsRange} />

## Default date

Use the `defaultDate` prop to set the date value that will be used to determine which month should be displayed initially.
Note that if you set the `date` prop, then the `defaultDate` value will be ignored.

<Demo data={WeekPickerDemos.defaultDate} />

## Hide outside dates

Days that belong to the selected week but are outside of the displayed month are highlighted too. Set `hideOutsideDates`
to hide them. When `numberOfColumns` is larger than 1, outside dates are hidden by default and a week that spans two
months is displayed partially; set `hideOutsideDates={false}` to always display whole weeks:

<Demo data={WeekPickerDemos.hideOutsideDates} />

## Min and max date

Set the `minDate` and `maxDate` props to define minimum and maximum dates. Days outside of the range are disabled,
but a week is still selectable as long as it contains at least one enabled day. Note that the emitted value is
the first day of the week, which can be before `minDate` when a week starts outside the allowed range but contains
enabled days.

<Demo data={WeekPickerDemos.minMax} />

## Exclude dates

`excludeDate` disables individual days. A week that contains enabled days can still be selected through those days:

## Accessibility

### Aria labels

Set the `ariaLabels` prop to specify `aria-label` attributes for next/previous controls:

```tsx
import { WeekPicker } from '@mantine/dates';

function Demo() {
  return (
    <WeekPicker
      ariaLabels={{
        nextDecade: 'Next decade',
        previousDecade: 'Previous decade',
        nextYear: 'Next year',
        previousYear: 'Previous year',
        nextMonth: 'Next month',
        previousMonth: 'Previous month',
        yearLevelControl: 'Change to decade view',
        monthLevelControl: 'Change to year view',
      }}
    />
  );
}
```

### Week control aria-label

By default, week controls have an `aria-label` with the first and the last day of the week. Use `getWeekControlProps` to customize it:

```tsx
import { WeekPicker } from '@mantine/dates';

function Demo() {
  return (
    <WeekPicker
      getWeekControlProps={(weekStart) => ({
        'aria-label': `Select week starting on ${weekStart}`,
      })}
    />
  );
}
```

### Keyboard interactions

Only week controls (week numbers) can be focused with the keyboard. The control of the selected week
is in the tab order; if no week is selected, the control of the current week or the first enabled week is used.
