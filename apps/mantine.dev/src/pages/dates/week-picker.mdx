## Usage

`WeekPicker` renders the same calendar as [DatePicker](/dates/date-picker/), but selects whole weeks.
Hovering any day highlights its week and clicking selects it:

<Demo data={WeekPickerDemos.usage} />

## Week value

The value is a date string in `YYYY-MM-DD` format that points to the first day of the selected week.
The first day of the week is set by the `firstDayOfWeek` prop or by [DatesProvider](/dates/getting-started/), Monday by default.
Use `getStartOfWeek` and `getEndOfWeek` exported from `@mantine/dates` to get the week boundaries from the value:

<Demo data={WeekPickerDemos.weekValue} />

## Allow deselect

Set `allowDeselect` to allow users to deselect the selected week by clicking on it, `onChange` is called with `null`.
`allowDeselect` is ignored when the `type` prop is `range` or `multiple`:

<Demo data={WeekPickerDemos.deselect} />

## Multiple weeks

Set `type="multiple"` to allow users to pick multiple weeks:

<Demo data={WeekPickerDemos.multiple} />

## Weeks range

Set `type="range"` to allow users to pick a weeks range. The value is a tuple of the first day of the
first week and the first day of the last week:

<Demo data={WeekPickerDemos.range} />

## Single week in range

By default, clicking the same week twice deselects it, a single week cannot be selected as a range.
Set `allowSingleDateInRange` to allow it:

<Demo data={WeekPickerDemos.singleRange} />

## First day of week

Set the `firstDayOfWeek` prop to change which day starts the week, 0 is Sunday and 6 is Saturday.
It changes both the calendar layout and the emitted value:

<Demo data={WeekPickerDemos.firstDayOfWeek} />

## Week controls

Every week number is a button that selects its week, days can be clicked with the mouse only.
Use `getWeekControlProps` to pass props to week controls, for example to disable specific weeks:

<Demo data={WeekPickerDemos.weekControlProps} />

## Presets

Use the `presets` prop to add custom week presets. Presets are displayed next to the calendar.
Any date inside the week can be used as a preset value:

<Demo data={WeekPickerDemos.presets} />

To use `presets` with `type="range"`, define the value as a tuple of two dates:

## Default date

Use the `defaultDate` prop to set the month that is displayed initially.
`defaultDate` is ignored when the `date` prop is set:

<Demo data={WeekPickerDemos.defaultDate} />

## Hide outside dates

Set `hideOutsideDates` to hide days of the selected week that are outside of the displayed month.
When `numberOfColumns` is larger than 1, outside dates are hidden by default,
set `hideOutsideDates={false}` to display whole weeks:

<Demo data={WeekPickerDemos.hideOutsideDates} />

## Controlling with useCalendar

`WeekPicker` component supports the [controller pattern](/guides/controllers). Use the `useCalendar` hook to manage the displayed date and level.
The controller does not own the selected value, keep using `value` and `onChange` for it.
When the `controller` prop is set, the date and level props of the component are ignored, pass them to `useCalendar` instead:

<Demo data={WeekPickerDemos.controller} />

## Min and max date

Set the `minDate` and `maxDate` props to define minimum and maximum dates.
A week can be selected if it contains at least one enabled day, so the value can be before `minDate`:

## Accessibility

### Aria labels

Set the `ariaLabels` prop to specify `aria-label` attributes for next/previous controls:

```tsx
import { WeekPicker } from '@mantine/dates';

function Demo() {
  return (
    <WeekPicker
      ariaLabels={{
        nextDecade: 'Next decade',
        previousDecade: 'Previous decade',
        nextYear: 'Next year',
        previousYear: 'Previous year',
        nextMonth: 'Next month',
        previousMonth: 'Previous month',
        yearLevelControl: 'Change to decade view',
        monthLevelControl: 'Change to year view',
      }}
    />
  );
}
```

### Week control aria-label

By default, the `aria-label` of a week control contains the first and the last day of the week.
Use `getWeekControlProps` to change it:

```tsx
import { WeekPicker } from '@mantine/dates';

function Demo() {
  return (
    <WeekPicker
      getWeekControlProps={(weekStart) => ({
        'aria-label': `Select week starting on ${weekStart}`,
      })}
    />
  );
}
```

### Keyboard interactions

Only week controls (week numbers) can be focused with the keyboard.

<KeyboardEventsTable
  data={[
    { key: 'ArrowDown', description: 'Focuses next non-disabled week control, switches to the next month if needed' },
    { key: 'ArrowUp', description: 'Focuses previous non-disabled week control, switches to the previous month if needed' },
    { key: 'Enter/Space', description: 'Selects the focused week' },
  ]}
/>

When `presets` are used, only one preset button is in the tab order.
`ArrowDown` and `ArrowUp` move focus between presets, `Enter` or `Space` selects the focused preset and `Tab` moves focus to the calendar.
