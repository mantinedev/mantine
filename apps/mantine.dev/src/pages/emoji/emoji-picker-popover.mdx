## Usage

`EmojiPickerPopover` renders [EmojiPicker](/emoji/emoji-picker) in a popover.
The child element is the popover target, clicking it toggles the popover:

<Demo data={EmojiPickerPopoverDemos.usage} />

## Close on select

By default, the popover closes when an emoji is selected. Set `closeOnSelect={false}` to keep it open:

<Demo data={EmojiPickerPopoverDemos.closeOnSelect} />

## EmojiPicker props

All `EmojiPicker` props are supported on `EmojiPickerPopover`, for example to change the number of columns or hide sections:

<Demo data={EmojiPickerPopoverDemos.pickerProps} />

## onEmojiSelect

`onEmojiSelect` is called with the full emoji object when an emoji is selected:

```tsx
import { useState } from 'react';
import { ActionIcon } from '@mantine/core';
import { EmojiPickerPopover } from '@mantine/emoji';
import { emojiData } from './emoji-data';

function Demo() {
  const [emoji, setEmoji] = useState<string | null>(null);

  return (
    <EmojiPickerPopover data={emojiData} onEmojiSelect={(e) => setEmoji(e.emoji)}>
      <ActionIcon variant="default" size="lg">
        {emoji || '☺'}
      </ActionIcon>
    </EmojiPickerPopover>
  );
}
```

## Controlled state

Use `opened` and `onOpenedChange` props to control the popover state.
A controlled popover is not toggled by the target click, add an `onClick` handler to the target:

```tsx
import { useState } from 'react';
import { ActionIcon } from '@mantine/core';
import { EmojiPickerPopover } from '@mantine/emoji';
import { emojiData } from './emoji-data';

function Demo() {
  const [opened, setOpened] = useState(false);

  return (
    <EmojiPickerPopover
      data={emojiData}
      opened={opened}
      onOpenedChange={setOpened}
    >
      <ActionIcon variant="default" size="lg" onClick={() => setOpened((o) => !o)}>
        ☺
      </ActionIcon>
    </EmojiPickerPopover>
  );
}
```

## Popover props

Use the `popoverProps` prop to pass props to the underlying `Popover` component:

```tsx
import { ActionIcon } from '@mantine/core';
import { EmojiPickerPopover } from '@mantine/emoji';
import { emojiData } from './emoji-data';

function Demo() {
  return (
    <EmojiPickerPopover
      data={emojiData}
      popoverProps={{ position: 'bottom-end', shadow: 'md', offset: 8 }}
    >
      <ActionIcon variant="default" size="lg">☺</ActionIcon>
    </EmojiPickerPopover>
  );
}
```
