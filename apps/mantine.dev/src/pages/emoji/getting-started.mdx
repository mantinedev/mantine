
## Emoji data

`@mantine/emoji` does not bundle emoji data — you need to supply it via the `data` prop.
The package provides adapter functions for the two most popular emoji data sources:

### Using @emoji-mart/data

Install the data package:

<InstallScript packages="@emoji-mart/data" />

Then use the adapter to convert the data:

```tsx
import data from '@emoji-mart/data';
import { emojiMartAdapter, EmojiPicker } from '@mantine/emoji';

const emojiData = emojiMartAdapter(data);

function Demo() {
  return <EmojiPicker data={emojiData} />;
}
```

### Using emojibase-data

Install the data packages:

<InstallScript packages="emojibase-data" />

Then use the adapter to convert the data:

```tsx
import data from 'emojibase-data/en/data.json';
import messages from 'emojibase-data/en/messages.json';
import { emojibaseAdapter, EmojiPicker } from '@mantine/emoji';

const emojiData = emojibaseAdapter(data, messages);

function Demo() {
  return <EmojiPicker data={emojiData} />;
}
```

### Custom data

You can also provide data directly using the `EmojiPickerData` interface:

```tsx
import { EmojiPicker, EmojiPickerData } from '@mantine/emoji';

const data: EmojiPickerData = {
  categories: [
    { id: 'people', label: 'Smileys & People', emojis: ['grinning', 'wave'] },
  ],
  emojis: {
    grinning: {
      id: 'grinning',
      name: 'Grinning Face',
      keywords: ['happy', 'smile'],
      emoji: '😀',
    },
    wave: {
      id: 'wave',
      name: 'Waving Hand',
      keywords: ['hello', 'hi'],
      emoji: '👋',
      skins: ['👋🏻', '👋🏼', '👋🏽', '👋🏾', '👋🏿'],
    },
  },
};

function Demo() {
  return <EmojiPicker data={data} />;
}
```

## Canonical category IDs

The adapters output categories using canonical IDs and labels so that `categoryLabels` overrides
work consistently across data sources. Categories are emitted in the following order:

- `people` – Smileys & People
- `nature` – Animals & Nature
- `foods` – Food & Drink
- `activity` – Activity
- `places` – Travel & Places
- `objects` – Objects
- `symbols` – Symbols
- `flags` – Flags

`frequent` (Frequently Used) is not emitted by the adapters. It is reserved for custom data:
add a category with `id: 'frequent'` (for example, with recently used emojis) to your data
and it is displayed with a clock icon in the category navigation.
