## Controlled

The value is an emoji ID, a key of `data.emojis`.
A value that was not selected in the picker is displayed without skin tone:

```tsx
import { useState } from 'react';
import { EmojiPickerInput } from '@mantine/emoji';
import { emojiData } from './emoji-data';

function Demo() {
  const [value, setValue] = useState<string | null>(null);

  return (
    <EmojiPickerInput
      data={emojiData}
      value={value}
      onChange={setValue}
      placeholder="Select emoji"
    />
  );
}
```

## Controlled dropdown

Use `opened` and `onOpenedChange` props to control the dropdown state:

```tsx
import { useState } from 'react';
import { EmojiPickerInput } from '@mantine/emoji';
import { emojiData } from './emoji-data';

function Demo() {
  const [opened, setOpened] = useState(false);

  return (
    <EmojiPickerInput
      data={emojiData}
      opened={opened}
      onOpenedChange={setOpened}
      placeholder="Select emoji"
    />
  );
}
```

## onEmojiSelect

`onChange` is called with the emoji ID.
Use `onEmojiSelect` to get the full emoji object with name, keywords and skin variants:

```tsx
import { EmojiPickerInput } from '@mantine/emoji';
import { emojiData } from './emoji-data';

function Demo() {
  return (
    <EmojiPickerInput
      data={emojiData}
      placeholder="Select emoji"
      onEmojiSelect={(emoji) => console.log(emoji)}
    />
  );
}
```

## Popover props

Use the `popoverProps` prop to pass props to the underlying `Popover` component:

```tsx
import { EmojiPickerInput } from '@mantine/emoji';
import { emojiData } from './emoji-data';

function Demo() {
  return (
    <EmojiPickerInput
      data={emojiData}
      placeholder="Select emoji"
      popoverProps={{ position: 'bottom-end', shadow: 'md', offset: 8 }}
    />
  );
}
```
