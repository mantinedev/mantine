## Usage

`EmojiPicker` displays a searchable emoji grid with category navigation, skin tone selector,
and emoji preview. Emoji data is supplied via the `data` prop — see the
[Getting started](/emoji/getting-started) page for setup instructions.

Customize the internal `ScrollArea` with the `scrollAreaProps` prop. You can change the height,
scrollbar type, and any other `ScrollArea` prop. The default height is 300px. Empty search
content is displayed inside the same scroll area, so it has the same height.

## Controlled search

Use `searchValue` and `onSearchChange` props to control the search input value:

```tsx
import { useState } from 'react';
import { EmojiPicker } from '@mantine/emoji';
import { emojiData } from './emoji-data';

function Demo() {
  const [search, setSearch] = useState('');

  return (
    <EmojiPicker
      data={emojiData}
      searchValue={search}
      onSearchChange={setSearch}
    />
  );
}
```

## Unsupported emoji detection

Set `withUnsupportedDetection` to filter out emojis not supported by the current browser/OS.
Detection runs eagerly on data load: each emoji is drawn on a canvas and is considered supported
when it renders as a single color glyph (monochrome fallback glyphs and sequences that fall apart
into several glyphs, for example unknown flags, are filtered out). Results are cached.

```tsx
<EmojiPicker data={emojiData} withUnsupportedDetection />
```

This feature is disabled by default because canvas-based detection has edge cases across platforms.

## Keyboard navigation

The emoji grid is a single tab stop. When the grid is focused, arrow keys move the active emoji
row by row, keeping the column across category boundaries. Keyboard navigation continues from the
last hovered or clicked emoji, or from the first emoji of the category selected in the category
navigation. When the search input is focused, `ArrowDown`, `ArrowUp` and `Enter` are forwarded
to the grid (`ArrowLeft` and `ArrowRight` move the text caret), and `Enter` selects the first
search result after the query changes. The keyboard focus indicator only appears during keyboard
navigation.
