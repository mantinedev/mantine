## Usage

`EmojiPicker` displays a searchable emoji grid with category navigation, skin tone selector and preview.
Emoji data is passed with the `data` prop, see [getting started](/emoji/getting-started) for setup instructions:

## Controlled search

Use `searchValue` and `onSearchChange` props to control the search input value:

```tsx
import { useState } from 'react';
import { EmojiPicker } from '@mantine/emoji';
import { emojiData } from './emoji-data';

function Demo() {
  const [search, setSearch] = useState('');

  return (
    <EmojiPicker
      data={emojiData}
      searchValue={search}
      onSearchChange={setSearch}
    />
  );
}
```

## Unsupported emoji detection

Set `withUnsupportedDetection` to hide emojis that the current browser or operating system cannot render.
Detection draws each emoji on a canvas and is not reliable on every platform, so it is disabled by default:

```tsx
<EmojiPicker data={emojiData} withUnsupportedDetection />
```

## Keyboard navigation

The emoji grid is a single tab stop.
`ArrowDown`, `ArrowUp` and `Enter` also work when the search input is focused, `Enter` selects the first search result.
