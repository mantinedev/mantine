## ColorWheel component

New [ColorWheel](/core/color-wheel) component – a circular hue selector. Its value is a hue in
degrees (0–360) that can be converted to a color with the `hsl()` syntax. Drag the thumb around
the ring or use the keyboard to change the value. Supports custom ring colors, size, thickness
and can be used with uncontrolled forms:

<Demo data={ColorWheelDemos.usage} />

## CompareSlider component

New [CompareSlider](/core/compare-slider) component – a before/after reveal slider. It stacks two
layers of content and clips the top one with a draggable divider to reveal the layer underneath.
The two sides can be any React nodes (images, videos, charts, plain markup), it supports vertical
orientation, custom handle, hover tracking and is fully keyboard accessible:
