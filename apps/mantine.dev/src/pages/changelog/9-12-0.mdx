## ImageCropper component

New [ImageCropper](/core/image-cropper) component provides an interactive crop UI: load an image,
then pan, zoom, rotate and flip it inside a fixed crop window with a rectangle or circle shape and
an optional aspect ratio. The cropped result can be exported as a `Blob` or data URL via a canvas,
or read back as a crop rectangle in source pixels for server-side cropping. It has no third-party
dependencies and works with server-side rendering:

<Demo data={ImageCropperDemos.usage} />

## Mentions component

New [Mentions](/core/mentions) component captures `@`-mentions (and any other trigger) in a textarea.
Typing a trigger opens a suggestions dropdown; picking a suggestion inserts a structured mention token
into the value. The value is stored as markup (`@[Display](id)`) that preserves a stable id for each
mention and round-trips through editing, while the user only ever sees the plain text. It supports
multiple triggers, async data sources with `AbortSignal` cancellation, caret-anchored or inline
suggestions and caret-aware mention styling, all with no third-party dependencies:

<Demo data={MentionsDemos.usage} />

## Persona component

New [Persona](/core/persona) component displays a person identity: an avatar, an optional
presence badge and up to four stacked text lines. It composes existing `Avatar` and
`Indicator` primitives into a single component that is useful in people pickers, contact and
chat lists, comment authors and profile headers. It supports presence statuses, initials and
image avatars, configurable text position and alignment, and a polymorphic root:

<Demo data={PersonaDemos.people} />

## use-broadcast-channel hook

New [use-broadcast-channel](/hooks/use-broadcast-channel) hook is a reactive wrapper over the
[BroadcastChannel API](https://developer.mozilla.org/en-US/docs/Web/API/BroadcastChannel) for
same-origin messaging across tabs, windows, iframes and workers. Post a message from one context
and receive it in all others subscribed to the same channel name, with support for
structured-clone payloads and server-side rendering:

## use-clipboard blobs and images support

[use-clipboard](/hooks/use-clipboard) `copy` function now accepts `Blob`, `ClipboardItem` and
`ClipboardItem[]` values in addition to strings. This makes it possible to copy binary data such as
images to the clipboard with `navigator.clipboard.write`, while strings keep using the widely
supported `navigator.clipboard.writeText`. The new `supported` value indicates whether copying
blobs and images is available:
