## Notifications custom rendering

[Notifications](/x/notifications) now support `renderNotification` prop that allows you to completely
replace the default notification with custom content. All animations (enter, exit, drag dismiss)
are preserved for custom notifications:

<Demo data={NotificationsDemos.renderNotification} />

## Notifications stacked layout

[Notifications](/x/notifications) now support `layout="stacked"` prop that displays notifications in a stacked
layout where only the latest notification is fully visible, and older notifications peek out behind it:

<Demo data={NotificationsDemos.stacked} />

## ActionBar component

New [ActionBar](/core/action-bar) component – a fixed-position bottom bar
for bulk selection actions. Designed to be controlled by table or checkbox
selections, it provides a set of actions that can be performed on selected items.

<Demo data={ActionBarDemos.usage} />

## GaugeChart component

New [GaugeChart](/charts/gauge-chart) component – a radial gauge chart for KPI and status display.
Supports threshold sections, target marker, custom labels, and configurable arc angles.

<Demo data={GaugeChartDemos.usage} />

## WaffleChart component

New [WaffleChart](/charts/waffle-chart) component – a part-to-whole grid chart with colored cells.
Simpler and more compact alternative to pie/donut charts for displaying percentages and proportions.

<Demo data={WaffleChartDemos.usage} />

## Stepper labelPosition

[Stepper](/core/stepper) component now supports the `labelPosition` prop. Set `labelPosition="bottom"`
to display the step label and description below the step icon:

<Demo data={StepperDemos.labelPosition} />
