## QRCode component

New [QRCode](/core/qr-code) component generates and renders QR codes as SVG. The
encoder is bundled with `@mantine/core`, so it works without additional dependencies
and supports server-side rendering. It is themeable with the `color` and `bg` props,
supports a centered `logo` overlay, and exposes the `encodeQR` function for custom
rendering:

<Demo data={QRCodeDemos.usage} />

## Tilt component

New [Tilt](/core/tilt) component rotates its content in 3D in response to the pointer position
and device orientation. It owns the `perspective` container and the transform, supports a layered
depth effect with `Tilt.Layer`, an optional pointer-following `withGlare`, `trackWindow` to react
to the pointer anywhere on the page, and respects `prefers-reduced-motion`:

<Demo data={TiltDemos.layers} />

## use-tilt hook

New [use-tilt](/hooks/use-tilt) hook powers the `Tilt` component. It produces normalized `roll`
and `tilt` values from the pointer position over a target element and, when available, the device
orientation gyroscope. It is headless – map the returned values to CSS transforms to build tilt
and layered depth effects that respond to the cursor on desktop and to device tilt on mobile:
