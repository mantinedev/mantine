## @mantine/emoji package

New `@mantine/emoji` package provides emoji picker components. It works with any emoji
data source through adapters, [emoji-mart](https://www.npmjs.com/package/@emoji-mart/data)
and [emojibase-data](https://www.npmjs.com/package/emojibase-data) adapters are included.

## EmojiPicker

[EmojiPicker](/emoji/emoji-picker) displays a searchable emoji grid with category navigation,
skin tone selector, and emoji preview.

<Demo data={EmojiPickerDemos.usage} />

## EmojiPickerInput

[EmojiPickerInput](/emoji/emoji-picker-input) is an input with an emoji picker dropdown.
It supports all standard input features like labels, descriptions, error messages, and sizes.

<Demo data={EmojiPickerInputDemos.usage} />

## EmojiPickerPopover

## Diff component

New [Diff](/code-highlight/diff) component highlights differences between two strings.
It supports unified and split (side-by-side) display modes, configurable diff
granularity (characters, words, or lines), and context line collapsing.

<Demo data={DiffDemos.usage} />

## PhoneInput component

New [PhoneInput](/core/phone-input) component provides an international phone number input
with country selector, auto-detection, and formatting masks.

<Demo data={PhoneInputDemos.usage} />

## MaskedDateInput component

New [MaskedDateInput](/dates/masked-date-input) component provides a date input with
individual masked fields for day, month, and year. It supports configurable field order,
custom separators, optional time fields, and a calendar dropdown for date selection.

<Demo data={MaskedDateInputDemos.usage} />

## QuarterPicker and QuarterPickerInput components

New [QuarterPicker](/dates/quarter-picker) and [QuarterPickerInput](/dates/quarter-picker-input) components
allow picking quarters, multiple quarters and quarters ranges. They work the same way as `MonthPicker`
and `MonthPickerInput`; the value is the first day of the selected quarter in `YYYY-MM-DD` format.

## WeekPicker and WeekPickerInput components

New [WeekPicker](/dates/week-picker) and [WeekPickerInput](/dates/week-picker-input) components
allow picking weeks, multiple weeks and weeks ranges. Clicking any day selects the whole week,
the value is the first day of the week according to `firstDayOfWeek` in `YYYY-MM-DD` format.

## Other changes

- [DayView](/schedule/day-view/#slot-label-interval) and [WeekView](/schedule/week-view/#slot-label-interval) support `slotLabelInterval` prop to display time labels more often than once per hour
- [DayView](/schedule/day-view/#business-hours) and [WeekView](/schedule/week-view/#business-hours) `businessHours` prop accepts exact minutes, business hours colors can be changed with CSS variables
- [MobileMonthView](/schedule/mobile-month-view/#hide-weekend-days) supports `withWeekendDays` prop to hide weekend days
- [ScrollArea](/core/scroll-area/#offset-size) supports `--scrollarea-offset-size` CSS variable to change the gap reserved by `offsetScrollbars`
- [Popover](/core/popover/#click-outside) and components based on it support `clickOutsideCapture` prop to close the dropdown when the click target stops event propagation
- `getUploadImageExtension` in [@mantine/tiptap](/x/tiptap/#pasted-html-content) uploads images embedded in pasted HTML, use `shouldUploadPastedImage` option to control which images are uploaded
- Keyboard navigation in [DatePicker](/dates/date-picker) and other `@mantine/dates` pickers has been improved: arrow keys move focus across months and focus returns to the input when the dropdown closes
- `@mantine/form` exports `UseContextForm` type
- [Notifications](/x/notifications/#auto-close-progress-position) support `autoCloseProgressPosition` prop to display the auto close progress line at the top of the notification
