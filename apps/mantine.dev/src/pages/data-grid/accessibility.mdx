## Focus model

The grid body has one focus model. By default, rows are the focus targets: `Tab` moves focus
to the first rendered row and arrow keys move it between rows. With `withCellSelection`, cells
are the focus targets: `Tab` moves focus to the last focused cell, or to the first cell when
none was focused. The list view always uses the row model.

## ARIA attributes

- Sortable column headers have `aria-sort` and render a button for the sort action
- The column menu button is labelled with the `columnMenu` label and has `aria-expanded`
- Selection checkboxes and radios are labelled with the `selectAll`, `selectRow` and `selectGroup` labels, expand toggles with `expandRow` / `collapseRow`
- The default inline editor is labelled with the column label. Use `getColumnLabel(cell.column)` to get the same label in a custom `editComponent`
- The row reorder grip is pointer-only and hidden from assistive technology
- Group rows have `aria-expanded`. Expandable rows and tree rows have it on the expand toggle button
- The list view uses `role="list"` with `role="listitem"` items
- A row with a pending async save has `aria-busy`, invalid editor cells have `aria-invalid`
- The grid has `aria-busy` while `loading` is set, skeleton rows are `aria-hidden`
- The virtualized body uses `role="grid"` with `aria-rowcount`, `aria-rowindex` and `aria-colindex`

## Focus management

- When editing ends with `Enter`, `Escape` or a save/cancel control, focus returns to the row or to the cell. When the edit is committed because focus moved elsewhere, focus stays where it moved
- The default editor is focused and its content is selected when editing starts
- In virtualized mode, rows that scroll out of the window are unmounted. Move focus with the arrow keys to keep it inside the rendered window

## Screen readers

The table body renders semantic HTML table elements, which screen readers interpret natively.
The virtualized body relies on the ARIA grid roles listed above. The status text of
`DataGrid.Footer`, the row count and the selection bar count are plain text, they are not live
regions.
