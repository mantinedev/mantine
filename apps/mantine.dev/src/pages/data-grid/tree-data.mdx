## Basic tree data

Pass `getSubRows` to `useDataGrid` to define how child rows are read from your data.
The tree is rendered in the first visible data column: rows are indented, a chevron toggles
rows that have children and guide lines connect the levels:

<Demo data={DataGridDemos.treeData} />

## Icons and custom labels

The tree cell renders the output of the column `cell` renderer, use it to add icons or any
other inline content:

<Demo data={DataGridDemos.treeDataIcons} />

## Tree column

The tree is always displayed in the first visible data column. Put the column that should have
the indentation and the chevron first in your column definitions or in `columnOrder`.
`withRowExpansion` and `renderExpandedRow` are ignored for tree data.

## Filtering through tree hierarchy

Set `filterFromLeafRows` to filter from leaf rows upward. When a leaf row matches
the filter, its parent rows are kept to preserve the tree structure:

<Demo data={DataGridDemos.treeDataFiltering} />

## Pagination with expanded rows

By default, expanded sub-rows count toward the page size. Set `paginateExpandedRows: false`
to count top-level rows only:

<Demo data={DataGridDemos.treeDataPagination} />

## Server-side expansion

Set `manualExpanding` for server-side tree data. Load children in your data fetching logic
with controlled `expanded` and `onExpandedChange`.

## Per-row expand control

Use `getRowCanExpand` to control which rows can be expanded:

```tsx
const store = useDataGrid({
  data,
  columns,
  getSubRows: (row) => row.children,
  getRowCanExpand: (row) => (row.original.children?.length ?? 0) > 0,
});
```

## Selection

With `withRowSelection`, selecting a parent row selects its children. Set
`enableSubRowSelection: false` to select the parent row only.

## List view and row reorder

In list view, tree rows are rendered flat without indentation. Row reorder is not available
with tree data.
