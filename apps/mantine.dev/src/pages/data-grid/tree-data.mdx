## Basic tree data

Use `getSubRows` in `useDataGrid` to define how child rows are accessed from your data.
DataGrid renders the tree in the first visible data column: rows are indented by 20px per level, a
chevron toggles rows that have children, and guide lines connect every level.

<Demo data={DataGridDemos.treeData} />

## Tree lines

Guide lines are displayed by default. Set `withTreeLines={false}` for a plain indent with the
chevron only:

<Demo data={DataGridDemos.treeDataPlainIndent} />

## Icons and custom labels

The tree cell renders the output of the column's `cell` renderer, so icons and any other
inline content are rendered by the column itself:

<Demo data={DataGridDemos.treeDataIcons} />

## Tree column

The tree is always displayed in the first visible data column. Put the column that should have
the indentation and the chevron first in your column definitions or in `columnOrder`.
`withRowExpansion` and `renderExpandedRow` are ignored for tree data.

## Filtering through tree hierarchy

Set `filterFromLeafRows` to `true` to filter from leaf rows upward. When a leaf row matches
the filter, its parent rows are included to keep the tree structure.

<Demo data={DataGridDemos.treeDataFiltering} />

## Pagination with expanded rows

By default, expanded sub-rows count toward the page size. Set `paginateExpandedRows` to `false`
to only count top-level rows when paginating.

<Demo data={DataGridDemos.treeDataPagination} />

## Server-side expansion

Set `manualExpanding` to `true` for server-side tree data. Handle expansion in your data
fetching logic using controlled `expanded` and `onExpandedChange`.

## Per-row expand control

Use `getRowCanExpand` to control which rows can be expanded:

```tsx
const store = useDataGrid({
  data,
  columns,
  getSubRows: (row) => row.children,
  getRowCanExpand: (row) => (row.original.children?.length ?? 0) > 0,
});
```

## Selection

With `withRowSelection`, selecting a parent row selects its children. This behavior is
controlled by the `enableSubRowSelection` option, `true` by default.

## List view and row reorder

In list view tree rows render flat, without indentation. Row reorder is not available with tree
data.
