## Basic sorting

Set `enableSorting: true` on columns that should be sortable. Sorting is enabled automatically
when any column has this flag. Click a sortable column header to cycle through ascending,
descending, and unsorted states.

## Multi-column sort

Hold `Shift` and click additional column headers to sort by multiple columns simultaneously.
Enable multi-sort by passing `enableMultiSort: true` via `tableOptions`.

<Demo data={DataGridDemos.multiSort} />

## Controlled sorting

Pass `sorting` and `onSortingChange` to `useDataGrid` to control sorting state externally.
The state follows the TanStack Table `SortingState` format -- an array of `{ id: string, desc: boolean }` objects.

<Demo data={DataGridDemos.controlledSorting} />

## Custom sort icons

Use the `sortedIcon` and `unsortedIcon` props to replace the default sort indicator icons.
The `sortedIcon` is displayed when a column is actively sorted -- it rotates automatically
for ascending and descending directions via CSS. The `unsortedIcon` is displayed on sortable
columns that are not currently sorted.

## Custom sort functions

Set a custom `sortFn` on a column definition to override the default sort behavior. The value can
be one of the built-in sort function names (a string) or a custom comparator function:

```tsx
const columns = [
  {
    accessorKey: 'date',
    header: 'Date',
    enableSorting: true,
    sortFn: 'datetime',
  },
  {
    accessorKey: 'name',
    header: 'Name',
    enableSorting: true,
    sortFn: (rowA, rowB, columnId) => {
      return rowA.getValue(columnId).localeCompare(rowB.getValue(columnId));
    },
  },
];
```

## Sort removal behavior

By default, clicking a sorted column header cycles through ascending → descending → unsorted.
Pass `enableSortingRemoval: false` via `tableOptions` to skip the unsorted state and cycle only
between ascending and descending:

```tsx
const store = useDataGrid({
  data,
  columns,
  tableOptions: {
    enableSortingRemoval: false,
  },
});
```

## Sort direction

By default, the first click on a sortable column header sorts ascending. Pass `sortDescFirst: true`
via `tableOptions` to sort descending on the first click:

```tsx
const store = useDataGrid({
  data,
  columns,
  tableOptions: {
    sortDescFirst: true,
  },
});
```

## Server-side sorting

For server-side sorting, set `manualSorting` to `true` and handle sorting in your data fetching logic.
See the [Server-side](/data-grid/server-side) page for a complete example.

## Accessibility

DataGrid adds `aria-sort` attributes to sortable column headers automatically. Headers are focusable
and can be activated with `Enter` or `Space` keys.
