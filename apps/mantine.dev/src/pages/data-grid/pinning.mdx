## Column pinning

Pin columns to the start or end edge of the grid so they remain visible while scrolling
horizontally. Pass `columnPinning` to `useDataGrid` with `start` and `end` arrays of column IDs.

<Demo data={DataGridDemos.columnPinning} />

Utility columns (selection, expand, row numbers, reorder) are always pinned first and cannot
be unpinned.

## Pin multiple columns

Pin multiple columns to the start and end edges simultaneously.

<Demo data={DataGridDemos.columnPinningMultiple} />

## Interactive column pinning

Use controlled `columnPinning` and `onColumnPinningChange` to let users pin and unpin
columns dynamically. With `withColumnMenu` on `DataGrid`, every column gets **Pin to left** /
**Pin to right** / **Unpin** items in its header menu.

<Demo data={DataGridDemos.columnPinningInteractive} />

## Row pinning

Pin rows to the top or bottom of the grid so they remain visible while scrolling vertically.
Pass `rowPinning` to `useDataGrid` with arrays of row IDs (from `getRowId`) to pin.

<Demo data={DataGridDemos.rowPinning} />

## Interactive row pinning

Add pin/unpin controls to each row using a custom cell renderer that calls `row.pin('top')`,
`row.pin('bottom')`, or `row.pin(false)`.

<Demo data={DataGridDemos.rowPinningInteractive} />

## Combined row and column pinning

Row pinning and column pinning can be used together. Pinned rows stay fixed vertically while
pinned columns stay fixed horizontally.

<Demo data={DataGridDemos.rowColumnPinning} />

## Pinning with header groups

Column pinning works with grouped headers. A group header is pinned when every visible leaf column
under it is pinned to the same side; a group whose leaves are split between pinned and unpinned
columns is rendered unpinned.

<Demo data={DataGridDemos.pinningWithGroups} />

## Sticky header

Set `stickyHeader` on `DataGrid` to keep the header visible while the page scrolls.
Use `stickyHeaderOffset` to set where the header sticks, for example under a fixed app header:

```tsx
<DataGrid store={store} stickyHeader stickyHeaderOffset={60} />
```

Top-pinned rows stick under the sticky header. With `virtualize`, the header is always sticky
and `stickyHeaderOffset` is not applied.

## keepPinnedRows

By default, pinned rows remain visible even when they would normally be filtered out or
paginated away. Set `keepPinnedRows: false` in `useDataGrid` to allow pinned rows to be
hidden by filters and pagination.

```tsx
const store = useDataGrid({
  data,
  columns,
  rowPinning: { top: ['1'], bottom: [] },
  keepPinnedRows: false,
  getRowId: (row) => row.id,
});
```

## Per-row pinning control

Use `enableRowPinning` as a function to control which rows can be pinned:

```tsx
const store = useDataGrid({
  data,
  columns,
  rowPinning: { top: [], bottom: [] },
  enableRowPinning: (row) => row.original.status === 'active',
  getRowId: (row) => row.id,
});
```

## Controlled pinning state

Both column and row pinning support controlled state via `columnPinning`/`onColumnPinningChange`
and `rowPinning`/`onRowPinningChange`. Access current state directly from the store:

```tsx
const store = useDataGrid({ data, columns, columnPinning, onColumnPinningChange });

// Read current state
store.getColumnPinning() // { start: ['firstName'], end: [] }
store.getRowPinning()    // { top: ['1'], bottom: [] }
```

## Sticky positioning design

Column pinning is implemented with `position: sticky` on `th` and `td` elements, the grid is
rendered as a single table. Pinned cells inherit the background of their row, so stripes, hover
and selection styles are applied to them.

## Limitations

- Rows of a grid with pinned columns have opaque `--mantine-color-body` background. If the grid is rendered on a tinted surface, override the row background with Styles API.
- Row pinning is not supported with `virtualize`. Column pinning works with both standard and virtualized grids.
