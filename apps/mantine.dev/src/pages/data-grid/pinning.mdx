## Column pinning

Pass `columnPinning` to `useDataGrid` with `start` and `end` arrays of column ids to keep
columns visible while scrolling horizontally. Utility columns (selection, expand, row numbers,
reorder) are always pinned first and cannot be unpinned:

## Sticky header

Set `stickyHeader` on `DataGrid` to keep the header visible while the page scrolls.
Use `stickyHeaderOffset` to set where the header sticks, for example under a fixed app header:

```tsx
<DataGrid store={store} stickyHeader stickyHeaderOffset={60} />
```

Top-pinned rows stick under the sticky header. With `virtualize`, the header is always sticky
and `stickyHeaderOffset` is not applied.

## keepPinnedRows

By default, pinned rows stay visible when filters or pagination would hide them.
Set `keepPinnedRows: false` in `useDataGrid` to let them be hidden:

```tsx
const store = useDataGrid({
  data,
  columns,
  rowPinning: { top: ['1'], bottom: [] },
  keepPinnedRows: false,
  getRowId: (row) => row.id,
});
```

## Per-row pinning control

Pass a function to `enableRowPinning` to control which rows can be pinned:

```tsx
const store = useDataGrid({
  data,
  columns,
  rowPinning: { top: [], bottom: [] },
  enableRowPinning: (row) => row.original.status === 'active',
  getRowId: (row) => row.id,
});
```

## Controlled pinning state

Column pinning is controlled with `columnPinning` and `onColumnPinningChange`, row pinning
with `rowPinning` and `onRowPinningChange`. Read the current state from the store:

```tsx
const store = useDataGrid({ data, columns, columnPinning, onColumnPinningChange });

// Read current state
store.getColumnPinning() // { start: ['firstName'], end: [] }
store.getRowPinning()    // { top: ['1'], bottom: [] }
```

## Sticky positioning design

Pinned cells use `position: sticky` and inherit the background of their row, so stripes, hover
and selection styles apply to them.

## Limitations

- Rows of a grid with pinned columns have an opaque `--mantine-color-body` background. If the grid is rendered on a tinted surface, override the row background with Styles API.
- Row pinning is not supported with `virtualize`. Column pinning works with both standard and virtualized grids.
