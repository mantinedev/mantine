## Basic grouping

Set `withGrouping` and pass a `grouping` array of column IDs to group rows by one or more columns.
Group headers show the grouped value with an expand/collapse toggle to show or hide the rows within.

<Demo data={DataGridDemos.grouping} />

## Aggregation

Add an `aggregationFn` to column definitions to display aggregated values in group rows.
TanStack Table provides built-in aggregation functions: `sum`, `min`, `max`, `mean`, `count`, `unique`, and `extent`.

```tsx
const columns = [
  { accessorKey: 'department', header: 'Department' },
  {
    accessorKey: 'salary',
    header: 'Salary',
    aggregationFn: 'mean',
    aggregatedCell: ({ getValue }) =>
      `Avg: $${Math.round(getValue() as number).toLocaleString()}`,
  },
];
```

## Custom aggregation

Define a custom aggregation function for advanced calculations.

```tsx
const columns = [
  {
    accessorKey: 'salary',
    header: 'Salary',
    aggregationFn: (columnId, leafRows) => {
      const values = leafRows.map((row) => row.getValue(columnId) as number);
      const total = values.reduce((sum, val) => sum + val, 0);
      return { total, count: values.length };
    },
    aggregatedCell: ({ getValue }) => {
      const { total, count } = getValue();
      return `$${total.toLocaleString()} (${count} employees)`;
    },
  },
];
```

## Controlled grouping

Use the `grouping` and `onGroupingChange` props for controlled grouping state.
The state is an array of column IDs representing the current grouping hierarchy.

```tsx
import { useState } from 'react';
import { GroupingState } from '@tanstack/react-table';

function Demo() {
  const [grouping, setGrouping] = useState<GroupingState>(['department']);

  return (
    <DataGrid
      data={data}
      withGrouping
      grouping={grouping}
      onGroupingChange={setGrouping}
      columns={columns}
    />
  );
}
```
