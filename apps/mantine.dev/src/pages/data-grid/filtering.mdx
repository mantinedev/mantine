## Column filters

DataGrid owns the column filter state but renders no filter inputs: build the filter UI
you need with `@mantine/core` components and connect it to the store. `useDataGrid` infers
`withFiltering` from columns with `enableColumnFilter` or `filterFn`; the store exposes
`setColumnFilter(columnId, value)` (`undefined`, `null` and `''` remove the entry),
`setColumnFilters(updater)`, `resetColumnFilters()`, `getColumnFilterValue(columnId)` and
`columnFilters`. Enable `withFaceting` to read `getFacetedUniqueValues(columnId)` and
`getFacetedMinMaxValues(columnId)` for select options and range bounds.

## Global search

Pass `withGlobalFilter` to `useDataGrid` to enable cross-column search. Use `store.globalFilter`
and `store.setGlobalFilter` to connect your own search input.

## Controlled filters

Pass `columnFilters` and `onColumnFiltersChange` to `useDataGrid` to control filter state externally.
The state follows the TanStack Table `ColumnFiltersState` format -- an array of `{ id: string, value: unknown }` objects.

## Operator filters

`stringOperators`, `numberOperators` and `booleanOperators` describe operator sets
(contains, equals, greater than, ...). Pass `filterFn: createOperatorFilterFn(stringOperators)`
on a column and store an `{ operator, value }` object as its filter value:

```tsx
import { createOperatorFilterFn, stringOperators, useDataGrid } from '@mantine/data-grid';

const store = useDataGrid({
  data,
  columns: [
    { accessorKey: 'name', header: 'Name', filterFn: createOperatorFilterFn(stringOperators) },
  ],
});

store.setColumnFilter('name', { operator: 'startsWith', value: 'A' });
```

## Custom filter functions

You can provide a custom `filterFn` on any column definition. The function receives the row, column ID,
and filter value, and returns `true` if the row should be included. The example below uses a case-sensitive

## Disable filtering per column

Set `enableColumnFilter: false` on a column definition to make `column.getCanFilter()` return
`false` for it; `store.setColumnFilter` ignores writes for such columns.

## Global filter column exclusion

Set `enableGlobalFilter: false` on specific columns to exclude them from the global search.
The global filter will only match against columns that have global filtering enabled.

## Debounced server-side filtering

When filtering is handled server-side, you can debounce the filter value to avoid sending a request
on every keystroke. Use `useDebouncedValue` from `@mantine/hooks` with controlled filter state:

```tsx
import { useState } from 'react';
import { ColumnFiltersState } from '@tanstack/react-table';
import { useDebouncedValue } from '@mantine/hooks';
import { DataGrid, useDataGrid } from '@mantine/data-grid';

function Demo() {
  const [columnFilters, setColumnFilters] = useState<ColumnFiltersState>([]);
  const [debouncedFilters] = useDebouncedValue(columnFilters, 300);

  // Use debouncedFilters in your data fetching logic
  const data = useQuery(['employees', debouncedFilters], () =>
    fetchEmployees(debouncedFilters)
  );

  const store = useDataGrid({
    data: data ?? [],
    columns: [
      { accessorKey: 'firstName', header: 'First Name' },
      { accessorKey: 'lastName', header: 'Last Name' },
      { accessorKey: 'department', header: 'Department' },
    ],
    withFiltering: true,
    manualFiltering: true,
    columnFilters,
    onColumnFiltersChange: setColumnFilters,
  });

  return <DataGrid store={store} />;
}
```

## Server-side filtering

For server-side filtering, set `manualFiltering` to `true` and handle filtering in your data fetching logic.
See the [Server-side](/data-grid/server-side) page for a complete example.

## Clear filters

Column filters can be cleared individually by emptying the filter input. To clear all filters programmatically,
set the controlled `columnFilters` state to an empty array.
