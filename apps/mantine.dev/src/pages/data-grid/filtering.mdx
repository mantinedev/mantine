## Overview

DataGrid manages the filter state but does not render filter inputs. Build the filter UI
with `@mantine/core` components and connect it to the store:

<DataTable
  head={['Store member', 'Description']}
  data={[
    [<code>columnFilters</code>, <>Current filter state, an array of <code>{'{ id, value }'}</code> entries</>],
    [<code>setColumnFilter(columnId, value)</code>, <>Sets the filter value of one column, <code>undefined</code>, <code>null</code> and <code>''</code> remove it</>],
    [<code>setColumnFilters(updater)</code>, 'Replaces the whole filter state'],
    [<code>resetColumnFilters()</code>, 'Clears every column filter'],
    [<code>getColumnFilterValue(columnId)</code>, 'Returns the current filter value of a column'],
    [<code>getFacetedUniqueValues(columnId)</code>, <>Returns distinct values of a column, requires <code>withFaceting</code></>],
    [<code>getFacetedMinMaxValues(columnId)</code>, <>Returns <code>[min, max]</code> of a numeric column, requires <code>withFaceting</code></>],
    [<><code>globalFilter</code> / <code>setGlobalFilter(value)</code></>, 'Global search value and setter'],
  ]}
/>

Column filtering is enabled automatically when any column has `enableColumnFilter: true` or
`filterFn`. Set `withFiltering: true` to enable it for all columns.

Rows are filtered with `filterFn` of the column. It is the name of a built-in TanStack Table
filter function, for example `includesString` or `inNumberRange`, or your own function.

## Global search

Pass `withGlobalFilter` to `useDataGrid` to enable search across all columns.
`DataGrid.GlobalFilter` renders the search input, `DataGrid.Toolbar` without children includes it.
To use your own input, connect it with `store.getGlobalFilter()` and `store.setGlobalFilter()`:

## Filters popover

A **Filters** button in the toolbar opens a popover with one control per filterable column.
Controls read values with `getColumnFilterValue` and write them with `setColumnFilter`:

## Faceted filters

Pass `withFaceting: true` to `useDataGrid` to get unique values and numeric ranges of columns
from the data:

- `getFacetedUniqueValues(columnId)` returns `{ value, label }[]` that can be passed as `data` to `Select` or `MultiSelect`
- `getFacetedMinMaxValues(columnId)` returns `[min, max]` for `RangeSlider` or number inputs

Use the matching `filterFn`: `equals` for a single value, `arrIncludesSome` for multiple values
and `inNumberRange` for a range:

<Demo data={DataGridDemos.facetedFilters} />

## Operator filters

`stringOperators`, `numberOperators` and `booleanOperators` are sets of filter operators:
contains, equals, starts with, is empty, greater than, etc. Set
`filterFn: createOperatorFilterFn(stringOperators)` on the column and use an
`{ operator, value }` object as its filter value. To define your own operators,
pass an array of `FilterOperator` objects to `createOperatorFilterFn`:

<Demo data={DataGridDemos.operatorFilters} />

## Debounced and server-side filtering

For server-side filtering, set `manualFiltering: true`, keep the filter state controlled and
debounce it with `useDebouncedValue` before sending a request:

```tsx
import { useState } from 'react';
import { ColumnFiltersState } from '@tanstack/react-table';
import { TextInput } from '@mantine/core';
import { useDebouncedValue } from '@mantine/hooks';
import { DataGrid, useDataGrid } from '@mantine/data-grid';

function Demo() {
  const [columnFilters, setColumnFilters] = useState<ColumnFiltersState>([]);
  const [debouncedFilters] = useDebouncedValue(columnFilters, 300);

  // Use debouncedFilters in your data fetching logic
  const data = useQuery(['employees', debouncedFilters], () =>
    fetchEmployees(debouncedFilters)
  );

  const store = useDataGrid({
    data: data ?? [],
    columns: [
      { accessorKey: 'firstName', header: 'First Name' },
      { accessorKey: 'lastName', header: 'Last Name' },
      { accessorKey: 'department', header: 'Department' },
    ],
    withFiltering: true,
    manualFiltering: true,
    columnFilters,
    onColumnFiltersChange: setColumnFilters,
  });

  return (
    <DataGrid store={store}>
      <DataGrid.Toolbar>
        <TextInput
          size={store.getControlSize()}
          placeholder="First name"
          value={(store.getColumnFilterValue('firstName') as string) ?? ''}
          onChange={(event) => store.setColumnFilter('firstName', event.currentTarget.value)}
        />
      </DataGrid.Toolbar>
    </DataGrid>
  );
}
```

See the [Server-side](/data-grid/server-side) page for a complete example.

## Empty results

When all rows are filtered out, `emptyState` is displayed. Use `isFiltered` from its payload
to offer a "Clear filters" action, see [States](/data-grid/states).
