## Column filters

Pass `withFiltering` to `useDataGrid` to display filter inputs below each column header.
Each column gets a text input that filters rows using a case-insensitive string match by default.

## Controlled filters

Pass `columnFilters` and `onColumnFiltersChange` to `useDataGrid` to control filter state externally.
The state follows the TanStack Table `ColumnFiltersState` format -- an array of `{ id: string, value: unknown }` objects.

<Demo data={DataGridDemos.controlledFilters} />

## Filter variants

By default, each column uses a text input for filtering. You can change the filter UI per column
by setting `meta.filterVariant` on the column definition. The supported variants are `text`, `select`,
`multiSelect`, `range`, `dateRange`, and `boolean`.

Enable `withFaceting` on `useDataGrid` to automatically populate select options from your data
and provide min/max hints for range filters.

## Select filter

Set `meta: { filterVariant: 'select' }` on a column to render a select dropdown instead of a text input.
When `withFaceting` is enabled, the dropdown options are automatically derived from the unique values in the column.

<Demo data={DataGridDemos.selectFilter} />

## Multi-select filter

Set `meta: { filterVariant: 'multiSelect' }` to allow filtering by multiple values simultaneously.
Rows that match any of the selected values are shown.

<Demo data={DataGridDemos.multiSelectFilter} />

## Number range filter

Set `meta: { filterVariant: 'range' }` to display two number inputs for filtering within a numeric range.
When `withFaceting` is enabled, the inputs show the min and max values from the data as placeholder hints.

## Debounced server-side filtering

When filtering is handled server-side, you can debounce the filter value to avoid sending a request
on every keystroke. Use `useDebouncedValue` from `@mantine/hooks` with controlled filter state:

```tsx
import { useState } from 'react';
import { ColumnFiltersState } from '@tanstack/react-table';
import { useDebouncedValue } from '@mantine/hooks';
import { DataGrid, useDataGrid } from '@mantine/data-grid';

function Demo() {
  const [columnFilters, setColumnFilters] = useState<ColumnFiltersState>([]);
  const [debouncedFilters] = useDebouncedValue(columnFilters, 300);

  // Use debouncedFilters in your data fetching logic
  const data = useQuery(['employees', debouncedFilters], () =>
    fetchEmployees(debouncedFilters)
  );

  const store = useDataGrid({
    data: data ?? [],
    columns: [
      { accessorKey: 'firstName', header: 'First Name' },
      { accessorKey: 'lastName', header: 'Last Name' },
      { accessorKey: 'department', header: 'Department' },
    ],
    withFiltering: true,
    manualFiltering: true,
    columnFilters,
    onColumnFiltersChange: setColumnFilters,
  });

  return <DataGrid store={store} />;
}
```

## Server-side filtering

For server-side filtering, set `manualFiltering` to `true` and handle filtering in your data fetching logic.
See the [Server-side](/data-grid/server-side) page for a complete example.

## Clear filters

Column filters can be cleared individually by emptying the filter input. To clear all filters programmatically,
set the controlled `columnFilters` state to an empty array.
