## Installation

Install `@mantine/data-grid` and its peer dependencies:

<InstallScript packages="@mantine/data-grid @tanstack/react-table @tanstack/react-virtual" />

After installation, import the package styles. Add the import after `@mantine/core` styles:

```tsx
import '@mantine/core/styles.css';
import '@mantine/data-grid/styles.css';
```

Note: `@tanstack/react-virtual` is only needed if you plan to use the `withVirtualization` feature for large datasets.

## Quick start

```tsx
import { DataGrid } from '@mantine/data-grid';

const data = [
  { id: '1', name: 'Alice', age: 30 },
  { id: '2', name: 'Bob', age: 25 },
];

function Demo() {
  return (
    <DataGrid
      data={data}
      columns={[
        { accessorKey: 'name', header: 'Name' },
        { accessorKey: 'age', header: 'Age' },
      ]}
    />
  );
}
```

## Store hook

Use `useDataGrid` to create a store that manages grid state. Pass it to DataGrid via the `store` prop.
Most features are inferred automatically from columns and controlled state -- you rarely need explicit flags.

```tsx
import { DataGrid, useDataGrid } from '@mantine/data-grid';

function Demo() {
  const store = useDataGrid({
    data,
    columns: [
      { accessorKey: 'name', header: 'Name', enableSorting: true },
      { accessorKey: 'age', header: 'Age' },
    ],
  });

  return <DataGrid store={store} />;
}
```

## Features overview

Features are configured via `useDataGrid` options. Most are inferred automatically when you provide
controlled state or column-level flags:

| Feature | Inferred from |
|---------|---------------|
| Sorting | Columns with `enableSorting: true` |
| Column filtering | `columnFilters` or `onColumnFiltersChange` |
| Global filter | `globalFilter` or `onGlobalFilterChange` |
| Pagination | `pagination` or `onPaginationChange` |
| Column resizing | `columnSizing`, `onColumnSizingChange`, or `columnResizeMode` |
| Column pinning | `columnPinning` or `onColumnPinningChange` |
| Column visibility | `columnVisibility` or `onColumnVisibilityChange` |
| Column reorder | `columnOrder` or `onColumnOrderChange` |
| Row selection | `rowSelection` or `onRowSelectionChange` |
| Row expansion | `expanded` or `onExpandedChange` |
| Grouping | `grouping` or `onGroupingChange` |
| Editing | `editingMode` is set |

Presentation props like `striped`, `highlightOnHover`, `stickyHeader`, `withRowNumbers`,
and `withVirtualization` are set directly on the `DataGrid` component.

## Peer dependencies

`@mantine/data-grid` uses TanStack Table and TanStack Virtual as peer dependencies. This means you share versions with your application -- no bundled duplicates or version conflicts.

| Package | Min version | Purpose |
|---------|-------------|---------|
| `@tanstack/react-table` | `>=8.20.0` | Headless table logic |
| `@tanstack/react-virtual` | `>=3.13.0` | Row virtualization |
| `@mantine/core` | `9.0.2` | UI components |
| `@mantine/hooks` | `9.0.2` | React hooks |
