## Installation

Install `@mantine/data-grid` and its peer dependencies:

<InstallScript packages="@mantine/data-grid @tanstack/react-table @tanstack/react-virtual" />

After installation, import the package styles. Add the import after `@mantine/core` styles:

```tsx
import '@mantine/core/styles.css';
import '@mantine/data-grid/styles.css';
```

Note: `@tanstack/react-virtual` is only needed if you plan to use the `virtualize` feature for large datasets.

## Quick start

```tsx
import { DataGrid } from '@mantine/data-grid';

const data = [
  { id: '1', name: 'Alice', age: 30 },
  { id: '2', name: 'Bob', age: 25 },
];

function Demo() {
  return (
    <DataGrid
      data={data}
      columns={[
        { accessorKey: 'name', header: 'Name' },
        { accessorKey: 'age', header: 'Age' },
      ]}
    />
  );
}
```

## Store hook

Use `useDataGrid` to create a store that manages grid state. Pass it to DataGrid via the `store` prop.
Most features are inferred automatically from columns and controlled state -- you rarely need explicit flags.

```tsx
import { DataGrid, useDataGrid } from '@mantine/data-grid';

function Demo() {
  const store = useDataGrid({
    data,
    columns: [
      { accessorKey: 'name', header: 'Name', enableSorting: true },
      { accessorKey: 'age', header: 'Age' },
    ],
  });

  return <DataGrid store={store} />;
}
```

## createDataGridColumnHelper

`createDataGridColumnHelper` provides a type-safe API for building column definitions. Pass your row
data type as a generic to get full autocompletion on accessor keys and cell values. It is a thin
wrapper around TanStack Table's `createColumnHelper` that is already bound to the feature set
DataGrid registers, so you do not have to pass the features generic yourself:

```tsx
import { createDataGridColumnHelper, DataGrid, useDataGrid } from '@mantine/data-grid';

const columnHelper = createDataGridColumnHelper<Person>();

const columns = [
  columnHelper.accessor('name', { header: 'Name', enableSorting: true }),
  columnHelper.accessor('age', { header: 'Age' }),
  columnHelper.display({
    id: 'actions',
    meta: { type: 'actions' },
    cell: () => <Button size="xs">Edit</Button>,
  }),
];
```

## Column definition types

TanStack Table supports three kinds of column definitions:

- **Accessor columns** — defined with `accessorKey` or `accessorFn`. Read data from the row and support sorting, filtering, and grouping.
- **Display columns** — defined with an `id` and no accessor. Used for action buttons, checkboxes, or any content not tied to row data.
- **Group columns** — defined with a `columns` array. Create a multi-level header by nesting accessor or display columns inside a group.

## defaultColumn

Pass `defaultColumn` via `tableOptions` to set fallback values for any column property that is not
explicitly defined on individual columns:

```tsx
const store = useDataGrid({
  data,
  columns,
  tableOptions: {
    defaultColumn: { size: 200, minSize: 50, maxSize: 500 },
  },
});
```

Features are configured via `useDataGrid` options. Most are inferred automatically when you provide
controlled state or column-level flags:

Every `with*` flag can also be set explicitly to force a feature on or off. Features that render a
column (`withRowSelection`, `withRowExpansion`, `withRowNumbers`, `withRowReorder`) and the grid
`size` are `useDataGrid` options as well, because the store owns the column model. Appearance props
such as `withTableBorder`, `radius`, `withRowBorders`, `striped`, `withColumnBorders`,
`highlightOnHover`, `stickyHeader` and `virtualize` are set directly on the `DataGrid` component,
see [Customization](/data-grid/customization).
