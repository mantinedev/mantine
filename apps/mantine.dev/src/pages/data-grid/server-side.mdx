## Overview

Use server-side mode when your dataset is too large to load entirely in the browser, or when
sorting, filtering, and pagination must be handled by an API. Enable server-side mode by setting
the `manual*` options and providing controlled state in `useDataGrid`.

## Server-side sorting

Set `manualSorting` to prevent DataGrid from sorting data client-side. Use controlled `sorting`
and `onSortingChange` to send the sort state to your API.

```tsx
const store = useDataGrid({
  data: serverData,
  columns,
  manualSorting: true,
  sorting,
  onSortingChange: setSorting,
});
```

## Server-side filtering

Set `manualFiltering` to disable client-side filtering. Use controlled `columnFilters`
and `onColumnFiltersChange` to pass filter state to your API.

```tsx
const store = useDataGrid({
  data: serverData,
  columns,
  withFiltering: true,
  manualFiltering: true,
  columnFilters,
  onColumnFiltersChange: setColumnFilters,
});
```

## Server-side pagination

Set `manualPagination` and provide `rowCount` so DataGrid knows the total number of pages
without having all data in memory.

```tsx
const store = useDataGrid({
  data: serverData,
  columns,
  manualPagination: true,
  pagination,
  onPaginationChange: setPagination,
  rowCount: totalRowCount,
});
```

## Faceted filter options

When using server-side filtering, the API typically returns available filter values alongside the data.
Pass these as column `filterSelectOptions` to display a select dropdown instead of a free-text input.

```tsx
const columns = [
  {
    accessorKey: 'department',
    header: 'Department',
    filterSelectOptions: facetedValues.department,
  },
  {
    accessorKey: 'status',
    header: 'Status',
    filterSelectOptions: ['active', 'inactive'],
  },
];
```
