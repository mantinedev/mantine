## Empty state

Use the `emptyState` prop of `DataGrid` to render content when there are no rows to display:
the data is empty or filters match nothing. The content is rendered in a full-width cell
without padding, use the `emptyState` Styles API selector to style it.

`emptyState` can be a React node or a function that receives the following object:

<DataTable

  data={[

    ['`isFiltered`', 'Whether a column filter or a non-empty global filter is active (read from the state, so it is correct under `manualFiltering`)'],
    ['`table`', 'The table instance, for example to clear filters'],
  ]}
/>

<Demo data={DataGridDemos.emptyState} />

The empty state is not displayed while `loading` is set.

## Loading

Set the `loading` prop on `DataGrid` to display the loading state:

- If the grid has no rows yet, skeleton rows are displayed
- If the grid has rows, the `loadingVariant` prop defines what is displayed over them

## Loading variants

<DataTable
  head={['Variant', 'Rendering']}
  data={[
    ['`overlay` (default)', 'A core `LoadingOverlay` over the body only (the toolbar, header and footer stay clear; the tfoot is covered) with a 2px blur and 60% background opacity; interaction is blocked while it is visible'],
    ['`bar`', 'A 2px primary indeterminate progress bar on the header rule; the body rows are dimmed to 50% opacity and stay interactive, which suits background refreshes and infinite scroll. The animation is static under `prefers-reduced-motion`'],
    ['`skeleton`', 'Skeleton rows replace the existing rows'],
  ]}
/>

The number of skeleton rows is the page size when pagination is enabled and `skeletonRowCount`
(`10` by default) otherwise. Use `loadingOverlayProps` to pass props to `LoadingOverlay`
of the `overlay` variant:

```tsx
<DataGrid
  store={store}
  loading={isFetching}
  loadingVariant="overlay"
  loadingOverlayProps={{ loaderProps: { type: 'dots' }, overlayProps: { blur: 0 } }}
/>

<DataGrid store={store} loading={isFetching} loadingVariant="skeleton" skeletonRowCount={5} />
```

In list view there are no skeleton rows, the `skeleton` variant displays the overlay instead.

## Server-side example

The [full server-side example](/data-grid/server-side#full-example) uses `loading` with
`loadingVariant="bar"`: skeleton rows are displayed on the first load and the bar is displayed
while a new page, sort or filter is fetched.
