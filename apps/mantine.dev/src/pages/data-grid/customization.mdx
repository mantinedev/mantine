## Frame

By default, the grid has a border around the toolbar, the table and the footer.
Use `radius` to change its border radius and `withTableBorder={false}` to remove the border.

## Size

`size` is a `useDataGrid` option, `sm` by default. It controls the font size, row height,
cell padding and the size of controls and icons. Use `store.getSize()` and `store.setSize()`
to read and change it.

Controls in the toolbar, selection bar and footer use the size returned by `store.getControlSize()`.
Pass it to your own buttons and inputs inside the grid so they match.

## Compound components

Use compound components to add a toolbar, a selection bar and a footer to the grid.
The table itself is always rendered by the grid. The toolbar and the selection bar are displayed
above the table, other children below it.

<Demo data={DataGridDemos.compoundComponents} />

Available compound components:

- `DataGrid.Toolbar` -- chrome bar above the table, renders global filter, column visibility toggle and export button when empty
- `DataGrid.GlobalFilter` -- global search input
- `DataGrid.ColumnVisibilityToggle` -- labeled `Columns` menu button
- `DataGrid.ExportButton` -- export menu (CSV, Excel, print, copy to clipboard)
- `DataGrid.RowCount` -- total / filtered row count text
- `DataGrid.SelectionBar` -- bulk actions bar shown in the toolbar slot while rows are selected
- `DataGrid.Footer` -- chrome bar below the table with status text, page size select and pagination
- `DataGrid.ColumnMenu` -- column menu button for custom header cells

## Toolbar

`DataGrid.Toolbar` without children renders the global filter (with `withGlobalFilter`),
the column visibility toggle (with `withColumnVisibility`) and the export button.
Pass children to replace the default content. Use a `div` with `flex: 1` as a spacer.

<Demo data={DataGridDemos.toolbarComposed} />

`DataGrid.RowCount` displays the number of rows: `18 rows`, or `5 of 18 rows` when the data is filtered.

## Export button

`DataGrid.ExportButton` opens a menu with CSV, Excel, print and copy to clipboard items:

- `formats` – formats to display and their order, a single format renders a button without a menu
- `fileName` – name of the downloaded file, `data` by default
- `rows` – rows to export: `all` (default), `filtered`, `selected` or `page`
- `columns` – columns to export: `visible` (default), `all` or an array of column ids
- `onExport` – called with the format after an export

`all` and `filtered` rows follow the current sort order and ignore pagination, group rows and
tree sub-rows are not exported. Utility columns, actions columns and columns with
`meta.disableExport` are never exported.

<Demo data={DataGridDemos.exportButton} />

## Selection bar

`DataGrid.SelectionBar` replaces the toolbar while rows are selected. It displays the number
of selected rows, bulk actions passed as `children` and a button that clears the selection.

## Footer

`DataGrid.Footer` renders the status text, the page size select and pagination controls in one bar
at the bottom of the frame; see [Pagination](/data-grid/pagination) for every option.

## Column menu

Set `withColumnMenu` on `DataGrid` to add a menu button to every data column header.
The button is displayed when the header is hovered or focused, it is always visible on touch devices.
Menu items depend on the features enabled for the column: sorting, reordering, pinning, hiding,
grouping and resizing.

Use `columnMenuItems` to add your own items and `meta.disableColumnMenu` to hide the menu of one column:

<Demo data={DataGridDemos.columnMenu} />

To render the column menu inside your own header cell, use `DataGrid.ColumnMenu` and pass
the `column` instance to it. `children` are added after the built-in items:

```tsx
{
  accessorKey: 'name',
  header: ({ column }) => (
    <Group justify="space-between" wrap="nowrap">
      Name
      <DataGrid.ColumnMenu column={column}>
        <Menu.Item>Custom item</Menu.Item>
      </DataGrid.ColumnMenu>
    </Group>
  ),
}
```

## State persistence

To save and restore grid state, use controlled state options of `useDataGrid`.
The example below saves the sorting state to `localStorage`:

```tsx
import { useState, useEffect } from 'react';
import { SortingState } from '@tanstack/react-table';
import { DataGrid, useDataGrid } from '@mantine/data-grid';

const STORAGE_KEY = 'my-grid-state';

function Demo() {
  const [sorting, setSorting] = useState<SortingState>(() => {
    const saved = localStorage.getItem(STORAGE_KEY);
    return saved ? JSON.parse(saved).sorting : [];
  });

  useEffect(() => {
    localStorage.setItem(STORAGE_KEY, JSON.stringify({ sorting }));
  }, [sorting]);

  const store = useDataGrid({
    data,
    columns,
    sorting,
    onSortingChange: setSorting,
  });

  return <DataGrid store={store} />;
}
```

### useDataGridState

`useDataGridState` saves the state keys listed in `persistedState` to `localStorage`
and restores them on mount:

```tsx
import { DataGrid, useDataGrid, useDataGridState } from '@mantine/data-grid';

function Demo() {
  const store = useDataGrid({ data, columns, withSorting: true, withColumnReorder: true });

  useDataGridState({
    store,
    stateStorageKey: 'my-grid-state',
    persistedState: ['sorting', 'columnOrder', 'columnVisibility', 'size'],
  });

  return <DataGrid store={store} />;
}
```

## Custom storage

For session storage, URL search params or server-side persistence, use controlled state options
of `useDataGrid` the same way as in the `localStorage` example above.

## Theme integration

Use `DataGrid.extend` to set default props and class names for all grids in your application:

```tsx
import { createTheme } from '@mantine/core';
import { DataGrid } from '@mantine/data-grid';

const theme = createTheme({
  components: {
    DataGrid: DataGrid.extend({
      defaultProps: { withRowBorders: 'subtle', highlightOnHover: true, radius: 'md' },
      classNames: { root: 'my-grid-root' },
    }),
  },
});
```

## Dark mode

DataGrid colors are based on Mantine CSS variables and follow the current color scheme,
no additional configuration is required.

## ScrollArea configuration

The table is wrapped in `ScrollArea`. Use `scrollAreaProps` to pass props to it, or set
`withScrollArea={false}` to handle overflow yourself. `withScrollArea` is ignored when
`virtualize` is set and in list view.

```tsx
<DataGrid
  store={store}
  scrollAreaProps={{ type: 'always', offsetScrollbars: true }}
/>
```

## TanStack passthrough

Use `tableOptions` in `useDataGrid` to pass options that the hook does not cover to TanStack Table:

```tsx
const store = useDataGrid({
  data,
  columns,
  tableOptions: {
    enableMultiSort: true,
    maxMultiSortColCount: 3,
    sortDescFirst: false,
    debugTable: process.env.NODE_ENV === 'development',
  },
});
```
