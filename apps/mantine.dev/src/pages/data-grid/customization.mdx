## Compound components

DataGrid renders a default layout when no children are provided. For custom layouts, use the compound
component API to compose the grid from individual parts. This gives full control over ordering,
wrapping, and conditional rendering.

<Demo data={DataGridDemos.compoundComponents} />

Available compound components:

- `DataGrid.Toolbar` -- toolbar bar, renders global filter, column visibility toggle and export button when empty
- `DataGrid.GlobalFilter` -- global search input
- `DataGrid.ColumnVisibilityToggle` -- labeled column visibility menu button
- `DataGrid.ExportButton` -- export menu (CSV, Excel, print, copy to clipboard)
- `DataGrid.RowCount` -- total / filtered row count text
- `DataGrid.SelectionBar` -- bulk actions bar shown in the toolbar slot while rows are selected
- `DataGrid.Header` -- table header with column headers
- `DataGrid.Body` -- table body with data rows
- `DataGrid.VirtualBody` -- virtualized table body
- `DataGrid.Tfoot` -- table footer (`<tfoot>` with column footers and totals)
- `DataGrid.Footer` -- footer chrome bar with status text, page size select and pagination

## Toolbar

An empty `<DataGrid.Toolbar />` renders the global filter (with `withGlobalFilter`), a spacer,
the column visibility toggle (with `withColumnVisibility`) and the export button. Any children
replace this default. Controls take their size from `store.controlSize`, use it for your own
buttons to match.

```tsx
<DataGrid store={store}>
  <DataGrid.Toolbar>
    <DataGrid.GlobalFilter />
    <DataGrid.RowCount />
    <Button size={store.controlSize} variant="default" ml="auto">
      Add employee
    </Button>
    <DataGrid.ExportButton fileName="employees" formats={['csv', 'excel']} />
  </DataGrid.Toolbar>
</DataGrid>
```

## Selection bar

`DataGrid.SelectionBar` takes the toolbar's place while rows are selected: it renders the selected
count, your bulk action controls and a close button that clears the selection. With `floating`
it floats above the grid content instead and the toolbar stays visible.

```tsx
<DataGrid store={store}>
  <DataGrid.Toolbar />
  <DataGrid.SelectionBar>
    <Button size={store.controlSize} color="red" variant="light" onClick={deleteSelected}>
      Delete
    </Button>
  </DataGrid.SelectionBar>
</DataGrid>
```

## Footer

`DataGrid.Footer` renders the status text (`1–10 of 20`, or `20 rows` without pagination),
the page size select and pagination controls in one bar at the bottom of the grid.
Use `statusFormat="long"` to render `Showing 1–10 of 20 · 2 selected`, `pagination="arrows"`
for previous / next controls with a page label, `pagination="none"` for the status only and
`withPageSize={false}` to hide the page size select. Pass `children` to replace the default content.

```tsx
const store = useDataGrid({ data, columns, withRowSelection: true, pageSize: 10 });

<DataGrid store={store}>
  <DataGrid.Footer statusFormat="long" pagination="arrows" />
</DataGrid>
```

## Labels

Override any text label by passing a `labels` prop to `DataGrid`. All keys are optional --
only override what you need.

```tsx
<DataGrid
  store={store}
  labels={{
    pageSize: '{count} par page',
    pageSizeLabel: 'Lignes par page',
    footerRange: '{from}–{to} sur {total}',
    footerRows: '{count} lignes',
    footerSelected: '{count} selectionnees',
    globalFilterPlaceholder: 'Rechercher...',
  }}
/>
```

## State persistence

Save and restore grid state using the store. Access current state directly from `store.sorting`,
`store.columnFilters`, `store.pagination`, etc.

```tsx
import { useState, useEffect } from 'react';
import { SortingState } from '@tanstack/react-table';
import { DataGrid, useDataGrid } from '@mantine/data-grid';

const STORAGE_KEY = 'my-grid-state';

function Demo() {
  const [sorting, setSorting] = useState<SortingState>(() => {
    const saved = localStorage.getItem(STORAGE_KEY);
    return saved ? JSON.parse(saved).sorting : [];
  });

  useEffect(() => {
    localStorage.setItem(STORAGE_KEY, JSON.stringify({ sorting }));
  }, [sorting]);

  const store = useDataGrid({
    data,
    columns,
    sorting,
    onSortingChange: setSorting,
  });

  return <DataGrid store={store} />;
}
```

## Custom storage

For session storage, URL search params, or server-side persistence, implement the same pattern
with your preferred storage mechanism. The controlled state options in `useDataGrid` accept any state source.

## Column menu

Set `withColumnMenu` on `DataGrid` to render a menu button in every column header. The menu lists
sort, move, pin, hide, group and reset size items depending on the features enabled in the store,
and `columnMenuItems` appends your own items after them. Set `meta.disableColumnMenu` on a column
to hide its menu:

```tsx
<DataGrid
  store={store}
  withColumnMenu
  columnMenuItems={(column) => (
    <Menu.Item onClick={() => console.log(column.id)}>Inspect column</Menu.Item>
  )}
/>
```

`DataGrid.ColumnMenu` is the component behind the button. To render the column menu inside your
own header cell, pass the `column` instance from the header context:

```tsx
<DataGrid store={store}>
  {header.column && <DataGrid.ColumnMenu column={header.column} />}
  <DataGrid.Body />
</DataGrid>
```

## Theme integration

Use `createTheme` with `DataGrid.extend` to apply default props and class names globally. This
removes the need to repeat props on every `<DataGrid>` usage in your app:

```tsx
import { createTheme } from '@mantine/core';
import { DataGrid } from '@mantine/data-grid';

const theme = createTheme({
  components: {
    DataGrid: DataGrid.extend({
      defaultProps: { striped: true, highlightOnHover: true },
      classNames: { root: 'my-grid-root' },
    }),
  },
});
```

## Dark mode

DataGrid automatically adapts to the active Mantine color scheme. Border, stripe, hover, and
selected-row colors all derive from Mantine CSS variables, so switching between light and dark
mode requires no additional configuration.

## ScrollArea configuration

DataGrid wraps the table in a `ScrollArea` by default. Pass `scrollAreaProps` to configure it,
or set `withScrollArea={false}` to handle overflow yourself:

```tsx
<DataGrid
  store={store}
  scrollAreaProps={{ type: 'always', offsetScrollbars: true }}
/>
```

## TanStack passthrough

The `tableOptions` option in `useDataGrid` provides an escape hatch to the underlying TanStack Table
instance. Any option not covered by the store can be passed directly.

```tsx
const store = useDataGrid({
  data,
  columns,
  tableOptions: {
    enableMultiSort: true,
    maxMultiSortColCount: 3,
    sortDescFirst: false,
    debugTable: process.env.NODE_ENV === 'development',
  },
});
```
