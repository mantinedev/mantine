## Basic column visibility

Pass `withColumnVisibility` to `useDataGrid` to allow users to show and hide columns.
`DataGrid.ColumnVisibilityToggle` renders a button with a menu of columns. `DataGrid.Toolbar`
without children renders it automatically.

## Controlled visibility state

Pass `columnVisibility` and `onColumnVisibilityChange` to `useDataGrid` for controlled state.
The state is an object of column ids and boolean values.

## Disable hiding per column

Set `enableHiding: false` on a column definition to prevent the column from being hidden.
Such columns are not listed in the visibility menu.

## Column menu

With `withColumnMenu` on `DataGrid`, every hideable column gets a **Hide column** item in its
header menu, see [Customization](/data-grid/customization#column-menu).

## Toggle all columns

Use the table instance to show or hide all columns:

```tsx
const store = useDataGrid({ data, columns, withColumnVisibility: true });

// Hide all columns
store.table.toggleAllColumnsVisible(false);

// Show all columns
store.table.toggleAllColumnsVisible(true);
```

## Programmatic visibility

Use the column instance to show or hide one column:

```tsx
// Toggle a specific column
store.table.getColumn('email')?.toggleVisibility();

// Set visibility explicitly
store.table.getColumn('email')?.toggleVisibility(false);
```

## Initial hidden columns

Pass `columnVisibility` to `useDataGrid` to hide columns initially:

```tsx
const store = useDataGrid({
  data,
  columns,
  columnVisibility: { email: false, startDate: false },
});
```
