## virtualize prop

The `virtualize` prop controls which axis is virtualized. Pass one of the following values:

```tsx
<DataGrid store={store} virtualize="rows" height={500} />
<DataGrid store={store} virtualize="columns" height={500} />
<DataGrid store={store} virtualize="rows,columns" height={500} />
```

The `height` prop is required for all virtualization modes so the grid has a bounded scroll container.

## Basic virtualization

Set `virtualize="rows"` to enable row virtualization for large datasets. When virtualization is enabled,
only the rows visible in the viewport are rendered to the DOM. The `height` prop is required to define the
scrollable container size.

## Virtual scroll config

Fine-tune virtual scroll behavior with the `virtualScrollConfig` prop:

- `overscan` -- number of rows rendered above and below the visible area (default: `5`)
- `estimateSize` -- function returning the estimated row height in pixels (default: the row height of the current `size`)

```tsx
<DataGrid
  data={data}
  virtualize="rows"
  height={500}
  virtualScrollConfig={{
    overscan: 10,
    estimateSize: () => 48,
  }}
  columns={columns}
/>
```

## Infinite scroll

Use the `onScrollToBottom` callback to load more data when the user scrolls near the bottom of the grid.
This works with or without virtualization. Combine with `loading` to show a loading overlay during fetch.

## Column virtualization

Set `virtualize="columns"` to enable column virtualization when working with 50 or more columns.
Only the columns visible in the horizontal scroll area are rendered to the DOM. Fine-tune behavior
with the `virtualColumnConfig` option:

```tsx
<DataGrid
  store={store}
  virtualize="columns"
  height={500}
  virtualColumnConfig={{
    overscan: 5,
    estimateSize: (index) => columns[index]?.size ?? 150,
  }}
/>
```

Combine row and column virtualization with `virtualize="rows,columns"` for grids with many rows
and many columns simultaneously.

Virtualized rendering positions each cell independently, which is why cell spanning (`spanRows` /
`spanColumns`) and cell selection are not applied when `virtualize` is set.

## Performance tips

- Always memoize your `data` and `columns` arrays with `useMemo` to prevent unnecessary re-renders.
- Set explicit `size` on columns to avoid layout recalculation.
- Use `getRowId` to provide stable row identifiers instead of relying on array index.
- Adjust `overscan` based on row height -- fewer overscan rows for tall rows, more for short rows.
- For extremely large datasets (1M+ rows), consider server-side pagination instead.

## Accessibility

Virtualized grids maintain full ARIA grid semantics. DataGrid sets `role="grid"` on the root table element,
`role="row"` on each row, and `role="gridcell"` / `role="columnheader"` on cells. Keyboard navigation with
arrow keys moves focus between cells. `Home` and `End` scroll to the first and last rows respectively.
Screen readers announce row position (e.g., "row 500 of 100,000") using `aria-rowindex`.
