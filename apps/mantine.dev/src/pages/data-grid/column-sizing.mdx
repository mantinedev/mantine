## Basic column resizing

Pass `withColumnResizing` to `useDataGrid` to allow users to resize columns by dragging
column boundaries. Set the initial column width with the `size` property of a column definition.

<Demo data={DataGridDemos.columnResizing} />

## Resize handles

A resize handle is displayed at the boundary between two columns when one of them is hovered.
Double-click a handle to fit the column width to its content. To do the same from your code,
use the `autosizeColumns` function exported from the package.

## Resize mode

Set `columnResizeMode` to change when column widths are updated:

- `onEnd` (default) – when the user releases the handle, a guide line previews the new width while dragging
- `onChange` – while the user drags the handle

## Disable resizing per column

Set `enableResizing: false` on a column definition to disable resizing of that column:

```tsx
const columns = [
  { accessorKey: 'id', header: 'ID', size: 60, enableResizing: false },
  { accessorKey: 'name', header: 'Name', size: 200 },
  { accessorKey: 'email', header: 'Email', size: 250 },
];

const store = useDataGrid({ data, columns, withColumnResizing: true });
```

Utility columns and actions columns cannot be resized by the user. Their width depends on
the grid `size`, use `columnSizing` to override it.

## Column size defaults

TanStack Table uses these defaults when `size`, `minSize`, or `maxSize` are not specified:

<DataTable
  head={['Property', 'Default']}
  data={[
    ['`size`', '`150`'],
    ['`minSize`', '`20`'],
    ['`maxSize`', '`Number.MAX_SAFE_INTEGER`'],
  ]}
/>

Override these globally via `tableOptions.defaultColumn`:

```tsx
const store = useDataGrid({
  data,
  columns,
  withColumnResizing: true,
  tableOptions: {
    defaultColumn: { size: 200, minSize: 50, maxSize: 500 },
  },
});
```

## Table layout

Use the `tableLayout` prop of `DataGrid` to change how column widths are applied:

- `fixed` (default) – every column has the width set with `size`. The last data column takes the remaining space, the grid scrolls horizontally when columns do not fit.
- `auto` – the browser distributes the remaining space between columns, `size` is a hint

Use the `textOverflow` prop (`ellipsis`, `wrap` or `clip`) to change how content
that does not fit into the cell is displayed.

## Header groups

Group headers have resize handles too: dragging resizes all columns of the group
proportionally, double-click autosizes them.

## RTL support

The resize direction is taken from the closest `DirectionProvider`. Set `columnResizeDirection`
to override it:

```tsx
const store = useDataGrid({
  data,
  columns,
  withColumnResizing: true,
  columnResizeDirection: 'rtl',
});
```
