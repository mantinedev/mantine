## Basic column resizing

Pass `withColumnResizing` to `useDataGrid` to allow users to drag column boundaries to resize them.
Set initial column widths using the `size` property in column definitions.

<Demo data={DataGridDemos.columnResizing} />

## Resize handles

One handle is rendered at every boundary between two columns, at the end edge of the column it
resizes, and is revealed when either neighbour is hovered. There is no handle before the first
column, after the last column, or after a column with `enableResizing: false`. The hit area is 8px
wide with a 3px pill that turns primary while dragging; `touch-action: none` makes it work on touch
devices. While a handle is dragged, a 1px guide line marks the new edge across the whole grid.
Double-click a handle to autosize the column to its content (`autosizeColumns` is exported for
programmatic use).

## Resize mode

DataGrid supports two resize modes: `'onEnd'` (default) updates column widths when the user
releases the drag handle, with the guide line previewing the new edge, while `'onChange'` updates
widths in real-time during dragging.

<Demo data={DataGridDemos.columnResizeMode} />

## Column size constraints

Use `minSize` and `maxSize` in column definitions to constrain how small or large a column
can be resized. The `size` property sets the initial width.

## Controlled column sizing

Pass `columnSizing` and `onColumnSizingChange` to `useDataGrid` for controlled column sizing state.

## Disable resizing per column

Set `enableResizing: false` on individual column definitions to prevent them from being resized
while other columns remain resizable.

```tsx
const columns = [
  { accessorKey: 'id', header: 'ID', size: 60, enableResizing: false },
  { accessorKey: 'name', header: 'Name', size: 200 },
  { accessorKey: 'email', header: 'Email', size: 250 },
];

const store = useDataGrid({ data, columns, withColumnResizing: true });
```

Utility columns (selection, expand, row numbers, reorder) and actions columns are never
resizable; their widths come from the grid `size` and can be overridden through `columnSizing`.

## Column size defaults

TanStack Table uses these defaults when `size`, `minSize`, or `maxSize` are not specified:

<DataTable
  head={['Property', 'Default']}
  data={[
    ['`size`', '`150`'],
    ['`minSize`', '`20`'],
    ['`maxSize`', '`Number.MAX_SAFE_INTEGER`'],
  ]}
/>

Override these globally via `tableOptions.defaultColumn`:

```tsx
const store = useDataGrid({
  data,
  columns,
  withColumnResizing: true,
  tableOptions: {
    defaultColumn: { size: 200, minSize: 50, maxSize: 500 },
  },
});
```

## Table layout

`tableLayout` (`'fixed'` by default) decides how column widths are applied. With `fixed` every
column takes its `size` exactly; with `auto` the browser distributes the remaining width and
`size` is a hint. `textOverflow` (`'ellipsis' | 'wrap' | 'clip'`) controls what happens to cell
content wider than the column.

## Header groups

Resize handles stay on group headers: dragging a group boundary resizes the leaf columns under it
proportionally, and double-click autosizes all of them.

## RTL support

`columnResizeDirection` defaults to the direction of the closest `DirectionProvider`, so a grid
rendered inside an RTL layout resizes correctly without extra configuration. Pass the option
explicitly to override the detected direction:

```tsx
const store = useDataGrid({
  data,
  columns,
  withColumnResizing: true,
  columnResizeDirection: 'rtl',
});
```
