## Row selection

Pass `withRowSelection` to `useDataGrid` to add a checkbox column with a select-all checkbox
in the header. The `getRowId` option is required to provide stable row identifiers.

<Demo data={DataGridDemos.rowSelection} />

Selected rows have the `data-selected` attribute. It is set even when the checkbox column is
not used, so a custom selection column gets the same styles.

## Controlled selection

Pass `rowSelection` and `onRowSelectionChange` to `useDataGrid` to control selection state externally.
Selection state is keyed by row IDs (from `getRowId`), not positional indexes.

<Demo data={DataGridDemos.rowSelectionControlled} />

## Single selection

Set `enableMultiRowSelection` to `false` to restrict selection to one row at a time. The header
cell is empty in single-select mode and each row renders a radio control.

<Demo data={DataGridDemos.rowSelectionSingle} />

## Conditional selection

Pass a function to `enableRowSelection` to control selectability per row. Rows for which the
function returns `false` render a disabled checkbox and cannot be selected.

<Demo data={DataGridDemos.rowSelectionPerRow} />

## Select on row click

Set `selectOnRowClick` on `DataGrid` to select rows by clicking anywhere on a row:

- Click selects only that row
- `Shift + click` extends the selection to a range from the last selected row
- `Ctrl / Cmd + click` toggles the row without changing the others
- `Space` toggles the focused row, `Shift + Space` extends the range

## Bulk actions

Add `DataGrid.SelectionBar` next to `DataGrid.Toolbar`. While rows are selected, it replaces
the toolbar with the selected count, your bulk action controls and a button that clears the
selection. Use `store.table.getSelectedRowModel().rows` or `store.getRowSelection()` to get the
selected rows. See [Customization](/data-grid/customization#selection-bar) for the floating
variant and the bar's props.

## Row expansion

Pass `withRowExpansion` to `useDataGrid` to add an expand column. Use the `renderExpandedRow`
prop on `DataGrid` to define the expanded content. Click the expand icon or press `Enter` on

## Expand all rows

Call `store.table.toggleAllRowsExpanded()` with `true` to expand all rows, or `false` to collapse
all rows:

```tsx
store.table.toggleAllRowsExpanded(true);
store.table.toggleAllRowsExpanded(false);
```

## Conditional expansion

Use `getRowCanExpand` in `useDataGrid` to control which rows display the expand toggle:

```tsx
const store = useDataGrid({
  data,
  columns,
  withRowExpansion: true,
  getRowCanExpand: (row) => row.original.hasDetails,
});
```

## Expand on click

Set `expandOnRowClick` on `DataGrid` to toggle row expansion when clicking anywhere on
the row. `renderExpandedRow` is ignored for tree data (`getSubRows`), where expansion reveals
child rows instead of a panel.

## Row numbers

Set `withRowNumbers` in `useDataGrid` to add a row number column. Numbers count data rows only
and run continuously across pages.

## Row focus and keyboard navigation

Without cell selection, rows are the focus targets. The same keys work in the table body,
the virtualized body and the list view:

<DataTable
  head={['Key', 'Action']}
  data={[
    ['`ArrowDown` / `ArrowUp`', 'Move focus to the next / previous row'],
    ['`Home` / `End`', 'Move focus to the first / last rendered row'],
    ['`Enter`', 'Calls `onRowClick` and toggles expansion (or starts editing when editing is enabled and the row is editable)'],
    ['`F2`', 'Starts editing the row when editing is enabled'],
    ['`Space`', 'Toggles selection under `selectOnRowClick`; on a group row toggles the group'],
    ['`Shift + Space`', 'Extends the selection range under `selectOnRowClick`'],
    ['`Escape`', 'Blurs the row'],
  ]}
/>

Keys pressed inside controls within a row (checkboxes, buttons, editors) are not handled by the row.
See [Accessibility](/data-grid/accessibility) for the full list of keyboard interactions.

## Row click and double-click

Use `onRowClick` and `onRowDoubleClick` props on `DataGrid` to respond to row interactions.
Both callbacks receive the `row` object and the `event`; `onCellClick` receives the `cell`:

```tsx
<DataGrid
  store={store}
  onRowClick={(row, event) => {
    console.log('Clicked row:', row.original);
  }}
  onRowDoubleClick={(row, event) => {
    console.log('Double-clicked row:', row.original);
  }}
/>
```

## Cell selection

Pass `withCellSelection` to `useDataGrid` to enable spreadsheet-style cell range selection.
Cells become the focus targets instead of rows and text selection inside cells is disabled.
Group rows are excluded from ranges.

<Demo data={DataGridDemos.cellSelection} />

<DataTable
  head={['Interaction', 'Action']}
  data={[
    ['Click', 'Focuses the cell and starts a new single-cell range'],
    ['Drag', 'Selects the range from the pressed cell to the cell under the pointer'],
    ['`Shift + click`', 'Extends the current range to the clicked cell'],
    ['`Ctrl / Cmd + click`', 'Adds or removes a cell from the selection as another range'],
    ['`Arrow` keys', 'Move the focused cell and start a new range there'],
    ['`Shift + Arrow`', 'Extends the current range in that direction'],
    ['`Enter` / `F2`', 'Starts editing the focused cell when editing is enabled'],
  ]}
/>

Use `cellSelection` and `onCellSelectionChange` to control the state. To read the current
selection, use `store.getCellSelection()` or the table helpers:

```tsx
const store = useDataGrid({ data, columns, withCellSelection: true });

store.table.getSelectedCellIds();
store.table.getSelectedCellCount();
store.table.getSelectedCellRangesData(); // values as [region][row][column]
```

Set `enableCellSelection: false` on a column definition to exclude it from selection.

## List view

Set `listView` on `DataGrid` to render rows as a list instead of a table, for example on narrow
screens. `listView="cards"` (default) renders bordered cards, `listView="flat"` renders items
divided by rules inside the frame.

<Demo data={DataGridDemos.listView} />

By default, an item displays one label / value pair per visible data column. Use `renderListItem`
to render your own content inside the item:

```tsx
<DataGrid
  store={store}
  listView
  renderListItem={({ row }) => (
    <Group justify="space-between">
      <Text fw={500}>
        {row.original.firstName} {row.original.lastName}
      </Text>
      <Badge>{row.original.department}</Badge>
    </Group>
  )}
/>
```

Items follow the row focus model. Group rows are rendered as heading items that toggle on click,
tree rows are rendered flat. Editing and row reorder are not available in list view.

With `height` set, the list scrolls inside a container of that height and pinned items stick
to its top / bottom edge. Without `height`, pinned items are moved to the start / end of the list.

## Row reorder

Pass `withRowReorder` to `useDataGrid` to add a drag handle column. `onRowOrderChange` is called
with a new copy of the data array after rows are reordered:

```tsx
const [data, setData] = useState(initialData);

const store = useDataGrid({
  data,
  columns,
  withRowReorder: true,
  onRowOrderChange: setData,
});
```

Reordering is pointer-only: the handle is hidden from assistive technology and has no keyboard
alternative. If keyboard users need to reorder rows, provide your own controls, for example
move up/down actions in a row menu.

Sorting is disabled when `withRowReorder` is set. Row reorder is not available with tree data,
grouping, `virtualize` and list view. Pinned rows cannot be reordered and are not drop targets,
unpin a row to reorder it.
