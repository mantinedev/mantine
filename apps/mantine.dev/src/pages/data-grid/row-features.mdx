## Row selection

Pass `withRowSelection` to `useDataGrid` to add a checkbox column with a select-all checkbox
in the header. `getRowId` is required to provide stable row ids. Selected rows have the
`data-selected` attribute, use it to style a custom selection column:

## Select on row click

Set `selectOnRowClick` on `DataGrid` to select rows by clicking anywhere on a row:

- Click selects only that row
- `Shift + click` extends the selection to a range from the last selected row
- `Ctrl / Cmd + click` toggles the row without changing the others
- `Space` toggles the focused row, `Shift + Space` extends the range

## Bulk actions

Add `DataGrid.SelectionBar` next to `DataGrid.Toolbar`. While rows are selected, it replaces
the toolbar with the selected count, your bulk action controls and a clear button.
Get the selected rows with `store.table.getSelectedRowModel().rows`. See
[Customization](/data-grid/customization#selection-bar) for the floating variant:

## Expand all rows

Call `store.table.toggleAllRowsExpanded()` to expand or collapse all rows:

```tsx
store.table.toggleAllRowsExpanded(true);
store.table.toggleAllRowsExpanded(false);
```

## Conditional expansion

Use `getRowCanExpand` in `useDataGrid` to control which rows display the expand toggle:

```tsx
const store = useDataGrid({
  data,
  columns,
  withRowExpansion: true,
  getRowCanExpand: (row) => row.original.hasDetails,
});
```

## Expand on click

Set `expandOnRowClick` on `DataGrid` to toggle row expansion by clicking anywhere on the row.
With tree data, expansion reveals child rows and `renderExpandedRow` is ignored.

## Row numbers

Set `withRowNumbers` in `useDataGrid` to add a row number column. Numbers count data rows only
and continue across pages.

## Row focus and keyboard navigation

Without cell selection, rows are the focus targets. The same keys work in the table body,
the virtualized body and the list view:

## Row click and double-click

Use `onRowClick` and `onRowDoubleClick` props on `DataGrid` to respond to row interactions.
Both callbacks receive the `row` object and the `event`:

```tsx
<DataGrid
  store={store}
  onRowClick={(row, event) => {
    console.log('Clicked row:', row.original);
  }}
  onRowDoubleClick={(row, event) => {
    console.log('Double-clicked row:', row.original);
  }}
/>
```

## Cell selection

Pass `withCellSelection` to `useDataGrid` to enable spreadsheet-style cell range selection.
Cells become the focus targets instead of rows and text selection inside cells is disabled.
Set `enableCellSelection: false` on a column definition to exclude it from selection:

<Demo data={DataGridDemos.cellSelection} />

<DataTable

  data={[

    ['Drag', 'Selects the range from the pressed cell to the cell under the pointer'],
    [<code>Shift + click</code>, 'Extends the current range to the clicked cell'],
    [<code>Ctrl / Cmd + click</code>, 'Adds or removes a cell from the selection as another range'],
    [<><code>Arrow</code> keys</>, 'Move the focused cell and start a new range there'],

    [<><code>Enter</code> / <code>F2</code></>, 'Starts editing the focused cell when editing is enabled'],

Use `cellSelection` and `onCellSelectionChange` to control the state. To read the current
selection, use `store.getCellSelection()` or the table helpers:

```tsx
const store = useDataGrid({ data, columns, withCellSelection: true });

store.table.getSelectedCellIds();
store.table.getSelectedCellCount();
store.table.getSelectedCellRangesData(); // values as [region][row][column]
```

## List view

Set `listView` on `DataGrid` to render rows as a list instead of a table, for example on narrow
screens. `listView="cards"` (default) renders bordered cards, `listView="flat"` renders items
divided by rules. Editing and row reorder are not available in list view:

<Demo data={DataGridDemos.listView} />

By default, an item displays one label / value pair per visible data column. Use `renderListItem`
to render your own content inside the item:

```tsx
<DataGrid
  store={store}
  listView
  renderListItem={({ row }) => (
    <Group justify="space-between">
      <Text fw={500}>
        {row.original.firstName} {row.original.lastName}
      </Text>
      <Badge>{row.original.department}</Badge>
    </Group>
  )}
/>
```

With `height` set, the list scrolls inside a container of that height and pinned items stick
to its edges. Without `height`, pinned items are moved to the start / end of the list.

## Row reorder

Pass `withRowReorder` to `useDataGrid` to add a drag handle column. `onRowOrderChange` is called
with a new copy of the data array after rows are reordered:

```tsx
const [data, setData] = useState(initialData);

const store = useDataGrid({
  data,
  columns,
  withRowReorder: true,
  onRowOrderChange: setData,
});
```

Reordering is pointer-only: the handle has no keyboard alternative. If keyboard users need to
reorder rows, provide your own controls, for example move up/down actions in a row menu.

Sorting is disabled when `withRowReorder` is set. Row reorder is not available with tree data,
grouping, `virtualize` and list view. Pinned rows cannot be reordered, unpin a row to reorder it.
