## Basic pagination

Pass `withPagination` to `useDataGrid` to split data across pages. Use `pageSize` to control
how many rows are displayed per page (defaults to `10`).

<Demo data={DataGridDemos.pagination} />

## Page size selector

The pagination component includes a page size selector by default. Use the `pageSizeOptions` prop
on `DataGrid` to customize the available options (e.g., `pageSizeOptions={[5, 10, 25, 50]}`).

## Controlled pagination

Pass `pagination` and `onPaginationChange` to `useDataGrid` to control pagination state externally.
The state follows the TanStack Table `PaginationState` format -- `{ pageIndex: number, pageSize: number }`.

<Demo data={DataGridDemos.controlledPagination} />

## Page navigation methods

The underlying TanStack Table instance exposes programmatic navigation methods accessible via `store.table`:

```tsx
store.table.firstPage();
store.table.previousPage();
store.table.nextPage();
store.table.lastPage();
store.table.getCanPreviousPage();
store.table.getCanNextPage();
store.table.getPageCount();
```

Use these to build a custom pagination UI or to navigate programmatically in response to events.

## Auto-reset page index

By default, the page index resets to `0` when sorting or filtering changes. Pass `autoResetPageIndex: false`
via `tableOptions` to disable this behavior:

```tsx
const store = useDataGrid({
  data,
  columns,
  tableOptions: {
    autoResetPageIndex: false,
  },
});
```

## Server-side pagination

For server-side pagination, set `manualPagination` to `true` and provide `rowCount` with the total
number of rows. Alternatively, use `pageCount` directly when you know the total number of pages
rather than the total number of rows:

```tsx
const store = useDataGrid({
  data: serverData,
  columns,
  manualPagination: true,
  pagination,
  onPaginationChange,
  pageCount: Math.ceil(totalRows / pageSize),
});
```

See the [Server-side](/data-grid/server-side) page for a complete example.
