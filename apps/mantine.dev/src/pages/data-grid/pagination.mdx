## Basic pagination

Pass `pageSize` to `useDataGrid` to split data into pages, 10 rows per page by default.
Add `DataGrid.Footer` as a child of `DataGrid` to display the status text, the page size select
and the page buttons:

<Demo data={DataGridDemos.pagination} />

## Status formats

By default, the status text is `1–10 of 20`. Set `statusFormat="long"` to display
`Showing 1–10 of 20` instead. The number of selected rows is added while rows are selected:

## Page size

Use `pageSizeOptions` to change the options of the page size select, `[10, 25, 50, 100]` by
default. Set `withPageSize={false}` to hide the select, use `selectProps` to pass props to it:

```tsx
<DataGrid store={store}>
  <DataGrid.Footer pageSizeOptions={[5, 10, 25]} selectProps={{ w: 130 }} />
</DataGrid>
```

`paginationProps` are passed down to the `Pagination` component. For example, set
`paginationProps={{ hideWithOnePage: true }}` to hide the page buttons when there is only one page.

Pass `pagination` and `onPaginationChange` to `useDataGrid` to control pagination state.

## Custom footer

Pass `children` to `DataGrid.Footer` to replace the default controls with your own.
Use `store.getPagination()`, `store.table.getRowCount()` and the navigation methods below to build them.
A footer built without `DataGrid.Footer` must set the `--dg-footer-height` CSS variable
for the floating [selection bar](/data-grid/row-features#bulk-actions) to stay above it:

<Demo data={DataGridDemos.customFooter} />

## Page navigation methods

Use `store.table` methods to change the page programmatically:

```tsx
store.table.firstPage();
store.table.previousPage();
store.table.nextPage();
store.table.lastPage();
store.table.setPageIndex(2);
store.table.setPageSize(25);
store.table.getCanPreviousPage();
store.table.getCanNextPage();
store.table.getPageCount();
store.table.getRowCount();
```

## Auto-reset page index

By default, the page index resets to `0` when data, sorting or filtering changes.
Pass `autoResetPageIndex: false` to `useDataGrid` to keep the current page:

```tsx
const store = useDataGrid({
  data,
  columns,
  autoResetPageIndex: false,
});
```

## Server-side pagination

Set `manualPagination` and provide `rowCount` with the total number of rows, or `pageCount`
if you only know the number of pages:

```tsx
const store = useDataGrid({
  data: serverData,
  columns,
  manualPagination: true,
  pagination,
  onPaginationChange,
  rowCount: totalRows,
});
```

Without `rowCount` and `pageCount`, the footer displays `Page 3` with previous / next controls.
See the [Server-side](/data-grid/server-side) page for a complete example.

## Labels

Use `labels` prop of `DataGrid` to translate the footer texts:

- `footerRange` – `{from}–{to} of {total}`
- `footerRangeLong` – `Showing {from}–{to} of {total}`
- `footerRows` – `{count} rows`
- `footerSelected` – `{count} selected`
- `footerPage` – `Page {page} of {total}`
- `footerPageUnknownTotal` – `Page {page}`
- `pageSize` – `{count} / page`
- `pageSizeLabel` – `Rows per page`
- `paginationPrevious` – `Previous page`
- `paginationNext` – `Next page`
