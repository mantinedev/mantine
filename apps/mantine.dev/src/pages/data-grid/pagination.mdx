## Basic pagination

Pass `pageSize` or any other pagination option (`pagination`, `manualPagination`) to `useDataGrid`
to split data into pages. The default page size is `10`. Add `DataGrid.Footer` as a child of
`DataGrid` to display the status text, the page size select and the page buttons.

<Demo data={DataGridDemos.pagination} />

## Status formats

Set `statusFormat` to change the status text: `compact` (default) displays `1–10 of 20`,
`long` displays `Showing 1–10 of 20 · 2 selected`. The selected count is displayed only while
rows are selected. Without pagination the status is `20 rows`.

<Demo data={DataGridDemos.footerStatusFormats} />

## Arrows

## Status only

Set `pagination="none"` to display the status text only. This mode is used automatically

## Page size

Use `pageSizeOptions` to change the options of the page size select, `[10, 25, 50, 100]` by
default. Set `withPageSize={false}` to hide the select, use `selectProps` to pass props to it:

```tsx
<DataGrid store={store}>
  <DataGrid.Footer pageSizeOptions={[5, 10, 25]} selectProps={{ w: 130 }} />
</DataGrid>
```

`paginationProps` are passed to the `Pagination` component. For example, page buttons are
displayed when there is only one page, set `paginationProps={{ hideWithOnePage: true }}` to hide them.

## Controlled pagination

Pass `pagination` and `onPaginationChange` to `useDataGrid` to control pagination state externally.
The state is an object with `pageIndex` and `pageSize`.

<Demo data={DataGridDemos.controlledPagination} />

## Custom footer

Pass `children` to `DataGrid.Footer` to replace the status, page size select and pagination with
your own controls. Use `store.getPagination()`, `store.table.getRowCount()` and the navigation
methods below to build them:

<Demo data={DataGridDemos.customFooter} />

`DataGrid.Footer` sets the `--dg-footer-height` CSS variable, which the floating
[selection bar](/data-grid/row-features#bulk-actions) uses to stay above the footer. If you build
a footer without `DataGrid.Footer` and use the floating selection bar, set this variable yourself.

## Page navigation methods

Use `store.table` methods to change the page programmatically:

```tsx
store.table.firstPage();
store.table.previousPage();
store.table.nextPage();
store.table.lastPage();
store.table.setPageIndex(2);
store.table.setPageSize(25);
store.table.getCanPreviousPage();
store.table.getCanNextPage();
store.table.getPageCount();
store.table.getRowCount();
```

## Auto-reset page index

By default, the page index resets to `0` when data, sorting or filtering changes. Pass `autoResetPageIndex: false`
to `useDataGrid` to disable this behavior:

```tsx
const store = useDataGrid({
  data,
  columns,
  autoResetPageIndex: false,
});
```

## Server-side pagination

Set `manualPagination` and provide `rowCount` with the total number of rows, or `pageCount`
if you only know the number of pages:

```tsx
const store = useDataGrid({
  data: serverData,
  columns,
  manualPagination: true,
  pagination,
  onPaginationChange,
  rowCount: totalRows,
});
```

When neither `rowCount` nor `pageCount` is set, the total is unknown: the footer displays
`Page 3` with previous / next controls, and the next control is enabled while the current page is full.

See the [Server-side](/data-grid/server-side) page for a complete example.

## Labels

Use `labels` prop of `DataGrid` to translate the footer texts:

- `footerRange` – `{from}–{to} of {total}`
- `footerRangeLong` – `Showing {from}–{to} of {total}`
- `footerRows` – `{count} rows`
- `footerSelected` – `{count} selected`
- `footerPage` – `Page {page} of {total}`
- `footerPageUnknownTotal` – `Page {page}`
- `pageSize` – `{count} / page`
- `pageSizeLabel` – `Rows per page`
- `paginationPrevious` – `Previous page`
- `paginationNext` – `Next page`
