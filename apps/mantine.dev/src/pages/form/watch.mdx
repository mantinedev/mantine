## Usage

`useForm` provides several ways to react to value changes. Pick the one that matches the task:

- `form.getValues()` – read the current values in an event handler, see [Form values](/form/values/#getvalues)
- `form.useWatchValue(path)` – render a part of the form based on a field value
- `form.watch(path, callback)` – run an effect when a field changes
- `onValuesChange` option – react to any change in the form, for example to save values to local storage

## form.useWatchValue

`form.useWatchValue` returns the current value of a field and rerenders the component only when that field changes.
Use it to render a part of the form based on a value:

<Demo data={FormDemos.watchValue} />

Do not read values with `form.getValues()` during render, it does not rerender the component when the value changes:

```tsx
import { Collapse } from '@mantine/core';
import { useForm } from '@mantine/form';

function Demo() {
  const form = useForm({
    initialValues: { shipsInternationally: false },
  });

  // ❌ Does not rerender the component when the value changes
  const staleValue = form.getValues().shipsInternationally;

  // ✅ Rerenders the component when the value changes
  const shipsInternationally = form.useWatchValue('shipsInternationally');

  return <Collapse expanded={shipsInternationally}>{/* ... */}</Collapse>;
}
```

`form.useWatchValue` is a hook, it cannot be called conditionally or inside loops:

```tsx
function Demo() {
  const form = useForm({
    initialValues: { name: '' },
  });

  // ❌ This will not work
  if (Math.random() > 0.5) {
    const name = form.useWatchValue('name');
  }
}
```

## form.watch

`form.watch` runs a callback when a field changes.
The callback receives the new value, previous value, touched and dirty states:

<Demo data={FormDemos.watch} />

`form.watch` is a hook, it cannot be called conditionally or inside loops:

```tsx
function Demo() {
  const form = useForm({
    initialValues: { name: '' },
  });

  // ❌ This will not work
  if (Math.random() > 0.5) {
    form.watch('name', ({ previousValue, value, touched, dirty }) => {
      console.log({ previousValue, value, touched, dirty });
    });
  }
}
```

## form.watch cascade

A watcher of a parent path is called when a nested field changes.
The reverse is not true: `form.setFieldValue` on a parent path does not call watchers of nested fields.
Set `cascadeUpdates: true` to change that:

<Demo data={FormDemos.cascadeUpdates} />

## onValuesChange

The `onValuesChange` function is called with new and previous values every time form values change.
